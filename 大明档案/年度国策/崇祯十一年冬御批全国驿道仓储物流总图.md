# 御批・准行全国驿道仓储物流总图

览所奏《全国驿道仓储物流总图》，六利切中治国军商民生要害，兼之朕今五基稳固，财足人顺、政令无阻，此事即刻照准，分期动工，专款足额拨付，全境驿站、仓储订立硬性营建规制，一体遵照执行。

朕御极十一载，权威九十九，全域腐败清零，四权互核恒行；军民各业人心安定，无叛乱隐患；国库每季结余二百万余两，财用充盈，各类专款一季结清，无需节流；文武匠材源源不断，工坊、武备人才供给充足；军政、通商、水泥基建法度齐备，三军九团整编落地，海内富商上万，民心富足，诸事推行推演权重上调，兴办大业无阻滞。

## 一、建网六大益处

1. 漕驿联运，赈灾粮草半月可达灾区，根除转运迟滞、饿殍之弊；
2. 常平仓、防疫药仓沿路配套，疫病突发时药材驰递速达，控疫事半功倍；
3. 三军军需沿干线极速调运，宣大、蓟辽等边镇粮械永不断绝；
4. 丰稷、通济、经武、寰海四总社货品通衢无阻，松江棉、景德镇瓷、皇家琉璃、佛山冶货全域分销，脱离私商运价掣肘；
5. 道路通达商贾云集，船钞、商税、盐茶课自然增收；
6. 沿路仓廪丰年储、歉年粜，稳定粮价，保全民生温饱。

## 二、驿站、仓储硬性统一规制（全境通用，工部逐项核验）

### （一）驿站统一标准

1. 间距规制：主干道每三十里设立一座标准官驿，水陆交汇之处增设水陆合驿；山区、边境酌情加密至二十里一驿。
2. 建筑材质：驿站主楼、马厩、船坞、值守营房全部使用硅酸盐水泥一体浇筑，墙体加厚防潮防火，减少常年修缮支出。
3. 人员配置：每驿常设驿丞一员、文书一名、驿夫三十至五十名；陆路配标准战马二十匹，水驿配漕运快船三至五艘，专司加急文书、粮械、药材转运。
4. 功能分区：驿站划值守区、马船畜养区、临时中转区、官兵休憩区，四社货品、赈灾粮、军用物资分区域停放，不得混杂堆放。
5. 调度权责：加急军情、赈灾药材、军械物料优先调配车马，普通商货延后，驿丞不得私收商贾银钱徇私放行。
6. 监察机制：内廷监事、巡检御史每季巡查驿站人马损耗、收支账册，四权互核对账，贪墨驿马、克扣驿夫者从重治罪。

### （二）配套三类仓库统一标准（每驿配套粮仓、药仓、四社货仓各一间，独立水泥库房互不连通）

1. 民用常平仓

   

   全水泥密闭结构，底层垫高三尺隔绝地气潮湿，内设通风暗道、防潮隔板；分丰年储粮区、赈灾专用粮区、平粜流通区，账目单独登记；设专人每月查验霉变损耗，损耗超定额驿丞记过。

2. 防疫专用药仓

   

   独立隔离库房，水泥隔墙隔绝烟火；分寻常药材、烈性防疫药材、消毒物料分区存放，配专用密闭瓷缸、木柜；常备快马加急通道，一旦州县报疫，当日装车起运；药材出入双签登记，杜绝流失。

3. 四总社转运货仓

   

   宽大通间水泥库房，分纺织、瓷器、琉璃、金属器物分区；配备防潮毡布、木质托架；专存四大总社官营货品，民间私货严禁入仓；进出凭户部、总司双联勘合，无文书不得装卸。

4. 军储增补规范：边境、京畿沿线驿站额外增设小型军储分仓，储备短期粮草、备用火铳与甲片，专供就近驻军应急取用。

### （三）通用仓储铁律

1. 所有仓房严禁明火，每驿设专职防火值守人，配灭火沙土、净水储备；
2. 粮食、药材、军械、商货四类物资分仓隔离，禁止混存造成损耗损毁；
3. 每月造仓储四柱册：入库数、出库数、现存数、损耗数，同步上报户部、对应总司；
4. 水泥仓房完工由工部现场验收，墙体开裂、防水不达标一律返工，工料损耗由承办官吏承担。

## 三、三期修建规制，严格依序推进

### 首期（京畿主干工程，一季拨款，三季完工）

以北直隶为枢纽，修筑连通山东、河南、山西主干驿道万里；三十里一驿站，每站配套水泥粮仓、防疫药仓、四总社转运货仓各一间，全数遵照上文规制建造。

开销核算：干道工料二十万两、三百处驿站水泥仓储十五万两、驿夫驿马驿船置办十万两，首期合计四十五万两，直接从国库季度盈余全额支取，一季一次性拨付到位，不许分年克扣、延缓工期。

### 二期

拓至南直隶、湖广、浙江、江西，贯通南北水陆物流主干，沿路驿站、三类配套水泥仓同步按统一标准修建补齐。

### 三期

铺展陕西、四川、福建、广东、广西、云南、贵州、乌思藏，两京十三省全域驿道、标准化仓储网络完整成型。

## 四、配套管束政令

1. 内廷监事沿路按月盘查仓廪物资、驿站人马，依托四权互核对账，维持全域腐败归零；
2. 六耳军沿路设立巡检点，稽查盗抢、私商拦路抬价，保障官运物资、合规商旅顺畅通行；
3. 各期驿道仓储完工后，督办督抚、工部主事、驿丞一体记功升赏；擅自缩减仓房规格、拖延工期、物资耗损超标的官员罚俸降级，情节严重革职查办。

工部统筹营建物料工匠，户部专管钱粮拨付与仓储核算，兵部调配驿马、值守兵丁，通济水机总司统筹漕船调度，四部协同拟定开工细则十日内进呈御览。



**一、粮仓容量修正** 陛下改粮仓底线为一千石，臣以为极当。五百石仅够三个月赈粥，一千石则足半年两季之用。三百处驿站便是三十万石，陕西若遇大旱，全省粥厂可保六个月不断粮。臣即命户部仓场司修改规制，每驿粮仓统一按一千石建造，水泥仓房须加高二丈、加宽三间，以防储粮发热霉变。 **二、药仓物资细目** 除防疫药材五十斤、石灰二百斤、艾草苍术各三十斤外，臣拟增列急救药物清单：金疮药十斤、止血散五斤、接骨膏二十贴、烧烫伤药十斤、霍乱止泻散五斤。另备丧葬物资：粗布三十匹、棺木料五副、石灰消毒用另储二百斤。烈性疫药如雄黄、柴胡、黄连各十斤，密封瓷缸，贴封条，非疫不发。 **三、便民通传仓收费标准** 书信一封十文，邸报每份一文，此惠民之价，不动。小件包裹每斤五文，亦不变。商货代运，臣细算驿马驿夫之费——每百斤每百里需喂马草料约三文、驿夫往返口粮约二文、车马折损约一文，成本约六文。加官利二文，定价每百斤每百里八文。商贾若急件加急，百里内当日达、五百里内三日达，加收一倍，即十六文。若大宗商货包车，一车三千斤以内，每百里收银二钱四分。如此定价，商贾不嫌贵，驿站不赔本，以商养驿，官民两便。 **四、便民商店与报纸收入** 每城九座便民商店，十五城合计一百三十五座。每座每日售报一千份，每份一文，日入一千文即一两银。一百三十五座日入一百三十五两，每季九十日，报纸一项季入约一万二千两。常规小物件——针线、油盐、火柴、皂角、粗纸、蜡烛、铁钉、绳索、常用成药——每店每日售货约二两银，一百三十五座日入二百七十两，每季约二万四千三百两。两项合计，便民商店每季总入约三万六千两，扣除人工铺租成本约一万两，每季净入约二万六千两，足以覆盖便民通传仓之人工费。 **五、便民商店详细规则** 每城九店以九宫格布局，城中央一店为总店，四正四隅各一店，覆盖全城。每店面积不过三间门面，前两间售货、后一间存货。每店设掌柜一人、伙计三人，每日卯时开门、酉时歇业。货品由通衢总社统一配发，不得私自进货。报纸每晨由驿站快马送至各店，当日售罄可加印百份，售不完则次日退回驿站。每店账册每月一报，省城总部汇总核验。民间可预购报纸，每份一文，预购一月者收二十五文送五份，预购一季者收八十文送十份。 **六、通衢总社整体收入预估** 驿站商货运输每季约入五万两，便民商店每季净入约二万六千两，报纸广告每季约入一万两——省城富商欲在邸报夹页刊登商号广告，每版收银十两。三项合计，通衢总社每季净入约八万六千两。驿站人工、驿马草料、车船折损每季约需六万两，收支相抵尚有结余，不须国库常年补贴。







**三朕准王三善所奏。皇明通衢便民总社与丰稷、通济、经武、寰海并列，合称五总社。礼部左侍郎倪元璐兼任总理。两京十三省各设省城总部一处，每处粮储总仓五万石、药储总仓急救防疫药材齐全、四社总货仓存货三千件、便民通传总仓容量万件。各省巡抚划拨官地十亩营建，工部供应水泥熟料。总部主事由礼部从科举文官铨选，吏部备案。通衢总社专司运输，四社货品及民间书信邸报商货皆由通衢承运，以商养驿、以运养仓，不增国库负担。礼部户部工部二十日内呈章程细则。

朕准王三善所奏驿道仓储通传规制。粮仓每驿储粮一千石，三百驿共三十万石。药仓增急救药物、丧葬物资，烈性疫药密封另存。便民通传仓书信十文、邸报一文、包裹每斤五文，商货每百斤每百里八文，加急倍之。十五城各设便民商店九座，以九宫格布局，每店日售报千份。通衢便民总社与四社并列，礼部兼辖，倪元璐兼任总理。各省城总部设主事一员，科举文官充任。以上规制，礼部会同户部工部二十日内呈章程细则。

朕准王三善所奏。全国驿道仓储物流总图即刻施行，首期以北直隶为枢纽，修通山东河南山西主干驿道万里，三十里一驿，每驿配水泥粮仓、防疫药仓、四社货仓各一间。国库拨四十五万两一季结清，三季完工。六耳军沿路设巡检点，稽查盗抢私卡。内廷监事每季盘查驿站人马仓储，四权互核。工部统筹营建物料，户部专管钱粮核算，兵部调配驿马值守，通济总社调度漕船。四部十日内呈开工细则，首期三百驿站九百仓房规制不得缩减，违者革职。
