## 资料版本处理

- GitHub `main` 快照作为同步基准。
- 本地同路径异稿不覆盖GitHub正式稿，统一保存在 `99_原始资料/同步前本地同名稿/`。
- 本地独有资料按内容移动至朝政纪要、朝臣档案、军队档案、季度目标、年度国策、战略方略或制度规则。
- 所有移动只改变路径和文件名，正文SHA-256保持不变。
