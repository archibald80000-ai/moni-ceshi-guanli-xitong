# 崇祯二年夏季朝政纪要

# ——三层防务初定，江南洪涝陕乱加剧



## 朝政纪要



陛下本季颁布谕旨，意在确立“辽西守城、东江牵制、蓟宣防绕道”三层防御体系，命孙承宗总辖宁锦、东江、蓟宣三方军务，以核验关宁实册、裁汰虚额所余银两，六成修蓟宣烽堠墩台，四成赈陕西屯田；于东江镇试行制辽五策，拨银六万两、粮二万石、火药八千斤、修船银一万两，令毛文龙以皮岛为根本，小股登陆辽南焚粮毁船、招抚辽民、经营细作、封锁黄海、联络朝鲜；又拨北边扰敌专项银五万两，命袁崇焕选精骑三百专杀后金哨探运粮、毛文龙以舟师袭扰沿海粮道、满桂携茶帛联络土默特诸部拒后金借道；户部另分立辽西验饷、东江试行、蓟宣修防三册，三十日内核清银粮出处，明令不得挪陕西赈银、不得加派民田正税；礼部遣使寻察哈尔林丹汗新驻地，调整互市口岸至大同以西，往来朝鲜只求停泊补水、不迫出兵；加李国普统考成、王承恩旁验三处册籍、袁可立专审擅杀侵饷虚冒私通四案，并严谕袁崇焕不得擅杀毛文龙，二人相争须经孙承宗、卢象升、李国普裁定。



现将各项诏令执行实情与因果始末分条奏报如下：



**一、三层防御体系制度化落地**



孙承宗奉旨扩展为“总辖宁锦、东江、蓟宣三方军务”，建极殿大学士、督师辽东、兼理兵部事原职不变，新增总辖衔。十日内会同兵部尚书卢象升，对关宁军核验实兵、实饷、火药、马匹、城砖、病弱六册。经核，关宁将门对裁汰虚额、严核兵册一事极为不满，消极抵抗，忠诚度由八十降至七十八。孙承宗为顾全大局、避免激化矛盾，选择内部消化处理，未公开惩处。核验所得冗饷、空名、侵饷等结余银两，已按陛下旨意分作六成归蓟宣修防、四成归陕西赈灾屯田，但具体数额因将门抵制、账目复杂，本季仅部分到账。



满桂由大同总兵升任宣大蓟机动巡防主将，曹文诏由辽东游击将军调任京畿机动巡防副将、领精骑夜哨，二人分守宣大与蓟镇方向，形成机动呼应。蓟宣修防遵旨不兴大工，只补居庸、古北口、蓟州、宣府、大同各镇最急险段墩台倾圮、烽燧断火等处。得益于此前解锁之竹筋砼技术，同等经费可修补更多险段，效率小幅提升。



**二、东江五策试行启动**



毛文龙奉旨启动东江五策试行。本季国库实拨银六万两、粮二万石（折银约一万两）、火药八千斤（折银约一万六千两）、修船银一万两，合计约九万六千两。来源为辽饷核减虚额、山海关追回侵饷、广州宁波市舶留成与宫中节用四项拼凑，未动陕西赈库。试行银粮到账后，东江军补给由四十升至五十、士气由六十升至六十三、忠诚由四十五升至四十七——试行银粮立竿见影，但忠诚仍处危险区间，若后续粮饷不继可能反弹。毛文龙已按诏书要求，开始筹备小股登陆袭扰辽南、招抚辽民、经营细作、封锁黄海、联络朝鲜等事，本季可执行一至二次小规模登陆。陛下原定每登陆一次限三千至五千人、战船约二百艘、耗粮约三千石、银约二万两、火药五千斤，东江镇已照此备办。招抚辽民分战兵、屯户、老弱、军眷四册之法亦已部署，待收容后造册上报。



**三、北边扰敌专项启动**



户部拨专项银五万两，三月为期。袁崇焕遵旨选关宁精骑三百，于大凌河至辽河之间专杀后金哨探运粮，夜出昼伏；毛文龙以东江舟师袭扰沿海粮道；满桂遣人携茶帛盐引前往联络土默特诸部，以拒后金借道，并许以斩后金使臣哨骑来报者赏银十两。三路同时展开，但因规模有限，以牵制为主而非决战，本季未见重大战果。



**四、财政分册与考成推进**



户部尚书毕自严奉旨分立辽西验饷、东江试行、蓟宣修防三册，三十日内核清银粮出处。国库当前赤字约三百九十七万两，在不得挪陕西赈银、不得加派民田正税的硬约束下，东江试行银粮从核减虚额和市舶留成中拼凑到账。因圣旨隐含起复毕自严之意（其原赋闲在家，已起复为户部尚书），毕自严全力配合，但国库深赤，来源有限，部分银粮尚未完全到位。蓟宣修防以验饷结余六成支用，因竹筋砼技术提高了修防效率，有限经费发挥了更大效用。三月终考三事（辽饷虚额是否核出、东江试行银粮是否有实物、蓟宣烽堠是否可传警）已纳入考成，李国普总司其事。



**五、互市调整与遣使**



礼部尚书来宗道奉旨二十日内遣使西行，沿河套、漠西方向寻找察哈尔林丹汗新驻地。互市常额十二万两与军情赏格三万两仍分册给付，互市口岸随察哈尔西迁调整至大同以西。本季张家口、宣府口岸因林丹汗西迁，物资部分积压，仅约六成通过土默特等中间部族间接流向察哈尔，察哈尔对明朝信任度下降。遣使已于本季出发，预计下季度有初步结果。对朝鲜方面，礼部已按旨意只求铁山、义州两港供东江停泊、补水、收容辽民、递送边报，不索饷不迫出兵，策略务实。



**六、监督机制与秘密调查**



王承恩奉旨旁验东江、辽西、蓟宣三处册籍，选锦衣卫清慎官十二员，分驻山海关、登莱、东江、宣大互市，只验银粮、军额、船只、边报副本，不夜入民宅、不拷掠士民。袁可立专审擅杀镇将、侵吞东江饷粮、虚报辽民兵额、私通后金朝鲜四案，有实证者六十日内定罪，无实证不得借党争罗织。



此外，陛下另授王承恩秘密调查之权。王承恩持皇帝玉佩，调北直隶等七省锦衣卫精干，分查阉党旧赃（天启年间侵吞盐课库银）与东林贪墨（江南七府隐匿田亩偷漏商税）。证据造册封存一式两份，王承恩与锦衣卫指挥佥事李若琏各掌其一。此番调查不惊动有司、不立案不审讯不上奏，为期两个季度。阉党残余闻讯恐慌加剧，满意度由五十八降至五十五，影响力由三十六降至三十四；东林党亦受震动，满意度由二十四降至二十二。



**七、江南春旱转洪涝**



本季江南遭遇严重天灾。南直隶春旱未已，又连降数十日暴雨，转为中等洪涝，民心由六十九降至六十四；浙江、江西亦由旱灾转为轻微洪涝，民心分别由七十五降至七十二、六十五降至六十二。旱灾后遭洪涝，粮食产量再降约两成，粮价推高，朝廷从江南购粮赈陕更加困难。江南士绅因清查与天灾叠加，恐慌加剧，满意度由十九降至十七。



**八、湖广治水完工**



湖广水灾解除，灾害状态由水灾中等恢复正常。此前内帑借银十万两及后续投入的堤岸修缮和沟渠疏浚工程全部完工，民心由六十回升至六十三。粮食产量逐步恢复，预计秋季可完全恢复正常。湖广可作为陕西赈灾新粮源，替代受灾的江南。



**九、陕西旱灾持续与起义军扩张**



陕西严重旱灾持续。此前累计约一百四十五万两银和约三十万石粮的赈灾投入大幅减轻了后果，但因旱灾持续，赈灾效果被侵蚀：民心由三十二降至二十九，动乱风险由八十二升至八十四。仍有约五至八万农民转为流民，部分加入起义军。王二起义军增加约八百辅兵（总兵力由一万一千四百增至一万二千二百），王嘉胤部增加约一千辅兵（由一万八千五百八十增至一万九千五百八十），高迎祥部增加约五百辅兵（由八千三百五十增至八千八百五十）。李自成于陕西米脂起兵，聚集约二千五百人（辅兵二千三百、轻步兵二百），加入起义军序列。陕西起义军总兵力已超四万八千人。河南饥民起义军亦夏季扩张，由约一千三百人增至约二千三百人（增加约一千辅兵），活动范围在豫西山区进一步扩大，河南民心由三十八降至三十六，动乱风险由三十二升至三十五。



**十、魏忠贤南下清查到期收队**



魏忠贤南下清查苏松常三府三个月到期。追缴隐匿田亩折银约十五万两、私囤金银约八万两，合计约二十三万两。东林党和士绅强烈反弹但未大规模抗议。魏忠贤按期收队，未扩大株连。追缴银两七成解陕西赈灾、二成充国库、一成支办案费用。



**十一、其他已发生事件**



宋应星廷议定秩：常平仓建设推进中（陕西四仓存粮约五至六万石未满）、湖广治水近完工、火器改良完成约六成。廷议结果：保留工部尚书衔但受工部左侍郎会签限制，再给三个月观察期。



陕西常平仓（西安、延安、庆阳、凤翔四府）框架已建成运营，但储粮未满：目标十二万石，实际存粮约五至六万石，距满仓差距约六至七万石。因江南春旱购粮受阻和冬季运粮困难，湖广治水完工后可从湖广增购补仓。



广州宁波市舶轻税运行一年评估：广州年化市舶税约七万五千两、宁波约六万五千两，郑芝龙岁输税银约六万两，合计年化约二十至二十一万两，略超二十万两目标。民间海外贸易规模扩大约两成，福建广东海商活跃度上升。可作为东江试行银来源之一。



锦衣卫巡查分驻一年评估：山海关查获侵饷案三起追回约二万两，陕西查获侵赈案五起追回约三万两，两淮查获私盐案四起追回约五万两，广州宁波查获侵吞市舶税案二起追回约一万两，合计追回约十一万两。巡查制度对基层贪腐有震慑，腐败度由八十降至七十八。



**十二、诏令中未成功执行或部分生效之处**



陛下原旨命田尔耕、曹化淳前往陕西锁拿贪吏宗室并强征银两，但田尔耕已于天启七年冬季魏忠贤败亡案中被捕下狱，今仍系狱中。陛下误命囚臣，经刑部与锦衣卫核查，此人确在狱中，无法执行诏令，该任务已转交他人办理。此事暴露中枢信息滞后，对大明威望产生一定影响。



陛下原命清查山西、陕西隐匿田亩追缴二百万两，但陕西已陷入全面战乱，明军控制区极小，执行部队遭起义军伏击和地方武装抵制，仅搜刮到少量财物，反而激起更大规模民愤，陕西民心彻底崩盘。山西方面，晋商恐惧资产被夺，纷纷通过秘密渠道将资本转移至江南或海外，并加强与后金的秘密贸易以寻求政治庇护，朝廷几乎未能追缴到银两，反而引发大规模资本外逃。



陛下原命户部毕自严限期增银五十万两，但因国库深赤、各地天灾战乱，整顿阻力重重，本季仅勉强维持收支平衡，未能实现增银五十万两之目标。



陛下原命东江试行银粮来源为辽饷核减虚额、山海关追回侵饷、市舶留成与宫中节用四项，因部分项目未完全到账，实际拨付约九万六千两，虽已足额，但后续季度能否持续存在不确定性。
