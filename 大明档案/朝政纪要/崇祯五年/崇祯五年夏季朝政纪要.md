# 崇祯五年夏季朝政纪要

# ——三路扰辽初振军心，察哈尔覆灭边患愈深



## 朝政纪要



陛下本季颁下数道紧要谕旨：军事方面，命卢象升总督北边大举扰辽，孙承宗总裁军议，袁崇焕、毛文龙、孙元化三路并发，乘皇太极远征林丹汗、后金主力在塞外之机，于六月内焚后金粮囤、毁其船械、掳其马畜，务求成捷；拨银五十万两，粮二万石、马料五千石、火药一万二千斤、铅子五万发，由户、兵、工三司会给；宁远、山海关、大同、宣府、蓟州、居庸、古北口诸要害各留守兵不得少于五千。内政方面，命孙传庭坐镇西安总陕晋豫截流军务，洪承畴专主赈务，户部本季再拨赈粮八万石、银十五万两、种具银三万两，续入陕晋豫赈抚屯田库；王徵所造农具夏末前实到陕西、河南屯棚；徐霞客舆图交孙传庭设卡；史可法巡按河南、山西；魏照乘督八省药仓，内帑二十万两限三月建仓六十八处以上。外交方面，命来宗道联察哈尔、土默特牵制后金，仍给互市常额十二万两、军情赏格三万两；礼部遣使朝鲜，令其守义州、铁山、朔州，密报后金东线兵马；熊文灿、郑芝龙守广州、宁波、泉州、漳州、福州五口商路，禁炮法北流。其他方面，命王承恩、毕自严、李若琏总四库分账，另立“三路扰辽军费册”，与大同急救库、陕晋豫赈抚屯田库、辽西换防库、疫前药仓库并行；兵部、礼部、翰林院会撰捷报告谕，榜示天下。



现将各项诏令之执行实情与因果始末分条奏报如下：



### 一、三路扰辽之役



陛下乘皇太极北征、后金主力在塞外之机，命三路并发扰辽。然军人阶层因满意度仅十九，本季消极抵抗，虽未完全拒绝出战，但关宁军实出约九成，共计约一万一千人。袁崇焕率关宁军精选轻骑、火枪兵、辅兵，分三营夜出辽河套，专袭屯田、牧场、驿站、粮仓，不攻坚城，不恋久战，焚辽河套西岸屯田牧场二处，夺粮约一千二百石、掳马约一百八十匹，自身损失约一千二百人。毛文龙率东江舟师战兵约一万三千人，分登陆辽南复州、金州、盖州、旅顺诸处，焚粮囤三处、毁盐场一处，招辽民、截私船，自身损失约一千八百人。孙元化调登莱水师三十艘大船护粮船、火药船往宁远、皮岛，佯攻鸭绿江口，以牵后金东线；朝鲜遵旨出兵佯动，配合登莱水师。后金留守约十至十一万人应战，损失辅兵约二千五百人。此役夺粮约一千二百石、掳马约一百八十匹，未达陛下诏书“焚毁粮仓十处以上、夺粮三千石以上、掳马五百匹以上”之全胜目标。军费由内帑支出四十五万两。然三路主动出击，天下知朝廷非坐守待毙，大明威望由四十四升至四十五，军心稍振。关宁军士气由六十七升至七十，东江军士气由八十升至八十二。



### 二、察哈尔覆灭与后金坐大



陛下命来宗道联结察哈尔、土默特牵制后金，给互市常额十二万两、军情赏格三万两。然皇太极率八至十万大军远征林丹汗，察哈尔仅二至三万众，不敌后金。林丹汗率残部约九千六百人西迁青海方向，察哈尔蒙古全部被后金征服，其故地归后金所有。后金威望由八十四升至八十七，察哈尔威望由三十五降至二十五，漠南蒙古战略真空进一步扩大，后金战略纵深愈加广阔。察哈尔部兵马损失惨重：重骑兵由一千减至四百，轻骑兵由八千五百减至三千四百，轻步兵由一千五百减至六百，辅兵由一万三千减至五千二百，士气由四十降至十五。科尔沁部补给亦受战事波及，由七十降至六十五。



### 三、陕西赈抚屯田



陛下命孙传庭坐镇西安，总陕晋豫截流军务；洪承畴专主赈务，不受出辽军务牵制。户部本季拨赈粮八万石、银十五万两、种具银三万两，续入陕晋豫赈抚屯田库，西安、延安、米脂、潼关、蒲坂、晋南、豫西诸处粥厂照旧给粮，归降营照旧收胁从，屯田棚照旧给种具。王徵所造水车百具、铁锄千柄、辘轳五百具，夏末前实到陕西、河南屯棚，王徵因功授工部营缮司主事。徐霞客舆图交孙传庭设卡，专断流民入贼之路，未借测图丈田扰民。史可法巡按河南、山西，查豪强闭仓、军士扰民、官吏侵赈。经此一番赈抚封控，陕西新增裹挟约一千八百人，低于陛下底线一千八百九十人，达成目标；归降屯田约四千人，较春季增三成以上，亦达成目标。洪承畴因此实授陕西巡抚。陕西民心由二十三升至二十四，叛乱风险由九十二降至九十，起义军扩张速度放缓，但因各股贼众仍逾七万，形势仍十分严峻。



### 四、八省药仓开建与疫防



陛下命魏照乘督八省药仓，内帑拨银二十万两，限三月内于北直隶、山东、河南、山西、陕西、南直隶、湖广、四川八省建药仓六十八处以上，备艾草、苍术、石灰、粗布、棺木、常用药材。疫册五日一报，鼠毙、井臭、兵营病亡、逃荒聚棚、仓粮霉烂有一项异常，即开仓预备。本季内帑已支出二十万两，八省药仓已开建，预计崇祯六年春季验收。又因陛下诏书命兼察五省疫册，工部左侍郎刘宗周正式上任，以工部左侍郎兼察五省疫册，理学与西学在工部形成张力，疫册核验效率有所提升。



### 五、辽西防务与宁远炮铸



辽西六十日考成本季执行：撤民、撤粮、撤炮完成约六至七成，遗炮控制在二门以内，关宁军士气止跌回升。宁远红夷炮补铸因红夷大炮年产为零，本季仅新增三门，库存由二十门增至二十三门，远未达陛下期望的二十五门目标。大同三月考成亦执行：大同边军士气由三十四升至三十五，维持不跌破二十底线达成；边民被掠减半达成；左良玉因功实授大同副总兵。宁远、山海关、大同、宣府、蓟州、居庸、古北口诸要害各留守兵均不少于五千，山海关、宁远未空虚。



### 六、外交与海贸



来宗道会兵部、户部，维持对察哈尔、土默特互市常额，然察哈尔已覆灭，互市之策效力大减。礼部遣使朝鲜，朝鲜遵旨守义州、铁山、朔州，出兵佯动配合登莱水师，并获火药、鸟铢援助。朝鲜水师士气因配合度提升而由十升至十三。熊文灿、郑芝龙守广州、宁波、泉州、漳州、福州五口商路，三等商税仍旧，未另增名目，截获硝磺、铅铁、炮书、炮匠北流之事未有重大发现，海贸禁炮持续。后金仿制红夷大炮之尝试本季亦在进行，因缺乏实物参照和西洋技师指导，仅完成粗糙模具和初步熔炼试验，无成品产出。



### 七、其他事项



艺学局一年评估完成：首批学员二十二人完成基础西洋历算和铸炮理论学习，底线二十人达成，上考四十人未达。宋应星呈报工部，建议续办并扩大招生。工程营一年评估完成：成丁约六千人，底线八千人未达成，修成井渠堡仓多处，陕西抗旱能力小幅提升。陕晋豫封控首季考成亦已完成，洪承畴升陕西巡抚实衔。王徵农具验收完成，授工部营缮司主事。三路扰辽捷报由兵部、礼部、翰林院会撰，经王承恩、孙承宗核验后，榜示京师、九边、陕西、江南诸省。

**陕西民心**（二十三 → 二十四）：赈粮到位、农具实到、归降屯田见效，民心微升 **陕西叛乱风险**（九十二 → 九十）：封控赈抚见效，裹挟增速放缓，动乱微降 **察哈尔蒙古归属**：由大明势力范围转为后金所有



### 军队系统变动



**关宁军士气**（六十七 → 七十）：出战且取得焚屯田牧场之实绩，士气提振 **关宁军补给**（六十五 → 五十七）：出塞作战消耗，补给下降 **关宁军兵力**：重骑兵五千七百→五千五百（损失二百），轻骑兵六千五百→六千二百（损失三百），火枪兵一万一千五百→一万一千三百（损失二百），辅兵一千六百四十→一千一百四十（损失五百） **东江军士气**（八十 → 八十二）：四路并发、焚粮毁盐，士气提振 **东江军补给**（六十 → 五十五）：远途登陆作战消耗，补给下降 **东江军兵力**：轻步兵一万→九千六百（损失四百），火枪兵八千→七千八百（损失二百），辅兵二万一千二百八十五→二万零八十五（损失一千二百） **八旗军士气**（九十 → 八十九）：遭三路袭扰，士气微降 **八旗军补给**（八十三 → 七十五）：远征与应战双重消耗，补给下降 **八旗辅兵**（六万二千四百一十一→五万九千九百一十一，损失二千五百） **察哈尔部兵马士气**（四十 → 十五）：遭后金击溃，士气崩盘 **察哈尔部兵力**：重骑兵一千→四百（损失六百），轻骑兵八千五百→三千四百（损失五千一百），轻步兵一千五百→六百（损失九百），辅兵一万三千→五千二百（损失七千八百） **科尔沁部补给**（七十 → 六十五）：受察哈尔战事波及，补给下降 **大同边军士气**（三十四 → 三十五）：大同三月考成达成，士气微升 **朝鲜水师士气**（十 → 十三）：配合登莱佯动，士气提升 **登莱水师补给**（六十 → 五十五）：佯攻鸭绿江口消耗，补给下降



### 势力威望变动



**大明威望**（四十四 → 四十五）：三路扰辽主动出击，天下知朝廷非坐守待毙 **后金威望**（八十四 → 八十七）：击溃察哈尔、征服其故地，威望大涨 **察哈尔威望**（三十五 → 二十五）：被后金击溃，威望骤降



### 社会阶层与党派变动



**军人满意度**（十九 → 二十二）：出战犒赏提振，微升 **武勋满意度**（四十*****十八）：关宁东江出战、左良玉实授大同副总兵，武勋满意



### 装备变动



**红夷大炮库存**（二十门 → 二十三门）：宁远补铸新增三门 **火铳库存**（四万六千二百支 → 四万五千七百支）：三路扰辽作战消耗五百支



### 人事变动



**洪承畴**：因陕晋豫封控首季考成达标（新增裹挟低于底线、归降屯田超三成），由专主赈务实授陕西巡抚 **左良玉**：因大同三月考成达成（士气不跌破底线、边民被掠减半），实授大同副总兵 **刘宗周**：以工部左侍郎兼察五省疫册，正式上任 **王徵**：因水车百具、铁锄千柄、辘轳五百具实到陕西河南屯棚，授工部营缮司主事



## 总结



三路扰辽虽未达全胜目标，然焚粮夺马、毁场毁盐，天下知朝廷非坐守待毙，军心稍振、威望微升；然皇太极远征得胜，察哈尔覆灭、后金威望升至八十七，漠南蒙古尽归其手，战略形势对大明愈加严峻。陕西赈抚封控见效，裹挟放缓、归降增多，洪承畴实授巡抚，西北根基稍固。八省药仓开建，疫防体系初立。内帑因军费与药仓共支出六十五万两，国库压力沉重。后金秋季可能回师报复，辽西、宣大防务不可稍懈。
