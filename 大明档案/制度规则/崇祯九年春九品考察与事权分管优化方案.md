# 《九品考察与事权分管优化方案》
## ——考成法第二版与国家执行链条改革国策

> **国策目的**：解决现行九品考成“指标过多、数字易虚报、一次未达即恐慌”和事权分管“防贪有效但层层签押、执行迟缓”的问题。
> **核心原则**：少考、实考、连续考；定策、执行、财计、稽核、密侦、司法彼此分离，但不得相互推诿。

---

## 一、现行制度的主要问题

### 1. 九品考成的问题

现行制度已经产生正面效果：

- 官员知道赈务、军饷、工务要有期限和数字；
- 养廉与考成结合后，官僚满意度曾明显回升；
- 四权互核能够降低大额挪用与单人专断。

但档案反馈也暴露出四个问题：

1. **同一季度目标太多**：官员既要赈灾、反贪、扩军、修渠、建仓、兴学，又要提高满意度，最终只能把每项都完成一点。
2. **不同职位用同一把尺子**：边将、户部官、地方知县、工部匠官、刑部官的任务不同，不能用同一组数字评价。
3. **把不可控结果直接压给官员**：民心、满意度、腐败度由灾害、战争、资源和多部门共同决定，不能因单项点数未升就认定某官失职。
4. **高压考核诱发虚报**：当上考目标远高于实际能力，地方会虚报归屯、军功、工程和情报数量，以避免被降品。

### 2. 事权分管的问题

当前“掌账不掌刑、掌刑不掌账、审账、密核、内阁复核、司礼监封册”的方向正确，但若所有小额支出都要多部门事前签押，会出现：

- 紧急军饷、药材和赈粮迟发；
- 每个部门都有否决权，却无人对结果负责；
- 事后失败时互相归责；
- 六耳、锦衣卫、都察院和刑部重复调查。

所以必须从“所有事情多方共管”改为：

> **定策一处、执行一人、财计双钥、稽核抽查、密侦补证、司法定案。**

## 二、三目九品考成制

每名官员每季度只考三大项，总分100分。

### 1. 主业成果：50分

只考本职最重要的1—2项结果。

示例：

- 边将：守口、军队保全、补给、敌军预警；
- 陕西主官：叛军补给、取消番号、归屯留存；
- 户部官：到账率、账实差、专库余额；
- 工部官：合格产量、工期、返修率；
- 地方官：粮价、粥厂、春播、治安；
- 情报官：有效预警、验证率、错报率；
- 刑部官：证据完整、结案时限、冤案率；
- 学政官：入学、到任、课程和人才留用。

### 2. 质量与持续结果：30分

不能只看当季数量，要看成果能否维持：

- 归屯三十日、九十日留存率；
- 工程三个月后是否损坏；
- 军队补给是否连续；
- 降众是否复叛；
- 海贸税是否真实入库；
- 情报是否帮助决策；
- 官员离任后制度是否继续运行。

### 3. 廉洁、纪律与扰民：20分

考核：

- 账实差；
- 克扣、乱派；
- 杀良冒功；
- 冤案；
- 越权；
- 对百姓、军士、商人的实际负担；
- 是否隐瞒灾情和战损。

## 三、职位分类考核

### A类：军事主官

| 指标 | 权重 |
|---|---:|
| 守住任务区、保全主力 | 30 |
| 军粮、士气、训练与预警 | 20 |
| 战果质量、协同与持续性 | 30 |
| 军纪、扰民、虚报 | 20 |

军事主官不能以单纯斩首数为第一指标。擅自出塞、抽空原防、杀良冒功属于红线。

### B类：财政与仓储官

| 指标 | 权重 |
|---|---:|
| 实银、实粮、实物到账 | 30 |
| 账实差与支付时限 | 20 |
| 收入持续性、专库安全 | 30 |
| 乱派、挪用、官商勾连 | 20 |

不得用“追缴案件数量”作为反贪主指标，以免制造案件。

### C类：地方治理官

| 指标 | 权重 |
|---|---:|
| 粮价、赈务、治安、春播 | 30 |
| 流民、归屯、灾后恢复 | 20 |
| 三十日与九十日留存 | 30 |
| 扰民、克扣、隐灾 | 20 |

### D类：工部、军工与工程官

| 指标 | 权重 |
|---|---:|
| 合格产量、完工率 | 30 |
| 原料、尺寸、试验、交付 | 20 |
| 返修率、持续产能 | 30 |
| 偷料、虚工、事故 | 20 |

### E类：情报与巡核官

| 指标 | 权重 |
|---|---:|
| 有效预警、验证情报 | 30 |
| 提前量与覆盖盲区 | 20 |
| 错报、漏报、泄密 | 30 |
| 越权、扰民、造假 | 20 |

### F类：刑名与监察官

| 指标 | 权重 |
|---|---:|
| 证据完整与结案时限 | 30 |
| 大案追回与责任认定 | 20 |
| 冤案率、复核通过率 | 30 |
| 刑讯、株连、借案索贿 | 20 |

### G类：学政、外交与海贸官

按本职分别考：

- 学政：人才到任与实际使用；
- 外交：有效军情、互市守信、敌方分化；
- 海贸：净入库、护航、禁货外泄和商路持续。

## 四、九品等级

| 品级 | 季度综合分 | 处置 |
|---|---:|---|
| 一品上上 | 90—100 | 大赏、晋升、扩大权限 |
| 二品上中 | 85—89 | 记大功、优先晋升 |
| 三品上下 | 80—84 | 记功、增俸或专项赏 |
| 四品中上 | 75—79 | 良好，留任 |
| 五品中中 | 70—74 | 合格，留任 |
| 六品中下 | 60—69 | 基本合格，限补短板 |
| 七品下上 | 50—59 | 一季整改、减赏 |
| 八品下中 | 40—49 | 降调或更换副手 |
| 九品下下 | 0—39 | 撤职查责；有红线行为则入法司 |

### 重要修正

- **不以单季度决定长期升降**：采用连续两个季度加权平均。
- **年度总考**：四季度后按全年趋势定晋升、留任和降调。
- **新任官员保护期**：到任首季度只考建账、识人、组织和前置动作，不强求最终结果。
- **灾害豁免不免责**：不可抗灾害可修正目标，但不得豁免隐瞒、克扣和迟报。
- **红线优先**：通敌、贪赃、失城弃军、杀良冒功、挪赈、泄露核心火器资料，不受平均分保护。

## 五、证据等级

所有考成结果必须标明证据等级。

| 等级 | 证据 |
|---|---|
| A | 实物点验、双账一致、两路以上独立核验 |
| B | 正式册报并有一次外部抽查 |
| C | 单一部门奏报，尚未外核 |
| D | 口述、传闻、推演或计划数字 |

规则：

- A、B级可直接计功；
- C级只计暂定功；
- D级不得作为升降依据；
- 上考必须至少有B级证据；
- 涉及通敌、贪赃和死刑，必须有两类独立证据并经法司复核。

## 六、连续考成与归因

### 1. 两季度移动平均

```text
本季考成分 = 主业成果50 + 持续质量30 + 廉洁纪律20
任职考成分 = 本季60% + 上季40%
```

年度考成：

```text
年度分 = 最近四季平均分
        + 重大功劳修正
        - 红线与重大过失修正
```

### 2. 未达原因分为五类

1. **资源不足**：银、粮、兵、器未到账；
2. **外部冲击**：战争、灾害、疫病；
3. **协同失败**：其他部门延误；
4. **目标失真**：诏书目标高于合理兑现率；
5. **本人失职**：迟报、瞒报、贪腐、错误指挥。

处理方法：

- 1—4类先补资源、改协同或改目标；
- 第5类才直接扣分和追责；
- 多因并存时必须列明比例，不得用一句“执行不力”概括。

## 七、事权六分体系

### 1. 定策权

**主体**：皇帝、内阁、军议。
**职责**：确定季度主攻、资源上限、责任人、失败线。
**不得**：直接经手银粮、抓捕或审案。

### 2. 执行权

**主体**：六部、督抚、总兵、专项主官。
**职责**：按授权完成任务，对结果负责。
**不得**：自行修改审计规则或掌握秘密侦查全网。

### 3. 财计权

**主体**：户部、专库、地方布政司。
**职责**：拨款、记账、核对实银实粮和承诺。
**不得**：独自决定立案、判刑或军队调动。

### 4. 公开稽核权

**主体**：都察院、六耳巡核。
**职责**：查账实、查到位、查进度、接受公开陈报。
**不得**：秘密抓捕、刑讯、抄家、征税、调兵。

### 5. 密侦权

**主体**：锦衣卫。
**职责**：暗查通敌、重大贪腐、假账、泄密和六耳是否被收买。
**不得**：自行判刑、决定财政支付或长期掌控地方行政。

### 6. 司法权

**主体**：刑部、都察院、大理寺或临时三法司会审。
**职责**：审证、定罪、复核、纠错。
**不得**：以审案名义接管财政或军政。

## 八、双钥放款与风险抽查

### 1. 日常支出

小额、常规、已列预算事项：

- 执行官签押；
- 财计官签押；
- 即可支付。

不需要所有监察和法司部门事前批准。

### 2. 大额或高风险支出

以下事项增加第三钥：

- 超过专库季度额度20%的单笔支出；
- 军器采购；
- 大规模赈银；
- 新开港口和大工程；
- 涉及宗室、边镇和重要商团。

第三钥由内阁指定复核官或都察院承担。

### 3. 抽查比例

- 常规事项随机抽查20%；
- 高风险事项抽查50%；
- 出现异常指标时全查；
- 连续两季无异常，可降抽查比例；
- 连续出现账实差或举报，提升为专项审计。

### 4. 异常触发

任一情况触发全查：

- 账实差超过10%；
- 到账迟延超过10日；
- 单价高于周边30%；
- 同一商人连续中标；
- 军队、粥厂、工地的实收数与账面差异；
- 六耳与锦衣卫报告相互冲突；
- 举报两条以上且来源独立。

## 九、时限制度

| 事项 | 最长期限 |
|---|---:|
| 常规军饷、赏银拨付 | 10日 |
| 紧急赈粮、药材 | 3日先拨，10日补册 |
| 普通账目抽查 | 30日 |
| 重大贪腐初查 | 15日 |
| 证据移交法司 | 5日 |
| 普通案件结案 | 30日 |
| 重大通敌、军器泄密 | 60日内完成首轮会审 |
| 七、八品整改 | 1季度 |

超期必须写明是资源、协同、证据还是本人原因。

## 十、满意度、民心与腐败的正确考法

这些结果不再直接写成“本季必须上升5点”。

### 1. 满意度采用前置信号

军人：

- 饷银到账；
- 抚恤；
- 补给；
- 军功兑现；
- 无效伤亡。

官僚：

- 养廉到账；
- 职责清晰；
- 容错边界；
- 不乱兴大狱；
- 晋升有据。

农民：

- 粮价；
- 税役；
- 种子农具；
- 灾害救济；
- 军队扰民。

士绅：

- 不全面清丈；
- 捐输有荣誉；
- 新学和地方公共事务参与；
- 不被无证株连。

### 2. 腐败采用过程指标

- 账实差；
- 抽查异常率；
- 军饷与赈银到账率；
- 追回银两；
- 冤案率；
- 官商重复中标；
- 工程返修率；
- 举报查实率。

预期：

- 单季只能明显降低某一条线的腐败；
- 连续三至六季度，才期待国家腐败度稳定下降；
- 不用“多抓人”代替“钱粮真实到位”。

## 十二、国策实施步骤

### 第一季度

- 发布职位分类；
- 每人只设三项指标；
- 建立证据等级；
- 将所有旧考成表转换为新格式。

### 第二季度

- 启用两季度移动平均；
- 日常拨款改双钥；
- 六耳与都察院实行风险抽查。

### 第三季度

- 对异常部门全查；
- 清理重复审批；
- 统计迟延、账实差和冤案率。

### 第四季度

- 第一次年度总考；
- 评估制度是否降低虚报和迟延；
- 不以抓捕人数评价反腐成效。
