# 《诏书目标折损与季度验收 Scale v2》
## ——解决“诏书目标宏大、朝政纪要实际缩水”的系统化方案

> **用途**：为每一份诏书、国策和季度计划预先估算执行折损；在朝政纪要反馈后，用真实兑现率更新下一季度目标。
> **核心改变**：不再把所有任务统一上浮30%或50%，而是按任务类型、成熟度、资源、权威、满意度、腐败、并行项目和外部冲击分别计算。
> **最终目的**：让诏书既有雄心，又不逼迫系统和官员通过虚报来完成不可能的数字。

---

## 一、档案显示的执行规律

### 1. 成熟军工和扩编任务兑现率较高

档案中曾出现：

- 新军目标1.8万人，实际约1.76万人；
- 新军目标2.5万人，实际约3万人；
- 火铳目标2000支，实际2600支；
- 轻炮目标20门，实际26门。

说明已有厂、已有人员、已有原料和明确流程的任务，可能完成90%—120%，甚至超额。

### 2. 单一军事行动兑现率中等

例如破营、断粮、围困：

- 破营目标60处，实际45处，约75%；
- 断粮战略因任务集中而成功；
- 守城、清边、零遗炮等明确军事任务，往往比社会治理更容易兑现。

合理区间约65%—85%。

### 3. 招抚、归屯和民生恢复兑现率较低

例如：

- 归屯目标9000人，实际约4000人；
- 种子农具到账约80%；
- 新增裹挟虽下降，但经常无法达到上考数字。

合理区间约45%—70%。

### 4. 新制度第一季度兑现率最低

六年夏“三硬一成、七辅四成”，说明当灾害、改革、军务并行时，新制度的首季有效兑现可能只有35%—60%。

### 5. 满意度、民心和腐败不是线性任务

这些数值受以下因素共同作用：

- 皇帝权威；
- 官僚、军人、士绅和农民满意度；
- 战争伤亡；
- 灾害；
- 钱粮到账；
- 贪腐；
- 政策数量；
- 官员恐慌；
- 谣言和宣传。

所以不能把“满意度提高5点”当作一个部门可直接完成的产量目标。

## 二、四层目标口径

以后每一个指标都必须有四个口径。

### 1. 御前实得目标

陛下真正希望季度结束时得到的结果。

示例：

- 实际归屯1万人；
- 实际火铳产5000支；
- 实际取消1股叛军番号；
- 实际军饷到账率90%。

### 2. 诏令授权目标

考虑系统折损后，写入诏书、下达给执行人的授权数字。

计算：

```text
诏令授权目标 = 御前实得目标 ÷ 预计执行系数
```

但必须设上浮上限，防止数字虚高。

### 3. 预计实得

根据任务类型和当前国情，对本季最可能完成的范围进行估计。

### 4. 失败线

一旦低于该线，说明不是普通折损，而是方法、人员、资源或环境出现重大问题，必须转向。

## 四、修正系数

最终执行系数：

```text
E = 基础任务系数
  × 主攻集中系数
  × 权威系数
  × 执行群体满意系数
  × 腐败系数
  × 资源系数
  × 成熟度系数
  × 外部冲击系数
```

最后将E限制在0.25—1.15之间。

### 1. 主攻集中系数

| 任务地位 | 系数 |
|---|---:|
| 本季唯一主攻 | 1.15 |
| 两项硬支援之一 | 1.00 |
| 维持任务 | 0.85 |
| 额外新增项目 | 0.70 |

### 2. 皇帝权威系数

| 权威 | 系数 |
|---|---:|
| 0—39 | 0.85 |
| 40—59 | 0.95 |
| 60—74 | 1.05 |
| 75—100 | 1.10 |

### 3. 执行群体满意系数

按任务使用对应群体：

- 军事用军人和武勋；
- 财政行政用官僚；
- 地方治理用农民、官僚和士绅；
- 海贸用士绅、官僚和相关商贸势力；
- 新学用官僚、士绅与西学派。

| 满意度 | 系数 |
|---|---:|
| 0—19 | 0.75 |
| 20—34 | 0.88 |
| 35—49 | 0.97 |
| 50—69 | 1.03 |
| 70以上 | 1.08 |

多群体任务取加权平均，不取最高值。

### 4. 腐败系数

| 腐败度 | 系数 |
|---|---:|
| 0—25 | 1.05 |
| 26—40 | 1.00 |
| 41—60 | 0.90 |
| 61—80 | 0.78 |
| 81以上 | 0.65 |

注意：四权分管只能逐步改善这一系数，不能一季直接把腐败系数提高到1。

### 5. 资源系数

| 资源状态 | 系数 |
|---|---:|
| 严重不足 | 0.70 |
| 部分到位 | 0.85 |
| 基本到位 | 1.00 |
| 有专库且提前到位 | 1.05 |

资源必须按实银、实粮、实物和已承诺分别判断。

### 6. 成熟度系数

| 状态 | 系数 |
|---|---:|
| 首次启动 | 0.80 |
| 已运行1—2季 | 0.92 |
| 已运行3季以上 | 1.00 |
| 有连续成功记录 | 1.05 |

### 7. 外部冲击系数

| 环境 | 系数 |
|---|---:|
| 同时发生大战与大灾 | 0.70 |
| 一项重大冲击 | 0.85 |
| 一般扰动 | 0.95 |
| 局势稳定 | 1.00 |

## 五、上浮上限

不能无限用低执行系数反推极大诏令数字。

| 类型 | 授权目标相对御前目标最大上浮 |
|---|---:|
| 成熟军工生产 | 15% |
| 单一军事行动 | 35% |
| 军队训练改编 | 35% |
| 工程建设 | 30% |
| 招抚归屯 | 50% |
| 新制度首季 | 不设最终结果大数字，只设里程碑 |
| 情报准确率 | 每年提升不超过8—10个百分点 |
| 满意度、民心、腐败 | 不上浮，改用前置信号 |

如果计算结果超过上限，说明御前目标本身不适合在一季度完成，应拆成多个季度，而不是继续拔高诏书。

## 六、标准计算示例

### 示例1：火铳生产

御前希望实际获得5000支。

条件：

- 成熟生产：1.00；
- 本季硬支援：1.00；
- 权威70：1.05；
- 官僚满意40：0.97；
- 腐败35：1.00；
- 资源到位：1.00；
- 已运行多季：1.00；
- 无重大冲击：1.00。

```text
E = 1.00 × 1.00 × 1.05 × 0.97 × 1.00 × 1.00 × 1.00 × 1.00
  ≈ 1.02
```

诏令无需写7000支，只需写5000—5200支，另设5600支上考。

### 示例2：陕西归屯

御前希望实际归屯1万人。

条件：

- 社会治理：0.58；
- 本季唯一主攻的一部分：1.15；
- 权威70：1.05；
- 农民、官僚综合满意偏低：0.90；
- 腐败35：1.00；
- 资源基本到位：1.00；
- 已运行多季：1.00；
- 春荒疫病冲击：0.85。

```text
E ≈ 0.58 × 1.15 × 1.05 × 0.90 × 1.00 × 1.00 × 1.00 × 0.85
  ≈ 0.54
```

直接反推需要约1.85万人，超过50%上浮上限。因此不能把1.85万人写进诏书并以此问罪。

正确写法：

- 御前实得目标：1万人；
- 诏令授权目标：1.5万人；
- 预计实得：8000—1.1万人；
- 失败线：5000人；
- 额外要求：三十日留存80%以上。

### 示例3：新制度

御前希望“新九品制度有效运行”。

首季不写“腐败下降5点、官僚满意上升5点”。

只写里程碑：

1. 完成职位分类；
2. 所有官员只设三项指标；
3. 建立证据等级；
4. 完成第一轮评分；
5. 统计迟延、虚报和冤案。

第二、第三季再考制度结果。

## 七、底线、预计、上考和失败线

### 1. 底线

不是“最低可以随便交差”，而是御前真正需要的结果。

### 2. 预计实得

由Scale计算，供内廷预算和风险判断。

### 3. 上考

建议：

- 成熟任务：底线的115%—125%；
- 军事任务：底线的120%；
- 社会治理：底线的115%；
- 新制度：完成里程碑之外再出现实际结果；
- 不再统一上浮50%。

### 4. 失败线

建议：

- 成熟生产低于底线70%；
- 军事行动低于预计实得70%；
- 社会治理低于预计实得60%；
- 制度连基本建账、人员、流程都未完成；
- 出现红线事件，不论数量是否达标都判失败。

## 八、季度任务数量限制

每季最多：

```text
决定性主攻：1项
硬支援：2项
维持任务：3项
```

每项最多3个核心指标。

若诏书出现：

- 4个以上主官共同负责同一任务；
- 10个以上数字目标；
- 3项以上新制度；
- 同时要求军工、平乱、兴学、开海、反贪、修边全部大幅拔高；

则自动判为“政令拥塞”，所有额外项目的集中系数降至0.70。

## 九、反馈后的系数更新

每季度收到朝政纪要后，对每类任务计算：

```text
本季兑现率 R = 实际结果 ÷ 诏令授权目标
```

新的任务系数采用滚动更新：

```text
新系数 = 旧系数 × 0.60 + 最近同类兑现率中位数 × 0.40
```

限制：

- 单季调整不超过0.10；
- 使用最近4个同类任务；
- 极端战争和灾害季度单独标记，不直接污染长期系数；
- 虚报或数据冲突季度不进入更新。

为什么用中位数：

- 防止一个超额季度把未来目标抬得过高；
- 防止一个灾难季度把长期能力压得过低。

## 十、结果评价

实际结果不直接与诏令授权目标比较，而分三层：

### 1. 与御前实得目标比较

决定国家是否真正得到需要的成果。

### 2. 与预计实得比较

判断执行人是否在现实条件下尽责。

### 3. 与诏令授权目标比较

只决定是否达到上考和额外奖励，不作为普通问罪唯一依据。

评价：

| 情况 | 结论 |
|---|---|
| 实际 ≥ 授权目标 | 上考 |
| 实际 ≥ 御前实得目标 | 合格并有实效 |
| 实际 ≥ 预计实得但低于御前目标 | 执行合格，目标或资源需调整 |
| 实际低于预计实得但高于失败线 | 限期补效，查协同与资源 |
| 实际低于失败线 | 方法或人员有重大问题 |
| 触犯红线 | 不受数量成绩保护，依法查办 |

## 十一、满意度、民心与腐败的 Scale

### 1. 不写直接点数目标

错误：

```text
本季农民满意度提高5点。
本季腐败下降3点。
```

正确：

```text
春耕赏银到账率达到90%；
灾区粮价不超过常年1.5倍；
军队扰民案件低于10起；
抽查账实差低于8%；
官僚养廉银10日内到账；
重大冤案为0。
```

朝政纪要最终产生多少满意度、民心和腐败变化，由游戏系统综合计算。

### 2. 前置信号表

#### 军人满意

- 饷银到账；
- 粮草；
- 抚恤；
- 军功兑现；
- 无效伤亡；
- 是否频繁抽调。

#### 官僚满意

- 养廉；
- 职责清晰；
- 容错；
- 晋升；
- 是否兴大狱；
- 目标是否合理。

#### 农民民心

- 粮价；
- 税役；
- 赈粮；
- 春种；
- 军队扰民；
- 疫病和水利。

#### 士绅满意

- 财产安全；
- 不无证株连；
- 捐输荣誉；
- 新学参与；
- 地方负担；
- 是否突然清丈。

#### 腐败

- 账实差；
- 到账率；
- 抽查异常；
- 工程返修；
- 官商重复中标；
- 冤案；
- 举报查实；
- 追回银两。

## 十六、实施步骤

### 第一季

- 为当前诏书所有目标标任务类型；
- 写出御前实得、授权目标、预计实得和失败线；
