# 崇祯9年冬《定职清费援朝固藩安民续制诏》

奉天承运皇帝，诏曰：

九年夏秋，北疆严边清野、三层军制、军械实发、人才新学与陕西剿抚皆有实效。秋季王二、王嘉胤两股番号已销，高迎祥独存；全国军制四数核验尚只六七成，京西总厂主体约五成，须继续考成。今清军五万入朝，仁祖困守南汉山城并遣使求援，藩篱不可坐失，亦不可抽空关宁与宣大仓促决战。冬季以援朝固藩、完成军制第二季考成为主，以清理杂支、逐省民心不低于40、陕西结案为硬支援。26万两常赏仍为唯一季度常额；所有新增款必须明载性质、起止季度、总额、本季上限及结余归库。本季硬目标季末逐项报实际数、完成率和判定；无实际数者按未完成，不得以启动、推进、预计、待下季考成代替。

【军事】

命建极殿大学士孙承宗总协调全国军务，兵部尚书卢象升主三层军制、调动训练与援朝军令，杨嗣昌以兵部左侍郎兼文华殿大学士主情报预警；关宁、宣大、东江不得因援朝抽空根本。

1. 三层军制以秋季实际为基线，10日内完成全国每军账面、实点、可战、可立即调动4数核验至100%，并定1项主要军役、1项备用军役；重复入册、冒饷和无实兵军额全部剔除。东、中、西3个经制机动群30日内补齐铳、枪、车炮、骑兵、工兵、军医、运输修械，60日各完成1次冬季实兵合操；90日精锐池实际可战8.5万人、5日可调5.5万人为底线，上考9万人、6万人，绝不抽空关宁和各核心守口。
2. 秋季各军士气与补给未达累计提高5点者，冬季补足至秋季季初基线累计提高5点；已经达标者不得下降，低于60者再提高2点为底线、3点为上考。冬季不再重复拨100万两练兵启动款，只用秋季结余、军队维护费和正常弹药修械费；四数核验100%、训练通过率90%、逃亡哗变不增后，方准一次性绩效银最高5万两，季末归零。
3. 工部现有库存和冬季合格军械验收后10日内下发90%，其中50%给第一层机动军、25%给低装备守备军、15%给京营地方轮训营、10%战区周转。到营30日内完成实弹、车炮铳枪协同和维修教学，受援军训练通过率92%、军械可用率96%为底线，上考95%、98%；军械压库超过30日或只发不训者，工部与主将同判未完成。
4. 陕西由孙传庭总筹，曹文诏、秦良玉分追堵，洪承畴归屯，刘泽深审首恶。高迎祥部补给继续为0，45日内完成首领和老营合围，90日取消其最后独立番号，陕西旧五股至此全数结案；河南山西新万人级叛军为0。新增稳定归屯6000人为底线、7500人为上考，30日留存85%以上；季末报首领结局、实兵、降俘亡散、归屯、官军伤亡和军费实耗。
5. 援朝只取保王统、通海路、牵清军、阻兼并，不与清军在朝鲜平原决一死战。东江军选6000人袭辽南与鸭绿江粮路，登莱水师护运，东部机动群1.5万人集结山海、登莱待命，但未经孙承宗、卢象升双令不得渡海。援军主力损失不得超过两成，宁锦山海、蓟宣大核心关口零失守；朝鲜若局势不可守，优先接应王室、工匠、图籍和伤员至江华及海路安全区。
6. 黄得功继续任京营副总兵，90日完成北京京营2万人转役实点、到岗、训练和实务验收；可战轮训、工兵、转运、仓医、屯田养马5类均须报人数、任务、逃亡和满意度。不得停基本饷，不得以转役名义裁弱留强、侵吞空额。

【内政】

命中极殿大学士兼户部尚书毕自严总财政资源调度，工部尚书宋应星主军工、工程、农政水利，吏部尚书周延儒会礼部续办科举新学；冬季既清杂支，又以50万两一次性民心补效，使各省民心均不低于40。

1. 国库50万两设“冬季逐省安民补效专款”，仅限崇祯9年冬，季末自动终止，未用结余归库。分为粮价平粜与急赈20万、种子农具与以工代赈12万、疫病医药与寒衣8万、军队扰民及征用补偿5万、御前绩效备付5万。10日内逐省核定最新民心和主因；低于40者90日必须升至40，已达40者不得下降并净增2点为底线、4点为上考。任何一省低于40，全国目标即未完成，不得以平均数抵销。
2. 安民验收须同时见直接结果：红灯粮价3日内处置，赈粮、种具和补偿到账率95%，流民与非正常死亡逐旬下降，军队扰民案件较秋季下降10%、上考15%，侵田、欠饷牵连民户和重大冤案30日内审结。只发银而粮价、流民、治安和民心不动者，判为款项已拨而政策未生效，下季不得原样重复。
3. 户部30日内把季度杂项支出由332.1万两压至200万两以内，上考190万两，国库季度净结余恢复100万两以上。26万两常赏每季只列1份；秋季100万练兵为九年秋至十年夏年度总授权，冬季不重拨；20万防疫改为黄红黑灯触发，无事件支出为0；人才专项为年度50万总额，原则冬季最多动用结余或12.5万季度额度。已完成一次性项目下季归零，减支不得靠欠饷、停赈、停学或停修边防。
4. 京西军械总厂冬季主体工程达到70%为底线、75%为上考；在秋季火铳6000支、轻炮50门、红夷炮7门、修复旧械5000件实绩上，冬季合格火铳6300支、轻炮52门、红夷炮7门、修复旧械5500件为底线。合格率96%，军中30日返修率低于4%；生产、实发、训练、可用率四项缺一不得判军工达标。
5. 科举新学与军工人才延续一年考成，不新拨第二个50万两。周延儒总铨选，陈新甲副之，宋应星、卢象升定实务岗位；冬季合格结业并到岗1000人为底线、1200人为上考，其中军官不少于600、工匠不少于400，30日留任90%以上。军官须实际带训100营，工匠须合格制修1000件；只录取、入学而不到营厂者不计成果。
6. 各省实际播种土地仍逐省考核，每省冬季新增或复垦实播5万亩为底线、8万亩为上考，只计已下种、有水源、有人耕作且30日未弃耕之田。严寒或战区不能冬播者，须以整地、水源、种粮、农具和来春可播面积形成同等可验收成果，不许虚造冬播数字。各省分别报新增、复垦、归屯、商屯、灾毁、弃耕6数。
7. 主要阶层满意度继续逐层验收，官僚、军人、农民、士绅、市民、武勋较秋季实际净增2点为底线、4点为上考，任何一层不得下降。户部、吏部须分列常赏、升迁、军功、粮价、司法、扰民和改革冲击的正负作用，不能用党派或全国平均替代阶层实际值。

【外交】

命武英殿大学士兼礼部尚书来宗道总外交、互市、海贸与援朝交涉，杨嗣昌总情报复核，毛文龙、熊文灿、郑芝龙执行东江牵制与海路援朝；不承认清国对朝鲜的吞并权，不以援藩之名挑起无准备总决战。

1. 朝鲜使臣抵京后3日内受见，礼部明示大明保其王统、海路和抗清诸臣，但援助以实效为限。一次性援朝专款30万两，限九年冬至十年春，国库15万、内帑15万；军粮5万石、药材寒衣、火药铅子及工匠随船，30日首批抵江华或可控海港，60日形成登莱—东江—朝鲜海路，90日累计实到率90%以上。未用结余期满归库，不得滚为季度常额。
2. 军器援助以朝军可立即使用为准，先给合格火铳2000支、轻炮12门及90日弹药，另派军官、炮手、军医、修械工共200人教学；30日内受援朝军完成实弹和城防训练，合格率80%为底线、90%为上考。军器不得落入清军，局势恶化时转移或毁去关键部件。
3. 东江每月2次有效袭扰辽南与鸭绿江清军粮路为底线、3次为上考，重点焚粮囤、截船料、诱其分兵，不诱清军主力围岛。祖大寿暗线、六耳、锦衣及朝鲜边报须双源核验清军兵力、回师路线和粮道；重大情报准确率72%为底线、75%为上考，预警不得晚于清军行动前1日。
4. 张家口互市10万两旧额不增，继续7万守信、3万按拒向导、截马、拖粮和军情给付；不得因援朝切断全部蒙古商路，使清军独占马匹向导。硝铁、火药、铅料、军器、工匠和地图禁止出边，查获须报数量、主使、去向和判决。
5. 海贸以保障援朝、军工和财政造血为本。天津、登莱、淮安、温州、广州、泉州优先输入硫磺、铜铅、钢铁、药材、船材和钻镗量具；冬季海贸经常实收入库较秋季增长5%为底线、8%为上考。只签合同、仍在海上者不计到货；炮图、火药方、军制册和核心工匠外泄为0。
6. 援朝成败不以斩首计，季末以朝鲜王统是否保存、南部与海岛是否仍有抗清区、海路是否通畅、清军被迫分兵和后勤受损、明军主力是否保全为判定。若无法解南汉山城之围，须保存朝鲜王室与合法朝廷于海岛或南方，不得用全军殉一孤城。

【其他】

命即刻按六阁、六部权责重新登记，一职一主，阁掌方向总协调，部掌执行与考成；同一人兼阁部仅限同一政务线，不得再兼第三项冲突职掌。10日内完成官印、题本、预算、属官和未结事项交接，30日验权责运行。

1. 六阁定职：中极殿大学士毕自严，专国家总财政与资源调度；建极殿大学士孙承宗，专北疆与全国军事总协调；文华殿大学士杨嗣昌，专情报、预警与六耳总核；武英殿大学士来宗道，专外交、互市、海贸与北疆应变；文渊阁大学士李国普，专人事考成与官僚稳定；东阁大学士钱谦益，专江南财源、士绅安抚与学政。六阁不得越部直接发银、调兵、定罪或任官。
2. 六部定职：吏部尚书周延儒，左侍郎陈新甲为副，专人事、铨选、反贪与科举；户部尚书毕自严，专钱粮、四库、赏银和专项分账；礼部尚书来宗道，专互市、海贸和外交礼仪；兵部尚书卢象升，左侍郎杨嗣昌为副，专军队编制、调动、训练和边防；刑部尚书刘泽深，右侍郎沈演为副，专刑名重大案件，大理寺卿郑三俊专复核；工部尚书宋应星，左侍郎刘宗周为副，专火器、军工、工程、农政水利。
3. 专责不变：徐霞客任兵部职方司员外郎、六耳舆图测路副总，只测路核图不掌刑税调兵；王徵任辽海监军道，督水车、井渠、屯田和农具，不兼军饷军法；黄得功任京营副总兵，专京营转役试点；李若琏掌锦衣密核，专暗线验证，不自行定罪。其他与上述权责冲突的兼差全部撤销或转为单项协办，人员不因撤差即弃用。
4. 李国普会周延儒30日内完成所有高级官员兼差清单，逐人列正式主职、唯一主责、可保留协办、应撤冲突职、继任和档案移交。任何人不得同时掌同一事项的决策、拨款、验收和定罪；户部掌账不掌刑，刑部掌刑不掌账，工部造物不自行验收军中效果，兵部调兵不自行核饷。
5. 冬季九品考成以实际结果为准：援朝、三层军制、财政减支、逐省民心、陕西结案、军工实用、人才到岗各设主官、副官和证据责任人。因战争、严寒、疫病等外部冲击未达者，报保全结果后免罚补效；隐瞒、虚报、贪挪、扰民、越权和重复报功者从重。
6. 季末由内阁呈一页御前总表，固定列：朝鲜王统与援助实到、明军伤亡与边关、三层军制四数、陕西最后番号、杂项支出和净结余、逐省民心、各阶层满意、逐省实播、军工实产实发实训、人才到岗、官职交接。每项必须列基线、底线、上考、实际数、完成率、证据等级和判定；无实际数按未完成，不得以启动、推进、预计、待下季考成代替。
7. 所有冬季新专项均须写明性质、起止季度、总额、本季上限、触发条件和结余归库；临时总办仍依3年日落，每4季年考，满12季只能撤销、并入正式衙门、缩编为常设科司或有B级以上证据续3年，不得自动永久存在。

钦此。
