# 崇祯11年春《定部考官兴业通货改军御敌验收诏》

奉天承运皇帝，诏曰：

库档最新已执行实数止于崇祯10年秋：精锐可战8.2万人、5日可调5.2万人，训练通过率94%、军械可用率97%；15厂均已投产，然农具仅1.1万件，开垦48万亩、移民2.8万人未达底线；燧发枪三厂仅报开工，十年冬最终实数尚缺。故十一年春前10日，由毕自严、孙承宗会六部核清国库、内帑、厂产、税收、移民、军制与燧发枪实际，未核之数不得冒充基线。

今春以三军定制、六部补任、四总社实产实销为国本，以通货、科举、火器换代和辽东有条件破袭为支援。季末每项必须报投入、实际数、完成率、证据和判定；无实际数按未完成，不得以启动、推进、预计、在途、待夏季考成代替。

【军事】

命建极殿大学士孙承宗总筹全国军制与辽海，兵部尚书卢象升主编练调动，左侍郎杨嗣昌主六耳明核，右侍郎徐霞客主职方舆图；三军都督各守其责，不抽空宁锦、山海、宣大蓟真，不以纸面兵额冒充战力。

1. 全国军队定为三级：一级经制机动军，专跨区增援、野战与破袭；二级守备军，专守边墙、城池、港口、仓厂和炮垒；三级屯田工程后勤军，专屯田、工兵、运输、军医、仓储、养马和修械。一军一籍、一军一役，禁止三层重复列数。一级军采用战区—军—军团—师—旅—营编制，军衔与指挥职分开登记，文官品级及武勋世职不因军衔废改。

2. 皇明天枢第一军驻京畿，满桂为都督，从一品，军训“居中制外，临危不退”。下辖羽林军团秦良玉、应机军团孙传庭、定鼎军团曹文诏，各实额1万人，分别任宿卫外线、快速驰援和中央预备。非奉御前明旨不得擅离畿辅，亦不得沦为仪仗京营。

3. 皇明地维第二军驻宣大，左良玉为都督，正二品，军训“据险守土，进退有节”。镇朔军团曹变蛟、固塞军团左光先各实额1万人；靖边军团由虎大威任候任都指挥使，先保留番号，须实点1万人、可战9000、训练94%、军械可用97%、3个月粮饷到位且不抽空守备军，方准授旗。设监军御史，擅调兵、私募、纵兵扰民者封还军令并飞章奏闻。

4. 皇明人和第三军驻蓟辽，黄得功为都督，正二品，军训“诸军同令，水陆一心”。山海军团祖大弼、沧溟军团沈寿崇、合锋军团吴三桂各实额1万人，分别主山海宁锦陆防、东江登莱海运、关宁东江新军混编破袭。黄得功掌全军军令、旗号、军械、饷册和战功统一，不得长期兼领军团。三军总训“不恃天威，不弃地利，不失人和”。

5. 三军首季按8万人实额编成，余约2000人列直属炮兵、工兵、军医、运输和补员，须实点后确认。15日九军团主官到任，30日呈兵籍、编成、军衔、军饷、继任5册。90日一级军可战8.35万人、5日可调5.5万人为底线，上考8.45万人、5.7万人；训练95%、军械可用97.5%、核心关口失守0。新军春训1万人次，补给由68恢复至75、78上考。

6. 国库、内帑各拨20万两，合计40万两为军制改编一次性赏银；内帑另拨9万两，九军团主官各1万两专办磨合，均限十一年春、季末关账、结余归库。一级军正饷外加20%战训津贴，二级守备按守口绩效赏，三级军正饷不低于现额七成、屯田净收五成留营。正饷到账95%、伤员当日救治98%、重伤阵亡3日抚恤95%。

7. 燧发枪春季合格交付8000支、1万支上考，10日内下发90%，一级军优先70%。辽东四路袭库须祖大寿、六耳、锦衣三路情报达B级且内应、退路可靠，方准8000人行动；任一闸门不合即撤销，不得以改革之名轻掷三军。

【内政】

命中极殿大学士兼户部尚书毕自严总财政收益，工部尚书宋应星会左侍郎孙元化、右侍郎王徵总厂业技术；原“四局”改为四总社，王承恩总监章程与账册，不直接经营，各社总理掌经营、内廷监事掌账，户部审税、都察院审计。

1. 皇明丰稷农工总社，总理徐骥，承接陕西、山西、河南、四川、贵州农具厂；春季实际销售合格农具1万件，补足旧厂9000件缺口，产品售出率80%、工资实发95%，季末报销售额、成本、利润、税银和受益农户。

2. 皇明通济水机总社，总理李天经，承接湖广、陕西、河南水利工坊；春季实际安装水车、筒车等500架，灌溉受益15万亩、30日可用率92%。只出厂未安装、无农户签认者不计完成。

3. 皇明经武军需总社，总理汤若望，承接京西、宣府、天津、登莱诸军械厂；专管军械产销、质量与母机，不越兵部验军用。春季燧发枪、火炮、简易军需须分别报新造、改造、合格、返修、下发、实训和军中可用；核心图纸分段掌管，外泄为0。

4. 皇明寰海百货通商总社，总理熊文灿，承接广州、泉州、天津、淮安、温州等市舶与销售网络；春季实际引入洋银15万两、18万上考，实销货值15万两，须报货值、实税、护航成本和净收益。四社30日完成工厂、人员、设备、库存、债权和账册交割，不得重复计产、重复领款。

5. 四社春季合计实缴股本30万两，国资最多18万、商股不少于12万；90日实际销售30万两、净经营收益8万两、实缴税银3万两、新增稳定就业3000人为底线，上考销售36万、净收益10万、税银4万。春夏秋冬累计净收益底线依次8万、18万、29万、40万；首季无销售、无工资、无税银者按建制失败。

6. 通货三策照行：内帑3万两增宝泉局熔炉6座，春季铸合格新钱300万文、收兑劣钱150万文，成色重量合格95%；三口岸引入洋银只计实际入库；陕西、山西、河南粮银各半纳税先选30县核仓容、粮价和折算，秋后方试，不得加派。

7. 春季自愿实迁2.5万人、3万人上考，实到95%、30日留存90%；新增或恢复实播30万亩、灌溉15万亩、新增就业5000人。每厂、每社、每项迁民均须报投入、销量、利润、工资、税银和回本期；连续2季亏损或完成率低于60%，停止扩面并更换主管。

【外交】

命礼部尚书来宗道会左右侍郎倪元璐、何宗彦总互市、海贸与朝鲜，杨嗣昌、徐霞客核清廷物价商路，熊文灿、郑芝龙护航；外交须为四社销路、军工原料、通货和对清贸易战产生实数。

1. 张家口互市10万两旧额不增，7万守信、3万按拒作清军向导、优先供明和有效军情发放。春季实际购得马牛、皮革、粮种、药材须报数量、单价和损耗；使清廷同类采购成本再升5%、8%上考，至少少得军马500匹。

2. 天津、登莱、淮安、温州、广州、泉州扩大棉布、粮食加工品、农具、水机、药材、木料、皮革和非核心军需贸易。合规报关5日内、3日上考；商贸货值、海贸实税较核定基线各增8%、10%上考，合同、在途和预计到港不计。

3. 四社及军械厂所需铜铅、铁、燧石、钢刀头、硫磺和量具30日实到90%、95%上考；不得以炮图、火药方、钻镗法、军制册和核心工匠换货。完成2次诱饵测试和两路独立审计。

4. 朝鲜—东江—登莱海路连续90日不断，东江每月2次有效袭扰、3次上考，不打无准备的朝鲜平原决战。物资、伤亡、清军分兵、海路收益逐月报数。

【其他】

命六阁六部依“一职一主”完成正式任命。六部各设尚书1人、左侍郎1人、右侍郎1人、堂官6人，共54个核心职位；尚书定方向，侍郎分线执行，堂官办具体司务，任何人不得同时掌决策、拨款、验收和定罪。

1. 吏部：尚书周延儒，左侍郎郑三俊，右侍郎史可法；六堂官分掌文选、考功、验封、稽勋、考成稽核、养廉核发。户部：尚书毕自严，左侍郎王三善，右侍郎蔡懋德；六堂官分掌度支、仓场、盐铁、市舶、农政、通货。

2. 礼部：尚书来宗道，左侍郎倪元璐，右侍郎何宗彦；六堂官分掌仪制、祠祭、主客、精膳、新学科举、邸报。兵部：尚书卢象升，左侍郎杨嗣昌，右侍郎徐霞客；六堂官分掌武选、职方、车驾、武库、军制改革、三级军营务。

3. 刑部：尚书刘泽深，左侍郎方岳贡，右侍郎金光辰；六堂官分掌律例、审决、恤刑、赃罚、四权互核、锦衣协查。工部：尚书宋应星，左侍郎孙元化，右侍郎王徵；六堂官分掌营缮、虞衡、都水、屯田、军械总局、四社监督。原任与新任冲突者先交割，另补原缺，不许一人两占实职。

4. 上列侍郎由吏部推举、内阁30日审核、御前钦定后授职；各部尚书会左右侍郎于30日内提出六堂官实名、履历、唯一主责、继任和回避关系。未奉钦定不得先以“署理”长期占缺，堂官不得兼任所监管四社的经营总理或监事。

5. 九品中正制以清、勤、能、廉、实绩五条评定。一至三品发全额养廉，四至六品发七成，七至九品发五成；贪墨有据者停发并交刑部。季度养廉池10万两，其中国库5万、内帑5万，户部记账、都察院审计、内阁考成、司礼监复核，逐人报品级、应发、实发、扣罚和画押；该内帑5万为一年试行绩效池，十一年冬年考后撤销、并入或另旨续期。

6. 每季开军事、经济、农业三科特科，糊名誊录、殿前复试；每科录取120人、每季360人，并各择1名御前特荐官，共3人，由朕亲授90日实职权限。春季六部核心职位实任率95%、九品考成300人、特科到岗360人、御前特荐3人为底线；只录取不到岗者不计。

7. 三军都督、九军团主官、六部、四社和三科人才均入同一御前考成表。固定列基线、本季投入、实际产出、销量、利润、税银、军力、民心、完成率、证据等级和判定；无实际数按未完成。总考表由内阁呈奏，王承恩掌账监督不掌刑，李若琏暗核，法司定罪。

钦此。
