# 崇祯11年春《定部考官兴业通货改军御敌验收诏》

奉天承运皇帝，诏曰：

库档最新已执行实数止于崇祯10年秋：三层军制精锐可战8.2万人、5日可调5.2万人，训练通过94%、军械可用97%；新军经验33、士气85而补给68；15厂尽投产，但农具仅1.1万件，开垦48万亩、移民2.8万人均未达底线；燧发枪三厂仅报开工，税收、海贸及十年冬最终实数尚缺。故十一年春前10日，毕自严、孙承宗会六部先核十冬国库、内帑、迁民、厂产、税收、军制与燧发枪实际，未核之数不得冒充基线。

今定十一年为举国兴商、兴工、兴农与军政革新之年。春季以“实产—实销—实税—实收”建立可见收益为决定性主攻，以六部九品考成、三级军制火器换代为两项硬支援；辽东四路袭库只在情报达到B级、内应与退路均经双核后实施。季末必须逐项报投入、产量、销量、利润、税银、工资、粮食、军力、完成率、证据与判定；无实际数按未完成，不得以启动、推进、预计、在途、待夏季考成代替。

【军事】
命建极殿大学士孙承宗总筹三层军制与辽海，兵部尚书卢象升主编练和行动，左侍郎杨嗣昌主六耳明核，李若琏主锦衣暗核；不抽空宁锦、山海、宣大蓟真，不以纸面扩军冒充战力。

1. 全国军队定为一级机动、二级守备、三级屯田工程后勤。一军一籍、一军一役。春季以已确认精锐8.2万人编第一军驻京畿、第二军驻宣大、第三军驻蓟辽，按实点分配，不硬凑9万。一级军采用战区—军—军团—师—旅—营编制：军约2.4万至3万人，军团约8000至1万人，师约3000至4000人，旅约1000人；军、军团、师、旅分别由都督、都指挥使、指挥使、千总统带。30日呈编成、军衔、军饷、继任4册。

2. 90日一级军实际可战8.35万人、5日可调5.5万人为底线，上考8.45万人、5.7万人；训练通过95%、军械可用97.5%、核心关口失守0。二级军守口覆盖100%，不得擅离本防；三级军逐军报屯田、工程、运输、军医、仓储与修械实岗。新军春训1万人次、不同受训士卒6000人，补给由68恢复至75、78上考。

3. 待遇实行一年递进，不骤增永久军费。一级军春季在正饷外加20%战训津贴，年度总待遇达到现额1.5倍为底线、2倍为上考；二级守备维持正饷并按守口实绩赏；三级军正饷不得低于现额七成，屯田净收五成留营。正饷到账95%、伤员当日救治98%、重伤阵亡3日抚恤95%，无实数不得称军心已升。

4. 燧发枪换代先验京西、天津、登莱三厂。春季合格交付8000支为底线、1万支上考，其中新造6000、旧铳改造2000；10日内下发90%，一级军优先70%，30日完成实弹、雨雪击发和维修。宣府、太原、济南、武昌、广州、成都六线60日完工、90日试产；年度累计5万支为底线、6万上考。

5. 辽东行动以祖大寿、六耳、锦衣三路核验为闸门。若沈阳、辽阳、广宁、铁岭库存、换班、侧门和撤路均达B级，准8000人四路袭库，沈阳为主、辽阳广宁铁岭牵制，只夺粮草、甲胄、兵器、火药和战马，不占城；全程4时辰内撤。底线为夺毁粮草6000石、军械2000件、甲胄800副、火药3000斤、战马800匹，归队90%以上、伤亡低于12%；任一闸门不合即撤销。

6. 辽东暗线每季须报8处薄弱：军械2处、马场2处、粮仓2处、备用2处，每处列储量、守兵、换班、路线、内应与证据等级。十冬既有10万两情报专款先清余款，不得重复拨第二份；不得以不知情官兵或死囚作弃子制造假功，明暗两线只能用受控诱饵和自愿知情人员。

【内政】
命中极殿大学士兼户部尚书毕自严总财政收益，工部尚书宋应星、王徵总工业农业，吏部尚书周延儒总人才；所有发展项目一律同时报投入、销售、利润、工资、税银与回本期。

1. 10日内建立十一年春收益基线表：经常实收、季度经常支出、真实净结余、工业销售、商贸货值、海贸实税、实播粮产、工人与农户收入、移民留存、可战军力各核一数。春季经常实收较核定基线增长8%、10%上考；季度真实净结余不低于80万两、100万上考。一次追赃、卖库存和账面应收不得冒充。

2. 大明农器、水利机具、军需杂械、海陆珍货四局春季挂牌，户部工部兼领，国资51%至60%，商股40%至49%。春季实缴股本30万两，国资最多18万、商股不少于12万；年度国资追加须以订单、利润与税银为据。90日四局合计实际销售30万两、净经营收益8万两、实缴税银3万两、工资实发95%、新增稳定就业3000人为底线；上考销售36万、净收益10万、税银4万。农器局售合格农具1万件，水利局实装500架，军需局售1.5万件，珍货局实销货值15万两。

3. 四局年度累计考成：春季净收益8万、夏季累计18万、秋季29万、冬季40万为底线，年度上考48万；实缴税银累计3万、7万、11万、15万。首季若只有挂牌、无产品销售、无工资和税银，按建制失败；临时筹办差遣12季度日落，每4季年考。

4. 通货三策并行。内帑3万两增宝泉局熔炉6座，春季合格新钱300万文、收兑劣钱150万文，重量成色合格95%，京师与三口岸钱价差下降5%；天津、登莱、广州等口岸春季实际引入洋银15万两、18万上考，只计入库；陕西、山西、河南粮银各半纳税秋后试行，春季先选30县核仓容、粮价和折算，不得加派。

5. 春季自愿实迁2.5万人、3万人上考，实到95%、30日留存90%、90日留存85%；对应落地实田18万亩、来春可播20万亩。全国新增或恢复实播30万亩、灌溉受益15万亩，农具实发1万件、水车实装500架，抽样农户粮银收入提高5%、8%上考。强迁、拆户、抽独子为0。

6. 秋季15厂须连续生产60日，产品售出率80%、工资实发95%；农具缺口9000件先补。春季全部工业实际销售较十年秋可核基线增长10%、税银增长8%，新增就业5000人。每厂须报销售减原料、工资、运输、维修、税费后的净利润；连续2季亏损或无销量，停止扩建。

7. 艺学局春季设京西、天津、登莱、宣府、太原、济南6分校，在学3000人，90日实训到岗1000人。火枪、炮学、炼铁、测绘、水利、算学分科；只入学未实作不计。发展专项春季中央新拨不得超过60万两，所有年度授权不是每季重复拨款。

【外交】
命武英殿大学士兼礼部尚书来宗道总互市海贸，杨嗣昌、徐霞客核清廷物价商路，熊文灿、郑芝龙护航；外交以引银、争原料、扩销路、抬高清廷成本为实绩。

1. 张家口互市10万两旧额不增，7万守信、3万按拒作向导、优先供明和有效军情发放。春季实际购得马牛、皮革、粮种、药材须逐项报数量、单价、损耗；使清廷同类采购成本再升5%、8%上考，至少少得军马500匹，须有商报、互市册与暗线互证。

2. 天津、登莱、淮安、温州、广州、泉州扩大棉布、粮食加工品、农具、水利器械、药材、木料、皮革和非核心军需贸易。合规报关5日内、3日上考；春季商贸实际货值较核定基线增长8%、10%上考，海贸实税增长8%、10%上考。合同、在途和预计到港不计。

3. 四局及九座燧发枪厂所需铜铅、铁、燧石、钢刀头、硫磺和量具优先通关，原料30日实到90%、95%上考；不得以炮图、火药方、钻镗法、军制册和核心工匠换货。完成2次诱饵测试、两路独立审计，零外泄必须有实数证据。

4. 朝鲜—东江—登莱海路连续90日不断，保王统、商路和军情，不打无准备的朝鲜平原决战。东江每月2次有效袭扰为底线、3次上考，只断粮路和船料，不诱清军围岛；物资、伤亡、清军分兵和海路收益逐月报数。

5. 海贸与互市新增净收入三成可留作下一季四局周转、移民和春耕，但须报新增净收入、留用上限、实拨和结余，不得自动形成新的季度杂项常额。

【其他】
命六阁六部沿一职一主运行，十一年春完成六部九名核心主官定额、九品中正考成、季度特科与御前亲授；阁定方向，部负执行，任何人不得兼掌决策、拨款、验收和定罪。

1. 六部各设尚书1、左侍郎1、右侍郎1、堂官6，共54职。吏部尚书周延儒，六堂官掌文选、考功、验封、稽勋、考成稽核、养廉核发；户部尚书毕自严，掌度支、仓场、盐铁、市舶、农政、通货；礼部尚书来宗道，掌仪制、祠祭、主客、精膳、新学科举、邸报；兵部尚书卢象升、左侍郎杨嗣昌，掌武选、职方、车驾、武库、军制改革、三级军营务；刑部尚书刘泽深，掌律例、审决、恤刑、赃罚、四权互核、锦衣协查；工部尚书宋应星，掌营缮、虞衡、都水、屯田、军械总局、四局监督。原任侍郎先暂署交接，30日由吏部推举、内阁审核、御前钦定，核心职位实任率95%、100%上考。

2. 新九品中正考成以清、勤、能、廉、实绩为准，不以门第党名。春季先评六部54职、督抚总兵及重点府县官共300人，全年累计1200人。1至3品发全额养廉并备升，4至6品发七成，7至9品发五成并限改；贪墨有据者停发交刑部。季度养廉总池10万两：国库5万沿用26万常赏中的既有养廉份额，内帑5万为十一年度临时绩效池，冬季总验后撤销、并入或另旨续期。30日实发率95%，逐人画押。

3. 每季开军事、经济、农业三科特科，每科录取120人，每季360人；各科第一名共3人入御前殿问，由朕亲授90日试任权限。军事官须有带训、后勤、筑城、火器或测绘实绩；经济官须有增收、厂贸、通货或审计实绩；农业官须有实播、水利、屯田、畜牧或种艺实绩。春季录取、到岗率90%，三名特荐官90日各交一项实际成果。

4. 六部改制、九品考成、四局和三级军制均以一年四季考成：春季建基线并见首批产出，夏季累计45%至60%，秋季70%至85%，冬季100%；上季完成率低于80%冻结下季30%额度，连续2季低于80%停止扩面。临时机构每4季年考、12季度日落。

5. 季末御前收益总表固定列：国库内帑、经常实收支出和净结余；四局与各厂投入、产量、销量、利润、工资、税银；洋银、通货、实播粮产、移民留存与家庭收入；六部54职、九品、养廉、科举特荐；三级军队、可战可调、训练军械、军饷抚恤；辽东行动和情报。每项列基线、底线、上考、实际、完成率、证据等级和判定。

6. 十一年年度底线：军事综合能力提高30%、政治行政提高30%、经济综合提高35%；上考分别40%、40%、45%。任何百分比必须有明确分子、分母和实数，不能靠扩军、加税、一次大赏或账面估值冲高。无实际数按未完成。
