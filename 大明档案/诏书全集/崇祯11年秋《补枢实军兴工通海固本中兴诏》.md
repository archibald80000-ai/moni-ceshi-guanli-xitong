# 崇祯11年秋《补枢实军兴工通海固本中兴诏》

奉天承运皇帝，诏曰：

十一年夏，毕自严薨逝，首辅、中极殿大学士、户部尚书三职空缺，财赋执行减速。三军仅实补战兵8000、辅兵7000、侦骑800，期末总实点及五日可调、训练、军械均无全数；靖边未授旗，九级军阶未成闭环。四总社销售25万至28万两、净收益6万至7万两，连续两季未达；辽东夺马750匹、军械3800件、焚粮3200石、归队89%，有战术之功而未达底线。山陕豫鼠疫死亡6.8万人，屯田百万亩仍无实耕实数。今秋以“三军九团实名实编、实装实训”为决定性主攻，以补财赋中枢、四社军工与通海收益收口为两项硬支援；水泥建筑、皇家琉璃、辽东暗线皆限量试办，不得挤压主轴。

凡朝臣密议所列腐败为0、皇权98、满编99%、税收翻倍、十年琉璃一万万两等，均属方略假设，不得当作本季事实。季末必须报实际数、完成率、证据和判定；无实际数按未完成，不得以启动、推进、预计、在途、编制或库存估值代替。

【军事】

命建极殿大学士孙承宗总裁秋季军政，兵部尚书卢象升总领三军实编，杨嗣昌核军阶、饷册与情报，徐霞客核马政、军械、舆图；满桂、左良玉、黄得功对本军实点与质量具结，九军团主官逐团受考。

1. 天枢、地维、人和三军最终定额为战兵9万、辅兵4.5万、直属侦骑5000，总额14万，不得写作15万。10日内逐营核清现有实数；90日实点战兵8.7万、辅兵4.2万、侦骑4000为底线，上考8.9万、4.45万、5000，冬季再总验14万。原京营、关宁、地方守备被抽调后实守兵力下降不得超过2%，不得以老弱、民夫、一人两籍充数。

2. 羽林秦良玉、应机孙传庭、定鼎曹文诏、镇朔曹变蛟、固塞左光先、山海祖大弼、沧溟沈寿崇、合锋吴三桂各以战兵1万、辅兵5000为最终编制，秋季合格满编率95%、上考99%。虎大威之靖边军团30日验实：战兵1万、可战9000、训练94%、军械97%、3个月粮饷全具方授旗；任一不具则仍为候任并更换整训方案，不得强授。

3. 三军训练通过率96.5%、军械可用98.5%、正饷到账98%、新军补给由71升至76、79上考；九团各完成1次线列步兵—长枪—火炮—骑兵合操。轻炮540门、红夷炮105门、可用战马3.2万匹须实际到营并完成试射、骑乘与维修。库存有数而未到营，不计军力。

4. 秋季合格燧发枪新造改造5000支，使三军实配9000支；甲胄新交6000副，优先天枢及合锋，辅兵以棉甲皮甲过渡。另试制线膛枪20支、机动野战炮6门，须有试放、故障和返修实数。库存红夷炮186门已足105门定额，不准再以10万两造500门；该款改作炮车、药弹、试放和旧炮修复。

5. 九级军阶秋季完成全国实名册100%，首批武备到学1170人中毕业合格1040、试任到岗936为底线。军阶与实职分离，5次有效记功升1级；季度赏银仍以15万两为硬上限，按实名、实辖、评分直发。单位按任务30、训练20、军纪15、伤亡10、饷械15、数据10评分；个人以单位60%、专项25%、廉洁15%定等。

6. 祖大寿须先报军械2、马场2、粮仓2、备用2共8处乙级以上目标。若内应、退路、援军预警三路齐备，黄得功总领、吴三桂率合锋短袭，沈应时导路、黄蜚海接；底线夺马800匹、军械4200件、焚粮3500石，归队91%、伤亡低于10%，上考900匹、5000件、4000石、归队94%。情报不足即取消，只准截硝、误调与烧运具；不得以死囚或不知情人员制造假功。

【内政】

命王三善升中极殿大学士、首辅，总财赋与屯田；蔡懋德升户部尚书，李含乙、张慎言分任左右侍郎。4人10日内交印分权：首辅定总额，尚书管执行，左侍郎管仓田，右侍郎管税审；不得一人兼掌拨款、经营、验收与定罪。

1. 10日内核清夏季三军50万、武备10万是否国库内帑重复列支，民心安抚30万与分项35万之差，并报国库、内帑、经常收入、经常支出和真实净结余。秋季经常收支净结余100万两、120万上考；专项审计实际节省20万两、30万上考。未核清前不恢复冻结的176万旧自动授权。

2. 王三善会13省、卫所补交屯田总册：清册100万亩、抽验10%、验实率90%、实际在耕80万亩为原底线，秋季不得抬高；三级屯田军3.2万人须统一“陕西或辽东1.3万”冲突并报实岗95%。每户田30亩、种1石、农具1副、口粮30日、3年免赋，田无人或未播不得计亩。

3. 四总社继续冻结扩张30%，先按社独立结算。秋季合计实销30万两、净收益8万、实税3万为底线，上考36万、10万、4万；丰稷实销6万、通济5万、经武8万、寰海11万，各报成本、工资、库存、应收、利润与税。军需内部划拨只计节省采购，不得冒充销售；连续3季未达者冬季撤换总理或并社。

4. 军工一次性50万两限秋季：20万建1座燧发枪厂，15万扩甲胄工坊与民间合格外协，10万攻关线膛枪、野战炮与火药化工，5万补炮车药弹。60日厂房设备验收，90日报合格产出、单位成本、工资和事故；不再重复新建库存已充裕的普通火铳厂。

5. 全国26处水泥建筑列年度总册，秋季只准使用60万两完成急要12处：京西军械、两京武备、登莱船坞、两淮盐仓、潼关军仓、杭州货仓、广州码头、都江堰渠、山海关炮台、湖广漕仓、贵州驿屯；其余14处只准勘址、预算和备料。完工须报工程量、使用率、运输或维修成本下降，只有砖瓦无效益不计功。

6. 皇家秘造琉璃总厂为首季试办，依工部与寰海总社，不另立永久衙门，12季度日落。内帑上限5万两，建精品窑20座，60日落成、90日试烧；底线合格透明器50件、彩色器100件、实销3万两、净收益1万两，外泄0。不得以禁民生计、拘禁匠户、虚定千两价格冒充收益，价格以实际竞售为准。

7. 山陕豫鼠疫由钱谦益、王三善、方岳贡分责，条件触发银不超过20万两。秋季死亡压至3万人以内、2万上考；军营辅兵疫损降60%，红灯县3日设隔离、净井、药棚和粮站。只报政策不报病例、死亡、病床、药材者按未完成。

【外交】

命来宗道总海贸互市，倪元璐主邸报商情，何宗彦主藩属规制；熊文灿只任寰海总社总理，福建巡抚须10日内交由专任官，不得地方行政与企业经营双实职。

1. 广州、泉州、天津、淮安、温州五市舶司正式按统一税票开市，登莱保留军港兼报关。秋季六口实际海贸实税20万两、22万上考，商贸货值较夏季增长10%、15%上考，平均报关3日；须同时报货值、实税、退税、欠税、护航与损失，合同和在途不计。

2. 天津、淮安、温州3港秋季实税合计不低于6.5万两，全年累计以25万两为底线；长芦、山东、浙江3盐场严缉私盐，秋季新增实课5万两、8万上考。官收官卖只限法定盐课，不得借缉私侵吞民盐或重复征税。

3. 张家口互市10万两旧额不增，购得合格战马1000匹、耕挽畜1500头，运输损耗低于8%；使清廷同类采购成本再升5%、8%上考。互市、太仆寺、三军马册三账互核，同一马匹不得重复记功。

4. 沧溟军团与登莱、福建、广东水师分区护航，朝鲜—东江—登莱海路90日不断；毛文龙每月2次有效袭扰，黄蜚逐船报运量、损失和清军分兵。港口巡逻只续原维护费，不再另设重复常额。

5. 琉璃、军械和四社产品只以成品外销，炮图、火药方、钻镗法、军制册、母机和核心匠师不得出境。完成2次诱饵测试、两路独立审计；发现泄密须报源头、损失与处置，不得只报“零”。

【其他】

命内阁设“十一年秋中兴总考册”，以实际军力、净收益、实耕、疫损和行政效率收官，不以权威、满编、腐败等未经本季实测的假设代替。

1. 王三善、蔡懋德补财赋中枢后，六部54席正式实职恢复100%。杨嗣昌只掌阁中情报总核与兵部军情，不再兼具体六耳科务；徐霞客只掌武选、马政、舆图；孙元化在工部与山东巡抚二职中择一；孙传庭、曹变蛟、满桂、左良玉、祖大弼、黄蜚、熊文灿等10日内完成主职、代理与交割表，双实职未解不得上考。

2. 九级军阶只是功勋考核，不替代文武官品。卢象升按战区统帅9级候考，三军都督8级，军团主官7级；实际统兵不足定额者保留军阶但不得领满额实职赏。秋季每名军官固定回填姓名、军阶、实职、实辖、单位分、个人分、等次、记功、赏银与处分。

3. 春夏特科累计720人须报到岗、90日实绩与去留；秋季再录360人、御前特荐3人。武备毕业与文官特科不得重复占岗，录取未到任不计完成。

4. 所有一次性项目季末关账：军工50万、建筑60万、琉璃5万、密赏5万、条件防疫20万。完成率100%且产生军力、销售、税银、节支或减亡者，冬季最多扩20%；80%至99%维持；60%至79%冻结30%；低于60%停止扩面并换主官。

5. 兵部、户部、工部、四社、锦衣、六耳、地方督抚各报一册，内阁合为一表。每项列基线、底线、上考、投入、实际、完成率、证据等级和判定；同一兵、械、马、厂、货、税不得跨册重复。虚报一项，相关主官本季九品或军阶考成直接不合格。

钦此。
