# 崇祯三年夏《防蝗剿寇核账肃贪诏》

- 时间：崇祯三年夏
- 状态：已执行并据夏季朝政纪要归档
- 归档说明：本诏承接崇祯三年春《勤王定陕修渠防蝗通商核账诏》。本季主线为江南防蝗、陕西剿寇、京畿肃贪、九边验饷，并延续东江五策、蒙古互市、东南海贸分账。夏季纪要显示：陕西旱极而蝗，起义军总兵力约五万五千九百二十一人；江南翻耕覆盖率升至五六成但未达七成；京畿肃贪追回约二十万两；腐败度由七十七降至七十五；阉党满意度因魏忠贤三十日凑五百万两之令暴跌。

奉天承运皇帝，诏曰：

【军事】

命孙传庭总督陕西剿寇，曹文诏扰王二老营，秦良玉守商洛粮道，六十日内封米脂、断贼粮、招胁从、剿悍首。

陕西旱荒未息，王二、王嘉胤、高迎祥、李自成诸贼因饥民裹胁而日炽，若止剿不赈，则饥民复投贼；若止赈不剿，则悍首乘赈养势。今孙传庭持尚方剑坐镇西安，专司军务；曹文诏率精骑二千，昼夜扰王二老营，不许孤军深入，不许贪首级轻战；秦良玉率白杆精兵三千守商洛、蓝田、武关诸道，截高迎祥、王嘉胤南下就粮之路；孙传庭自领中军五千，俟贼疲粮绝，合曹、秦二军围击。李自成新据米脂，榆林参将仍以本镇兵一千五百封其四路，许困不许纵，许招不许乱攻。

工部即拨火铳五百杆、轻型火炮十门、火药三千斤、铅子一万发入陕，宋应星造器械册，五日一报兵部；洪承畴从陕西四仓拨粮八千石，专供剿寇军两月之用，另于渭南、咸阳、宝鸡设粥厂三处，降众弃械者给三日粮，验无杀官焚仓之罪，老弱遣归，青壮编屯。汉中、凤翔、平凉三府各出民夫三千修关设卡，工钱从赈银支给，不许白役。河南巡抚严守潼关、陕州，防流贼东窜入豫。

六十日为限：米脂仍封、王二粮道断、高迎祥不得南掠、降众入册三千以上，为有功；杀良冒功、纵兵掠民、克扣军粮者，将官降三级，首犯斩。若粮饷火器迟误，卢象升会都察院逐册追问，不得独罪前线。

【内政】

命温体仁、史可法分督江南防蝗，毕自严筹银，宋应星、徐光启督工，六十日内踏滩、翻耕、掘卵、修渠、备器，务使南直隶、浙江、江西秋蝗不起。

江南洪涝方退，滩涂湿热，蝗卵潜伏，若今春夏不治，则秋后飞蝗蔽天，漕粮、市舶、棉纺、瓷业俱伤。今以南直隶归史可法督催，浙江归温体仁督催，江西责成巡抚魏照乘督催；每路设巡蝗官十员，逐县踏勘，造三册：滩涂册，记亩数、业主、蝗卵密度；翻耕册，记雇夫、亩数、掘卵斤数、所费银两；考成册，每十日分上中下三等直达御前。

前拨防蝗水利银十万两仍专款专用，南京户部再暂借银五万两，秋后以罚银、市舶税、工税余入分年归还。宋应星刻印《捕蝗要术》一千册，分发各县；每县备捕蝗网五百面、蝗蝻袋一千只、火把三千束，器具实数入册。十五日内踏勘毕，四十五日内翻耕七成，六十日内沟渠、圩堤、捕蝗器械俱备。士绅商户愿出银雇夫翻耕、修渠、备器者，所出银两折半计入助赈捐输，准减沿海工商费一等；阻挠踏勘、隐匿滩涂者，百亩以下罚银二十两，百亩以上五十两，千亩以上百两并枷号三日。

地方官不得借防蝗加派田税，不得强征夫役，不得侵吞工本。侵银十两以上革职追赔，百两以上下刑部重治。三限俱达者，知县记功；翻耕九成以上者赏银五十两。秋后蝗灾大起而册内无实工者，督臣、巡抚、知府、知县分等问责。

【外交】

命来宗道续通察哈尔互市，毛文龙守东江五策，熊文灿护东南海贸，三月内保粮路、保商路、保东江牵制，不许后金借蒙古再入边。

己巳之变，祸起蒙古借道。察哈尔互市常额十二万两、军情赏格三万两仍照册支给，但须以实到为功，不以出库为功；土默特能转运茶绢盐引至林丹汗残部者，按脚价给赏；科尔沁、喀喇沁有报后金路线、拒为向导者，许马市优先、小额银赏；再为后金前驱者，闭市夺引。不得给蒙古火器、火药、甲胄，不许边将擅出塞争功。

毛文龙东江镇仍为制辽侧翼，每月报兵、船、粮、火药、屯民、细作六册；遇后金西顾，许小股袭扰辽南粮囤、船械、盐铁转运，不求首级大捷，只求牵制其归路。袁崇焕不得擅并东江，不得擅杀毛文龙；争议由孙承宗、卢象升、李国普会裁。朝鲜铁山、义州仍许东江水师停泊取水、递送边报，不责其出兵，不得索其粮饷。

熊文灿核郑芝龙船册、人册、炮械册、税册，广州、宁波、泉州、漳州、福州五口市舶与护商修渠费分账，不得混收。郑部护商船每季二十艘，护粮税船不许私设税卡，不许私售硝磺铁器与后金。海贸税不断、东江小饷不断、商讼不增者，主办官记功；借护商勒索者，下刑部。

【其他】

命王承恩、李若琏督京畿百里肃贪，房壮丽、史可法审账，袁可立定罪；魏忠贤所供江南线索只作密核，不许其南下独办扰民。

王承恩持节督办京畿百里查抄，锦衣卫北镇抚司出缇骑二百，分四路锁拿阉党余孽侵饷者、东林乡宦隐田者、地方豪绅侵赈者、军卫将官克饷者，凡已有实证十七犯，七日内拿获，十五日内会审，三十日内赃银入库。赃银七成解陕西军饷与赈灾，二成补国库，一成支查案脚价。查抄止于实证人犯，不许借案株连门户，不许夜入民宅，不许拷掠取供；走漏风声致犯逃者，领队革职拿问。

魏忠贤所奏苏松常隐田、盐引、织造旧账，准作线索，不准其持勘合南下独办。东厂理刑百户杨寰、掌刑千户孙云鹤若确熟底册，只许在京师内廷账房供辨旧档，受王承恩、李若琏节制；锦衣卫刘侨选精干校尉三十名，亦只可随巡按御史密核盐引、织造、鱼鳞册副本，不得以夜巡为名暗清民田，不得封田抄宅。江南七府仍行一年密核，查账不查钱，封册不扰民；凡隐田过千亩、侵税过万两且三册互证者，列秋后会审，不许夏季骤然清算，以免士绅惊扰、防蝗失效。

毕自严所议四权分离，准即行：户部出纳记账，都察院审计核查，内阁评定考绩，司礼监复核存档；四册不符者，刑部追查。吏部以钱粮征收、仓储实数、有无侵挪、辖内民变四项考核州县，连考劣者降调，优者升迁。军饷验发先在关宁、宣大、蓟州试行直发到营，卢象升总督验饷，御史监发，厂卫旁验不得干预军务。贪墨军饷百两以上者重治，主动自首退赃者减等。此诏所列剿寇、防蝗、肃贪三事，每十日一报，六十日廷核，实绩者升赏，虚报者降调，扰民误国者重治。

钦此。

## 执行反馈摘要

- 陕西剿寇：孙传庭持尚方剑坐镇西安，工部火器入陕，洪承畴拨粮八千石，渭南、咸阳、宝鸡粥厂设立；但军人满意度仅十八，四镇出兵积极性低，官军仅约九千至一万人，对约五万五千九百二十一名起义军难以重创。
- 陕西灾荒：陕西旱极而蝗，粮食产量再降约二至三成，陕西民心由二十七降至二十二，动乱风险升至九十二；王二、王嘉胤、高迎祥、李自成继续裹挟饥民，张献忠新起约二千五百人。
- 江南防蝗：温体仁督浙江、史可法督南直隶、魏照乘督江西，追加南京户部五万两，翻耕覆盖率由三四成升至五六成，未达七成目标；秋季蝗灾概率降至中等但未消除。
- 肃贪反腐：京畿百里肃贪十七犯，追赃约二十万两，腐败度由七十七降至七十五；但魏忠贤三十日变产五百万之令导致阉党满意度降至三十五、叛乱风险升至五十五。
- 验饷与制度：卢象升兼九边验饷总督，关宁试行直发到营，关宁军士气升至七十、忠诚升至七十九；武勋满意度因克扣空间被压缩降至四十八。
- 长期风险：后金启动火炮获取计划；陕西免税将于崇祯三年冬到期，若恢复税率，可能引发民心崩溃与复叛。
