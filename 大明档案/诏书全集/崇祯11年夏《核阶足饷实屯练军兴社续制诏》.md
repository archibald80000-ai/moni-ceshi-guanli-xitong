# 崇祯11年夏《核阶足饷实屯练军兴社续制诏》

奉天承运皇帝，诏曰：

十一年春三军九团框架已立，八个军团实额8万人，靖边尚未授旗；然实际可战8.2万人、5日可调5.2万人、训练94%、军械97%、新军补给68，九军团五册仅成八九成。六部尚书侍郎到任而54席实职率仅85%至90%；四总社销售18至22万两、净收益3至5万两，未达原定；辽东两路夺马650匹、焚粮1800石，明军伤亡650人。故今夏不以建制名目冒充中兴，以“九级军阶考到人、三级军制考到军、百万屯田与军饷保障落到户营”为决定性主攻，以武备扩招、燧发枪列装和四社收益整改为两项硬支援。

所有春季未达项目先补原底线，达标后方准扩张。季末必须报实际数、完成率、证据和判定；无实际数按未完成，不得以启动、推进、预计、在途、待秋季考成代替。

【军事】

命建极殿大学士孙承宗总裁夏季军政，兵部尚书卢象升总负三层军制、补员、军阶与战备；杨嗣昌主饷册、九级实册和六耳核验，徐霞客主武选、马政、军械与舆图。春季可战8.2万人、5日可调5.2万人、训练94%、军械97%、新军补给68，皆为夏季实际基线，不得用原目标替代。

1. 90日一级军可战8.4万人、上考8.5万；5日可调5.6万人、上考5.8万；训练96%、军械98%、核心关口失守0，新军补给升至75、78上考。满桂负责天枢3万人：羽林秦良玉完成京畿4线合操，应机孙传庭做到3日先遣5000、5日全团出动，定鼎曹文诏保持30日满饷满械。左良玉负责地维2万人，镇朔曹变蛟、固塞左光先守口、互市、仓马；虎大威之靖边须实点1万、可战9000、训练94%、军械97%、3月粮饷到位方授旗。黄得功负责人和3万人，祖大弼、沈寿崇、吴三桂分别验陆防、海路和混编破袭，三军五册30日补齐100%。

2. 五十万两为三军结构调补一次性专款，不增加全国纸面兵额。90日战兵实点8.4万、辅兵3.5万、专职侦察骑兵2000为底线，上考8.5万、3.8万、2500；兵源限现有京营、都卫、归屯军和军中转类。30、60、90日逐团报实到、实训、实配马械。无马、无铳、不会绘图者不得计侦察骑兵。

3. 北京武备学堂扩至500人、南京400人，宣府、大同、蓟州、登莱各设100人速成班，每期3个月，内帑一次拨10万两。30日四班开课、60日两京扩建完成、90日到学1170人为底线、毕业合格1040人，武备毕业授3级候补，试任90日方转正式。

4. 九级军阶依统兵10、50、100、500、1000、5000、1万、3万、10万人能力登记，军阶与实职分离。60日实名册覆盖80%、90日覆盖90%；上等不超过同级10%，5次有效记功升1级，连续2季下等停候补、3季下降1级。单位考成按任务30、训练20、军纪15、伤亡保全10、饷械15、数据10计分；主官个人以所辖单位60%、本人专项25%、账实廉洁15%计分。季度军阶赏银上限15万两，按既定九级上中下表直发画押。

5. 陕西四镇积欠及罚银合计15万两，蓟州、真保、山海、宁远各5000两，东江6.2万两，均30日到营。设九边军饷保障库每季20万两，张懋德、周遇吉共掌，杨嗣昌饷册核验司独核；月造三册，克扣虚冒从军法。

6. 辽东不得因春季小胜盲目扩战。祖大寿先报8处乙级薄弱点；三路证据、内应、退路、援军预警齐备后，黄得功总领，吴三桂率合锋1万人，沈应时导路、黄蜚海接：广宁夺壮马900匹为主，沈阳兵器库取军械5000件，辽阳取军械2000件、焚粮4000石，沈阳粮仓纵火即撤，开原马场只作备选。归队率90%以上、伤亡低于12%，不攻坚城、不追溃兵；任一情报低于乙级即撤销。

【内政】

命中极殿大学士兼户部尚书毕自严总财政，户部左侍郎王三善主全国屯田，右侍郎蔡懋德主税收通货；工部宋应星、孙元化、王徵分负军械、农器水机和工程，吏部周延儒、郑三俊、史可法补官考成。

1. 王三善会13省布政使司、卫所，90日逐亩逐户造全国屯田清册，总额不少于100万亩；其中验实率90%、实际在耕80万亩为底线，上考90万亩。三军辅兵、军眷、移民和粥厂遴选屯户一体入册，每户田30亩、种子1石、农具1副、口粮30日，近堡荒地3年免赋。都察院分路抽验10%，虚报亩数以欺君论。

2. 第三级屯田工程后勤军核定3.2万人：陕西1.3万、晋豫6000、北直山东8000、川湖广5000。10日内由卢象升、王三善具名屯田总兵候选3人呈御前；地方文官豪绅退出营官，千总以下须经武备考核。孙传庭、曹文诏调退伍骨干补陕西；宋应星、王徵和太医院分别派工兵、军医教习。90日四类营实岗率95%，屯垦、护粮、工程、辅战各报实数。

3. 六部54席夏季补齐100%，36名堂官全部具名、唯一主责、继任、回避关系入册；一人兼两实职为0。春季特科360人须报到岗和90日实绩，夏季再录360人、御前特荐3人；只录取不到岗不计。

4. 四总社春季销售仅18至22万两、净收益3至5万两，夏季新增扩张额度冻结30%，只准完成交割、销路和成本整改。90日四社本季销售30万两、净收益8万、实税3万为底线，上考36万、10万、4万；丰稷农具1.2万件，通济水机600架，经武独立报军械成本、节省采购与实税，寰海引入洋银20万两。产品售出率80%、工资实发95%，连续2季亏损者撤换总理或并厂。

5. 燧发枪夏季新造及改造合计1.2万支、上考1.4万，10日下发90%，到营30日实训通过95%；新造、改造、返修、报废、库存分别列数。全国新增或恢复实播25万亩、灌溉15万亩；夏季自愿实迁2.5万人，30日留存92%、90日85%，强迁拆户为0。

6. 10日内核清春季国库、内帑、大赏、股本、谍网和燧发枪账；夏季经常收支净结余90万两、上考110万。一次性军制、武备、补饷、补员分别关账，库存、在途、应收、追赃不得冒充经常收益。

【外交】

命武英殿大学士兼礼部尚书来宗道总互市海贸与朝鲜，倪元璐主商情邸报，何宗彦主藩属互市规制；杨嗣昌、徐霞客核清廷军情物价，毛文龙、沈寿崇、黄蜚保东江海路。

1. 张家口互市10万两旧额不增，优先购马、耕牛、皮革、粮种、药材和军工原料。夏季实购战马1000匹、耕挽畜1500头为底线，运输损耗低于8%；使清廷同类采购成本较春季再升5%、8%上考，须互市册、商报、暗线三证。

2. 天津、登莱、淮安、温州、广州、泉州合规报关4日内、3日上考；商贸货值较春季增长10%、海贸实税增长10%。四社及军械厂铜铅、铁、燧石、硫磺、钢刀头30日实到90%，不得以炮图、火药方、军制册和核心工匠换货。

3. 东江6.2万两与军需由登莱水师30日运达，朝鲜—东江—登莱海路90日不断；毛文龙每月2次有效袭扰，黄蜚报船次、运量、损失、清军分兵，不诱敌围岛。

4. 祖大寿每季8处薄弱情报须分军械2、马场2、粮仓2、备用2，逐处列储量、守兵、换班、路线、内应和证据级。六耳、锦衣各独核，不得以假据点、假战果替代真实军情。

【其他】

命内阁设“十一年夏军阶—军队—屯田—收益总考册”，考核到人、到军团、到部、到社，不得以部门平均掩盖个人和部队失职。

1. 孙承宗考三军总制和武备；卢象升考三层军制、军官缺额与可战可调；杨嗣昌考饷册、军阶册、情报；徐霞客考武选、马政、舆图和军械。满桂、左良玉、黄得功分别以本军任务、训练、纪律、饷械和数据受考；秦良玉、孙传庭、曹文诏、曹变蛟、左光先、虎大威、祖大弼、沈寿崇、吴三桂逐团单列，不得由都督成绩代替。

2. 九级军阶初定：卢象升9级候考；三军都督8级；已授旗军团都指挥使7级；虎大威列7级候任，靖边未授旗前不得领实职全赏。其余军官按实辖兵额和能力核级，文官总策孙承宗不入军阶。升阶须5次有效记功，御前可因救全军、守国门等大功加记1次，不得越级滥授。

3. 单位与个人均分上中下：90分以上上等、75至89中等、60至74下等、60以下不合格；上等人数不超过同级10%。单位不达底线，主官不得仅凭个人请功列上等；数据造假、克饷、扰民、逃阵、私卖军械者直接不合格并交军法。

4. 30、60、90日各报一次。完成率100%且战力或收益增长者秋季可扩20%；80至99%维持；60至79%冻结30%；低于60%撤换主管、停止扩面。无实际数按0%。

5. 季末御前总表固定列：各人军阶、实职、实辖、记功、考等、赏银；各军团兵力、可战、可调、训练、军械、补给、伤亡、军纪；各部官缺、办结、审计；屯田亩户、四社销售利润税银、财政净结余。所有一次性专款季末结余归库。

钦此。
