# 崇祯十年秋《袭马断粮开厂垦田移民增税诏》

奉天承运皇帝，诏曰：

十年夏所列事项，凡已有实际数并达标者，今秋方准在其实际基线上小幅提高；凡未报实数、未达底线者，仍以夏季原目标先行补足，不得借开厂、夜袭等新事换名掩盖。今秋以新军精袭铁岭马场、鞍山驿粮仓，夺马断粮、实战练兵为决定性主攻；以工部开厂、开垦、移民、提高税收完成率为第一硬支援，以三层军制、京营转役、军工实发、海贸养廉等收官验实为第二硬支援。兵不大增，税不加民田正额，移民只取自愿，专项皆有起止与结余归库。季末每项必须报实际数、完成率、证据和判定；无实际数者按未完成，不得以启动、推进、预计、在途、待冬季考成代替。

【军事】
命建极殿大学士孙承宗总策辽海，兵部尚书卢象升遥制行动，择黄得功或可靠将领为前敌主将；祖大寿暗线核铁岭马场、鞍山驿仓、巡骑和撤路，东江在凤凰城方向佯动。只夺马毁粮、练新军，不攻铁岭沈阳辽阳诸城，不与八旗主力纠缠。

1. 一次性拨银15万两，限十年秋使用，季末关账，结余归库。其中内应情报4万、火器火种与兽药3万、三日粮和船马转运3万、军医抚恤2万、核实战果后绩效赏3万。不得转为季度常额，不得挪26万常赏、军制年度款和移民安置银。

2. 主攻兵3500人，新军精锐3000人为主，关宁可调或京营转役精锐500人为辅。无月或浓云夜沿辽河故道潜入，铁岭喂马旧部先使马匹安静，主力破栅夺马；鞍山驿内应同时开仓，能运则运、不能运则焚。全程不得超过2时辰，得手即由柳河故道撤回，不追击、不占地、不抢民财。

3. 铁岭约800匹马，以带回可用战马500匹为底线、650匹为上考；捕获、惊散而使清军30日内不能使用者合计650匹为底线、800匹上考。鞍山驿约8000石粮，以缴获或实毁6000石为底线、7500石上考。马匹归新军与驿传，粮草归军仓，不得私分；战果须祖大寿暗线、东江侦报、清军调马调粮反应三路互证。

4. 主攻归队率90%为底线、94%上考，伤亡超过12%、停留超过2时辰、擅攻城或被八旗主力合围即判失败。参战新军经验净增2点、4点上考，士气净增2点、4点上考；缴获战马30日内编成新军骑兵不少于400骑、上考520骑，并完成骑射、夜行和撤退训练。

5. 若内应暴露、马场迁移、巡骑异常、天气不合或情报低于B级，前敌主将立即撤销，不得强攻；鞍山驿只作辅攻，铁岭不具条件时全军撤回，不得改攻沈阳粮仓。败案仍须报集结、情报、撤销原因、损失和保全，不得虚报捷报。

6. 夏季军制项目继续验实：四数核验100%，精锐实际可战8.2万人、五日可调5.2万人为底线，训练通过率94%、军械可用率97%、核心关口失守为0；京营转役实到1.9万人、上考2万人，逃亡低于3%、哗变为0。新军秋季新增训练9000人次为底线、1万人次上考，重复点名不计。

【内政】
命中极殿大学士兼户部尚书毕自严总钱粮与税源，工部尚书宋应星、王徵主开厂开垦，东阁大学士钱谦益会吏部组织自愿移民；开厂、垦田、迁民必须对应产出、安置和税收实绩。

1. 秋季新增15厂，30日定址、45日厂房成、60日投产、90日报首月实产。陕西4厂为西安农具、汉中水利、延安军需、凤翔粮食加工；山西3厂为太原农具、平阳水利、大同军需；河南3厂为开封农具、洛阳水利、南阳军需；北直隶保定水利、宣化军需各1厂；拉萨、贵阳、成都各设简易军需厂1座。厂只造农具、水车辘轳、粮食加工与不涉核心火器的军需。

2. 设一次性开厂专款6万两，优先用春耕备种结余与地方闲置官房，十年秋季末关闭，结余归库。15厂全部投产为底线；首月合格农具2万件、铁犁1200具、水车辘轳筒车600具、简易军需1万件、加工粮食5000石为底线，上考分别2.4万、1400、700、1.2万、6000。未投产、只挂厂牌、无产品者不得计厂数。

3. 秋季开垦50万亩为底线、55万亩上考：陕西10万、山西8万、河南8万、北直隶6万、四川5万、贵州3万、湖广5万、广西3万、云南2万。军屯、归屯、移民新垦分别列册，只计已整地播种或完成来春可播水源、种粮、农具且30日有人经营之田；灾毁、弃耕须从新增中扣除。

4. 自愿移民实迁3万人为底线、3.3万人上考。南直隶1.2万、浙江8000、江西6000、湖广4000为迁出计划；陕西1万、山西8000、河南6000、四川3000、贵州2000、广西1000为迁入计划。不得抽独子、拆夫妻、强逐良民；每户给安家银3两、口粮30日、田30亩、农具与谷种，30日留存90%、90日留存80%，逃亡过半者迁出迁入官同责。

5. 移民安置一次性专款5万两，限十年秋使用，季末归零；迁民册须本人画押、迁出知府、接收巡抚、户部抽核四方验证。虚报1人追银10两，虚报10人以上主办官革职。工厂优先吸纳移民青壮与军属学徒，实际就业5000人为底线、6000上考。

6. 税收完成率低于60%的省份，秋季较夏季最新实数提高10个百分点为底线、12个百分点上考；陕西暂按52%升至62%、山西50%升至60%、河南55%升至65%，均须用最新实数校正。全国盐课、市舶、商税、矿课和新厂经常实收较夏季增长8%为底线、10%上考，不加民田正税，不以卖库存、一次追赃和账面应收冒充。

7. 京西总厂、王徵技术下沉、军工人才和养廉旧账凡夏季已达标者按实际提高5%以内；无实数者仍按夏季原底线补报。26万常赏每季只发1份，主要阶层满意度净增2点、4点上考，各省民心不得低于40。开厂、开垦、移民不得使迁出地民心下降或新增强征扰民。

【外交】
命武英殿大学士兼礼部尚书来宗道主蒙古互市、海贸和朝鲜，杨嗣昌、徐霞客核清廷马粮调度，熊文灿、郑芝龙护商路；外交须配合夺马断粮、工厂原料和税源增长。

1. 张家口互市10万两旧额不增，7万守信、3万按拒向导、截马、拖粮和有效军情给付。铁岭马场受袭后，须报清廷补购马匹价格、数量、路线和护场增兵；使清军马价及补运成本上升10%为底线、15%上考，至少迫其调兵1000人护马粮、1500人上考。

2. 海贸为15厂输入铁、铜铅、木料、皮革、硫磺、量具和船材，合规报关5日内、3日上考；秋季经常实收入库较夏季最新实数增长8%为底线、10%上考。逐港报货值、实税、欠税、护航损失和成本，只签合同、在途、预计到港不得计收入。

3. 朝鲜、东江海路继续保王统与军情，不因铁岭行动停止护航。东江佯动只牵敌不诱围岛，朝鲜海路连续90日不断；军器不得落清，炮图、火药方、钻镗图、军制册和核心工匠外泄为0，须完成2次诱饵测试和两路独立审计。

4. 外交与夜袭成果不得重复报功。夺马、毁粮、清廷补购涨价、蒙古拒售、东江牵制、海贸增税分别立册；无实数、无独立证据者按未完成。

【其他】
命六阁六部继续一职一主，秋季设“夜袭—工垦—移民—增税总考册”，并延续夏季未完成事项收官册；旧项未验收不得因新项目删除、换名或重新立项。

1. 总考册分别列铁岭夺马、鞍山粮仓、参战归队伤亡、新军经验骑兵编成、15厂投产产出、50万亩开垦、3万人移民安置、税收完成率、海贸实收、夏季滚入项目。每项列基线、底线、上考、实际数、完成率、证据等级和判定。

2. 工部管技术和产品，户部管钱粮税收，吏部管人员考成，巡抚管落地，兵部验军需实用；同一官不得同时造册、验收、拨款和定罪。王承恩掌账不掌刑，李若琏暗核，刑部和大理寺定罪复核。

3. 15厂、开垦和移民均列1年考成。首季除建制外必须有实际产出、就业、实播、留存、税收和民心结果；满1年总考，临时筹办差遣满12季只能撤销、并入六部正式职掌、缩编为常设科司或有B级证据续期，不得自动成永久衙门。

4. 夜袭军功须在三路证据确认后发放，缴获马匹、粮草与物资全部点交国库军仓和新军；官兵只领核定绩效赏，不得私分。内应和家属须秘密安置，杀良冒功、私卖战马、谎报毁粮者从重。

5. 主要阶层满意度净增2点、4点上考，但不得只靠捷报。军人看战马军械抚恤，农民看田种农具，官僚看养廉升迁，士绅市民看自愿移民、商路和合法财产。任一主要阶层下降，须报直接原因与补效，不得用全国平均抵销。

6. 季末御前总表必须逐项报实数。无实际数、完成率、证据和判定者按未完成；不得以启动、推进、预计、在途、待冬季考成代替。行动取消也须报情报、集结、撤销原因和保全结果，不得以未战为无从考成。

钦此。
