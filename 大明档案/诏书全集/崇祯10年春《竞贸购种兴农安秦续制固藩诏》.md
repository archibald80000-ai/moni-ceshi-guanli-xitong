# 崇祯10年春《竞贸购种兴农安秦续制固藩诏》

奉天承运皇帝，诏曰：

九年冬陕西旧五股全销，朝鲜王统暂保、登莱东江海路已通，财政杂项支出压至约205万两，三层军制四数核验约八成五至九成，京西军械总厂主体约六成五。然南汉山城之围未解，陕西民心按低口径仅35、山西36，归屯与京营转役亦未全竟。今春以“春耕—安民—归屯”三环联动为决定性主攻，以30万两互市海贸竞购马匹粮种、辽海援朝牵制为两项硬支援；三层军制、军工人才、财政四分类照旧续考，不重拨启动巨款。田须有人耕，人须有田种，粮种农具实到而后民心可安。本季硬目标季末必须逐项报实际数、完成率、证据及判定；无实际数者按未完成论，不得以启动、推进、预计、待下季考成代替。

【军事】

命建极殿大学士孙承宗总协调辽海、北疆与三层军制，兵部尚书卢象升主训练调动，孙传庭、洪承畴专秦晋归屯治安；春耕期间军队护田护路，不得扰民夺种，不因援朝抽空关宁宣大。

1. 三层军制以冬季实数为基线，10日内完成全国账面、实点、可战、可立即调动4数核验100%；东、中、西3个机动群60日各完成1次春季实兵合操。90日实际可战8万人、5日可调5万人为底线，上考8.3万人、5.2万人；训练通过率92%、军械可用率96%，核心关口失守为0。不得重拨100万两启动款，只用年度结余、维护费和最高5万两一次性绩效银。

2. 高迎祥既灭，陕西不再保留大规模追剿专款。曹文诏、秦良玉及地方守军分路巡田、护仓、查残余小股，河南、山西、陕西新万人级叛军为0。残余结伙超过500人须10日内分割处置；军队侵田、抢种、强役案件较冬季下降15%为底线、20%为上考。

3. 陕西、山西新增并稳定归屯1.5万人为底线、1.8万人为上考，30日留存90%、90日留存80%、复叛率不超过3%。归屯户优先给田、粮种、农具、轻税和治安保护；只登记未落地、无种无具、30日离屯者不得计功。季末分别报归屯、留存、复叛、实播和民心变化。

4. 黄得功完成北京京营2万人转役总验，实到1.9万人为底线、2万人为上考；其中6000人优先编入京畿及陕西边地屯田、工兵、转运，实际完成军屯实播6万亩，修路、修渠、建仓任务各报实数。转役军基本饷不断，逃亡低于3%、无哗变，士气不得下降。

5. 工部下发军械仍以形成战力为准。春季合格军械验收后10日内下发90%，50%优先第一层机动军；到营30日内完成实弹、合操、维修教学。压库超过30日、只有械无弹、只有领用无训练者，军工与受领军均按未完成。

6. 援朝继续海路、东江、暗线三策，不在朝鲜平原总决战。东江每月2次有效袭扰为底线、3次为上考，重点断辽南与鸭绿江粮路；祖大寿暗线继续核清军回师路线。朝鲜合法王统与江华、南部抗清区至少保其一，海路连续90日不断，明军相关主力损失不得超过两成。

【内政】

命中极殿大学士兼户部尚书毕自严总钱粮，工部尚书宋应星、王徵主水车农具灌溉下沉，吏部尚书周延儒、东阁大学士钱谦益续科举新学；各省春耕、秦晋安民、归屯必须形成同一闭环。

1. 北直隶、南直隶、山东、山西、河南、陕西、浙江、江西、湖广、四川、福建、广东、广西、云南、贵州及辽东安全区，逐省实际新增或恢复实播10万亩为底线、12万亩为上考。只计已下种、有水源、有人耕作且30日未弃耕之田；逐省报新增、复垦、归屯、商屯、军屯、灾毁、弃耕7数，不得以全国总数抵销未达省份。

2. 陕西民心按35、山西按36的较低口径起算，90日均须升至40为底线、42为上考；其他已达40省份不得下降并净增2点、4点上考。主要阶层满意度亦逐层净增2点、4点上考。粮价红灯3日内处置，种粮农具到账率95%，流民和非正常死亡逐旬下降；只发银而民心、粮价、实播不动者不得复用原法。

3. 国库一次拨30万两设“春季边贸竞购马种专款”，仅限崇祯10年春，季末关闭，结余归库。12万两购买马匹及耕挽骡牛，10万两购买粮种，4万两用于运输、检疫和仓储，3万两用于拒售清廷、守约供明之商部绩效，1万两机动。由来宗道、毕自严分账，六耳核实来源，严禁高价虚购、强征盟部口粮。

4. 90日实际购得马匹及骡牛合计6000头为底线、7500头上考，其中可耕挽、驮运者不少于70%；粮种8万石为底线、10万石上考，发芽率85%、上考90%。粮种50%发陕西、20%发山西、15%发河南、15%发其他红灯省份；畜力70%给春耕与运输、30%给第一层机动军及驿传。到境10日内分发90%，季末报采购、实到、分发、死亡、播种和成活。

5. 京西总厂与王徵技术下沉，不以厂内样品为功。30日选陕西、山西、河南及京畿重点州县50处，90日复制水车400架、改良农具1.2万件、简易灌溉样板150处为底线，上考500架、1.5万件、180处；实际受益田20万亩、30日可用率90%。军工边角料可制农具，但不得挤占火器主线和克扣工匠薪粮。

6. 京西总厂主体工程由65%推进至80%为底线、85%上考；合格火铳6500支、轻炮55门、红夷炮8门、修复旧械5800件为底线，验收后10日下发90%。人才春季再到岗1000人为底线、1200上考，使秋冬春累计3000人；不得新拨第二个年度50万两，只用年度余额与季度上限。

7. 26万两常赏每季只发1份。养廉旧账10日内先核应发、实到、拖欠和满意变化，旧账未清不得另设新增养廉名目。季度杂项支出压至190万两以内、185万两上考；经常收支净结余80万两为底线、100万两上考。防疫无红灯、黑灯不得另拨固定20万两。

【外交】

命武英殿大学士兼礼部尚书来宗道主对清竞贸、蒙古互市、朝鲜与海贸，杨嗣昌、徐霞客核马粮商路，熊文灿、郑芝龙护海运；以茶绢、盐引、现银和通关便利争夺马匹粮种，不以军器核心技术换货。

1. 对清贸易战以锁供货、抬其成本、保我盟部为法。蒙古各部、朝鲜南部安全区及海商愿优先供明马匹、粮种、硫磺、铜铅者，给绩效银、盐引、茶绢和优先通关；不得在灾区强买，不使盟部粮价因明廷采购上涨超过10%。六耳、互市册双核后金因我竞购少得军马1000匹为底线、1500匹上考，少得粮种和驮运物资须报实际数。

2. 张家口互市10万两旧额不增，与30万两竞购专款分账；7万两守信，3万两按拒向导、截马、拖粮和有效军情给付。同一马匹粮种不得在互市和竞购两账重复报销，重复冒领即停市追银。

3. 朝鲜采购只取南部、海岛和商人可售余粮余种，不得抽空抗清军民。明援火铳、轻炮和军需须换取海路、军情、粮种和工匠合作，不以朝鲜割地、重税或无偿输粮为条件。军器不得落清，核心炮图、火药方和军制册外泄为0。

4. 三港及相关海路冬季实收约17万两，春季海贸经常实收入库18万两为底线、20万两上考。来宗道会熊文灿缩短合规货物报关至5日内、上考3日，适度扩大药材、粮种、农具、布匹和船材货种；硝铁军器禁令不松，减少重复关卡而不新增杂派。

5. 海路援朝、东江袭扰和春耕采购合用护航，不得三线各自重复雇船。季末报船次、实到、损失、税银、采购成本、后金少得物资和海路连续日数；只签约、在途、预计到港均不计完成。

【其他】

命六阁六部沿九年冬“一职一主”继续运行，本季不再大改职位。阁定方向、部负执行，户部掌账不掌刑，刑部定罪不掌账，工部造物、兵部验军用，六耳明核、锦衣暗核。

1. 春耕—安民—归屯设共同考成，不许农政、户部、地方、军队各报一份重复功。每户归屯须有姓名、田亩、粮种、农具、畜力、轻税、实播和30日留存；每块新增田须能对应耕户与种源。田无人、人无田、只登记未播种均不得计功。

2. 30万两竞购专款为一次性项目，起于十年春、止于十年春，季末自动归零；任何后续采购必须另奏。26万两常赏为唯一季度常额，人才50万两为年度总额，军制100万两为九年秋至十年夏年度授权，港口巡逻每季10万两须报告护航、海盗、腐败和税收效果，效果不足不得夏季自动续额。

3. 吏部、工部、户部30日内核养廉、人才、工匠和军官旧账。养廉须报每人应发、实发、拖欠、离职和满意变化；人才须报录取、结业、到岗、留任和实际带训制修；未清旧账不得以新名目重复拨款。

4. 春季重点责任：毕自严负财政与竞购分账，来宗道负商路供货与海贸税，宋应星、王徵负农具水车实到，周延儒负人才到岗，孙传庭、洪承畴负归屯实播，卢象升负军制与护耕，杨嗣昌、徐霞客负后金竞购损失与预警证据。主官、副官和证据责任人不得相互代签。

5. 若清军在朝鲜扩大攻势，援朝按败案保王统、江华、南部抗清区和海路，不抽陕西春耕军与边墙守备军；若陕西山西春旱蝗害复起，竞购粮种优先转灾区，防疫及赈灾按红黑灯触发。任何败案均须报损失、保全和剩余目标，不得以战争灾害取消全部考成。

6. 季末御前总表固定列：逐省实播、秦晋民心、归屯留存、马畜粮种采购实到分发、技术下沉、水车农具、军屯、三层军制、军械实发实训、辽海朝鲜、海贸税、杂项支出、净结余、养廉旧账和各阶层满意。每项列基线、底线、上考、实际数、完成率、证据等级和判定；无实际数按未完成论。

钦此。
