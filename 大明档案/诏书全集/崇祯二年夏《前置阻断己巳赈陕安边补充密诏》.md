# 崇祯二年夏《前置阻断己巳赈陕安边补充密诏》
- 时间：崇祯二年夏
- 状态：补充归档，待游戏执行反馈
- 归档说明：本诏承接崇祯二年春《全国动员赈秦固边清饷安民诏》与春补《东江镇制辽五策及辽西蓟宣均衡补充诏》，并采卢象升“陕西剿抚赈军四路并进”奏议。因夏季纪要已明示陕西义军膨胀、江南洪涝粮源替代、漠南蒙古真空、蓟宣京畿短板与东江忠诚危险，本诏专以六十日为限逐项销号。凡钱粮、兵额无法由夏季纪要确认者，均标若。
奉天承运皇帝，诏曰：
【军事】
命卢象升总核陕西剿抚赈军四路，孙承宗总辖宁锦、东江、蓟宣三层防务，杨鹤、洪承畴抚陕，曹文诏剿悍首封米脂，满桂守蓟宣，六十日内剿抚并用、军赈兼行，不许弃辽，不许浪战，不许擅杀边将。
陕西之乱，根在旱饥，发为流寇。今夏王二、王嘉胤、高迎祥诸部合计仍胀，李自成又起米脂，陕西民心二十九、动乱风险八十四，贼势已逾四万八千。若徒事招抚而不剿悍首，是养痈；若专恃刀兵而不赈饥民，是益乱。着卢象升会兵部、户部、都察院，以六十日为总限，分四路并进：一路洪承畴赈饥民、抚胁从；二路曹文诏剿悍首、封米脂；三路杨鹤、毕自严、王承恩、袁可立安边军、补急饷；四路宋应星、满桂催火器、备关隘。四路各有专册，各有时限，各有赏罚，月终廷议，不得互相推诿。
第一路命洪承畴以陕西巡抚衔坐镇西安，专司赈务招抚，不为追贼军务牵制。西安、延安、庆阳、凤翔四仓目标十二万石，今夏实存仅五六万石，缺六七万石；江南旱后转洪，漕粮不可恃，着改从湖广调粮。洪承畴会毕自严、湖广巡抚，三十日内首批三万石入陕，四十五日内补足十二万石满仓之数；若湖广粮由汉水经襄阳入商洛，水陆兼程至西安，较江南漕运可省脚价约三成，然以实际脚价册为准。各州县设粥厂、工棚、归籍棚，流民按丁口造原籍、丁口、技能、亲属四册，每丁日给米一升、盐菜少许，老弱妇孺酌减，不得空榜无粮。青壮编工役队，修渠、掘井、筑堡、葺仓，优先修复郑国渠、白渠等灌溉旧渠，每工日给米二升、银二分，此为若工赈额，须按实工给付。凡被裹挟从贼而未杀官劫库者，许自首免死，杖二十后编入军屯或民屯，给种子、农具、耕牛，三年免赋；军官敢役屯丁为奴者，立解袁可立审办。
第二路命曹文诏领剿寇机动兵，专击王二、高迎祥悍寇，兼封控米脂困李自成。曹文诏本部精骑约八百，若更选蓟州、宣府、大同非守口游兵各五百，登莱火器兵一千，合约三千三百人；龙井关、大安口、喜峰口、居庸、古北口守口正兵一卒不得抽，宣大抽兵防区由真保镇与本镇备操兵暂协六十日，满桂统之。登莱火器兵由兵部指定教练官统带，配火铳五百杆、轻型火炮十门，专作破阵、守堡、护粮，不许轰击已降饥民。曹文诏接旨十日内集结，先由西安北上，经洛川、鄜州推进，与固原边军南北呼应，二十日内击溃王二主力或迫其分股就抚；王二被擒、阵斩或主力散后，余众无血案者交洪承畴招抚。继而西向与宁夏边军压高迎祥部，四十日内破其主力。李自成新起米脂，粮械未足，命榆林参将率本镇兵一千五百封锁米脂四路，不许放其出掠，亦不贸然攻城；每日哨探贼营动静，断粮道、截外援，以困促降。军纪从重：杀降、掠民、焚村、杀良冒功者，兵丁斩，将官连坐降三级；斩获首级须巡按御史点验，军功以护粮、破悍首、招降、解散裹胁四项并计，不以首级独论。蓟宣、宣大抽调游兵自离镇日起六十日内必须归防，曹文诏五十日内结主务，留十日撤还；逾期不还，曹文诏罚俸一年，相关总兵罚俸半年。
第三路命杨鹤以陕西三边总督衔抚边军，毕自严筹饷，王承恩旁验，袁可立审贪墨。固原、延绥、宁夏、榆林四镇先核实兵实饷，十日内每兵先发一月足饷现银，余欠分期补足；每兵另给口粮三斗、盐二斤、布一匹，种子农具随屯田册给发。王承恩所遣锦衣卫驻陕西清慎官逐营核对兵册、实兵、口粮、马匹、军械，查空额、冒饷、克扣；凡虚报兵数、克扣口粮者锁拿解京，袁可立十日开审、十五日定谳，赃银追回即充边饷。边军不得以欠饷擅离防地，亦不得坐视贼寇过境；杨鹤每日巡视各营，面谕补饷时限。煽动哗变、杀官劫仓者立斩以徇；因饥逃亡而自归者仍照春诏免死归营。
第四路命宋应星督工部火器军需，满桂巡视蓟宣关隘。工部改良火器已成约六成，宋应星五日内先解已成火铳五百杆、刀矛刺器一千柄、盔甲五百副赴陕西，配曹文诏剿寇队与四镇守堡兵；此为就既有库存与已成工料调拨。满桂即日巡视蓟州至喜峰口、古北口、居庸、宣府、大同，查城垣、兵员、粮草、火药、入堡路线五册；蓟州守口兵不得再抽，十五日内补修急坏城垣、烽燧、墩台，六十日内蓟镇不得失警。每五日一报后金与蒙古部落动向，若见后金集结或蒙古向导异动，飞报孙承宗、卢象升、兵部、王承恩四处复核。
辽东仍守宁远、锦州、山海关，不得撤屏障寒关宁军心，亦不得无限添兵掏空陕西京畿。袁崇焕止管关外宁锦守御，祖大寿守前锋要隘，未经孙承宗、卢象升会奏，不得擅调关内兵马，不得擅杀毛文龙，不得吞并东江船兵。毛文龙以皮岛为根本，仍行袭扰辽南粮囤船械、招抚辽民、十日急报后金兵马、黄海截盐铁粮、联络朝鲜铁山义州五策；本季沿用已拨银六万两、粮二万石、火药八千斤、修船银一万两，先核实兵、船只、屯民、细作、火药、粮饷六册。东江若登陆，只限三千至五千人，小股焚粮毁船截械，不以首级为唯一功，战后十日具报；若虚报辽民、劫掠明商、私通后金、索朝鲜粮饷者，停饷会审。后金借蒙古入边有警，三关先举烽闭关，近堡百姓入城，满桂、曹文诏三日内驰援，京营守城，辽军守宁锦，东江扰其后，不许轻骑出塞邀功。
【内政】
命毕自严总核陕西四路钱粮与江南湖广粮源，六十日内以湖广粮满陕仓、赈银三款分账、江南修圩保税为急，不加民田正税，不清丈江南田亩，不挪陕西赈银修北边。
卢象升所奏四路并进，用银用粮甚巨，然陕西若失控，则中原震动、军费十倍。今定若总预算银三十九万两、粮十二万石：湖广调粮十二万石，粮价及运费约银十五万两；四镇急饷约银八万两；粮布种子农具约银五万两；以工代赈约银三万两；剿寇兵饷及火器转运约银五万两；蓟镇急修约银三万两。银源分列：西北抗旱仓余银约七万两，内帑借银约二十万两，两淮盐课追欠约十万两，广州宁波市舶与郑芝龙岁税本季可用约十万两，余二万两由毕自严从杂项入库、追回侵饷中腾挪。此数皆须户部二十日内重核，因夏季纪要国库与内帑口径互异，不得以推演数充既成事实。
陕西赈银设专账三款：购粮款、工赈款、流民安置款，比例约五比三比二，此为若初分；洪承畴每旬报毕自严核查，王承恩旁验，房壮丽审计。购粮款只买湖广、河南可平买之粮，不许强籴；工赈款只给修渠、凿井、筑堡、葺仓、驿路五事；安置款只给归籍、编屯、种子、农具、耕牛。各州县发粮，由县丞亲视，里长具结，仓官、吏役、豪强克扣者，饥民许赴西安巡抚衙门鸣冤，洪承畴三日内亲审；查实侵粮一石、银十两者杖流，侵粮五十石、银五百两以上者下刑部重治。
湖广治水已成，民心六十三，可为陕粮新源；南直隶民心六十四、浙江七十二、江西六十二，皆旱后转洪，粮食约减两成，不可再强征。着湖广先解首批三万石，四十五日内补足陕西四仓十二万石；江南三省本季暂停征调赈陕实粮，只报堤岸、圩田、仓储、灾民四册，先修圩、疏河、护秋种。苏松常前案已收队，魏忠贤不得复入江南自行扩案；温体仁留南京收侵税、扰民、阻赈申诉，钱谦益只可劝士绅义仓输粮，不得经手银钱。士绅愿捐粮百石、银百两以上而不取息者，礼部给匾旌表，其粮银入地方义仓与江南灾后修圩，不强解入京。
广州、宁波市舶仍照五十取一，郑芝龙岁输十万两分季入库，两淮盐课只追旧欠、引目重冒、官吏侵蚀，不加灶户盐价，不设杂派。本季市舶、盐课、郑氏税银新增一成入北边防灾应急储备，二成入常平仓本，余补国库与赈陕车船。蓟宣修防只取辽西虚饷结余、市舶盐课一成、山海关追回侵饷、内廷节用，不得动陕西赈灾库。财政册分六库：陕西赈灾库、陕西剿寇军需库、辽西验饷库、东江试行库、蓟宣修防库、江南修圩仓本。未核清前，一切新增大工、大舰、全国清丈、全面新军扩编悉停。六十日终以内政八事考成：四仓满储十二万石、粥厂覆盖流民七成以上、归附胁从三千人以上、编屯五万亩以上、湖广粮运抵、江南洪涝不恶化、市舶盐课不扰商、赈银未被挪用。有实绩者升赏，虚文无物者降调。
【外交】
命来宗道总理蒙古、朝鲜、东南海贸交涉，六十日内寻察哈尔新驻地、分科尔沁喀喇沁、通朝鲜边报、护市舶税路，不割地，不称臣，不纳岁币，不迫朝鲜出兵。
察哈尔西迁，旧口岸物资仅约九成转达，信任已伤；若不即补，科尔沁、喀喇沁皆可为后金向导。来宗道二十日内遣使大同以西，寻林丹汗新驻地，互市常额十二万两与军情赏格三万两分册给付，不得以国库窘迫擅减常额，不得把赏格混作常额。察哈尔能报后金兵马、粮道、使节、借道部落者，优先给茶绢盐引；土默特守约者照旧通市；科尔沁、喀喇沁诸部若拒后金借道、献路线、首告附金部落，许盐引、小额银赏、马市优先，一概不给鸟铳、火药、铅子、甲胄。若容后金由其地入宣大、蓟门，即闭市三月，停赏夺引；同部首告证实者仍给赏，以分其势。宣大守臣不得私扣互市物，不得因迟给驱逐使者；吞赏百两以上者夺职追赔。
朝鲜力弱，不责其出兵，只令礼部使臣与东江旧线求铁山、义州临时停泊、补水、收容辽民、递送边报。朝鲜若报后金军粮转运、鸭绿江兵马、蒙古使节往来，给药材、布匹、历书、小额赏银；不得以火器、重炮、兵粮诱其开战。毛文龙与朝鲜往来须礼部馆驿、兵部边情、东江军册三处存副本；不得向朝鲜索饷索粮，不得越界招兵，不得私受书币。对后金仍守四不：不割辽土、不称臣、不纳岁币、不以宁锦东江为议价。袁崇焕、毛文龙、祖大寿、满桂、曹文诏皆不得私收后金文书礼物；有后金反间书至，须封存送孙承宗、卢象升、王承恩三处复核，不得据一纸谣言诛将。
东南海贸为国库长流，不可因江南洪涝而扰断。熊文灿会福建、广东、浙江巡海道核郑芝龙船册、人册、炮械册、税册，郑部每季二十艘护广州、宁波商路，不得私设税卡，不得私售硝磺铁器与后金，不得吞并福建水师。广州、宁波商船纳税后给票通行，海盗、倭船、红夷劫掠者由郑部与福建水师分汛追捕；因国库深赤，不兴远海大战，不造大舰。能使市舶年化五十万两上下不断、东江有小额续饷、江南商讼不增者，主办官升赏；借护商勒索者，先停官票，后下刑部。
【其他】
命李国普统考成，卢象升会内阁都察院六十日总核四路功罪，王承恩旁验，房壮丽审计，袁可立定罪，凡赈银、军饷、仓粮、互市、修防、边报皆有实册，不许党争误国，不许厂卫扰民。
本季考成以八患与四路并进同册销号：一核陕西义军是否继续膨胀，二核陕西赈灾招抚是否到口，三核边军是否再叛逃，四核江南洪涝是否转为粮源断绝，五核江南士绅是否因清查激变，六核漠南蒙古是否倒向后金，七核蓟宣京畿是否有烽堠机动，八核六部行政是否按期署事。卢象升每十日收四路进展，李国普月底廷议；逾期不报者罚俸，虚报者降调，伪造银粮者下刑部。王承恩选锦衣卫清慎官三十六员，分驻陕西四仓、米脂外线、四镇军营、山海关、登莱东江、宣大互市、广州宁波、两淮盐课，只验银米、军额、仓存、船只、边报副本，不得夜入民宅、拷掠士民、索取商税；犯禁者先夺勘合，后治罪。房壮丽会都察院审差额，毕自严会户部审钱粮，卢象升会兵部审军饷，袁可立专审侵赈、侵饷、擅杀、私通四案。
四路考成明定：洪承畴三十日内四仓储粮须达九万石以上，四十五日内满十二万石，粥厂覆盖流民七成以上，六十日内归附胁从三千人以上、编屯五万亩以上；未达者罚俸半年，达标超额者叙功。曹文诏二十日内击溃王二主力，斩获、招降、解散裹胁合计达其部众六成以上；四十日内击溃高迎祥主力，斩获、招降、解散裹胁达其部众五成以上；米脂十五日内合围，三十日内李自成部不得突围出掠；王二、高迎祥有一部未破，降级留任，两部皆未破，革职问罪。杨鹤、毕自严、王承恩、袁可立一路，十日内急饷拨付到营，二十日内粮布种子发完，三十日内虚冒克扣案解京，六十日内四镇逃兵叛投以降至零为上考；饷银逾期，毕自严罚俸三月，查案不力，王承恩、袁可立罚俸半年，边军仍大股叛投，杨鹤降级留任。宋应星五日内首批火器启运，三十日内续解已成器械；满桂十五日内蓟镇关隘急修完毕，六十日不得失警；火器逾期，宋应星罚俸三月，关隘失警，满桂革职拿问。
防反间之法并入考成。凡后金兵临、边报纷至，无实证不得拘押督师，不得因流言杀镇将。袁崇焕与毛文龙相争，先由孙承宗会卢象升、李国普裁定，王承恩留副本；擅杀、擅并、擅调关内兵者，以违制论。毛文龙便宜行事只限海上风信、登陆时机、撤退路线、小股袭扰，不得抗册拒饷。满桂、曹文诏不得互争京畿兵权，遇警以三日驰援为功，不以出塞斩首为功。东林、阉党、皇党、中立派各用其可用之处：孙承宗、袁崇焕、袁可立任边防司法，毕自严、李国普、杨鹤、洪承畴、卢象升任钱粮赈抚军务，王承恩、曹化淳管内廷副本，满桂、曹文诏任机动巡防，宋应星、徐光启、汤若望、公沙·的西劳只任技术。魏忠贤不得复赴江南扩案，田尔耕仍系狱不得授差。
六十日后，卢象升会内阁、都察院逐项考核，当殿述职。凡推诿延误、阳奉阴违者，无论品级，先停职后参奏；凡借剿寇之名扰民劫财者，以贼寇同罪；凡借赈灾之名侵银吞粮者，以伤民误国论。若陕西四仓满储、王二高迎祥两股悍寇被破、李自成困米脂不得外掠、四镇军心稍定、蓟镇关隘有备、胁从编屯成数，则主办诸臣按功升赏。若一味追杀激成民变，或只赈不剿坐视贼胀，皆罪在承办。朕每月亲览八患销号册，三月终据实赏罚。此诏但求钱粮到民、边堡有备、东江不断、蒙古不叛、江南不炸、陕西不糜；敢任事实者保全，阳奉阴违者虽近臣不贷。
钦此。
