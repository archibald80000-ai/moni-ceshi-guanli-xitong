# 崇祯9年春《固边收陕保春耕扩工兴学续赏诏》

奉天承运皇帝，诏曰：

先申赏格：本季犒军银5万两、官僚赏银5万两、养廉银5万两、春耕赏银10万两、吏部考察银1万两照旧发放，悉从国库直发，不动内帑，不经将官私库。另以国库50万两大赏天下，分6库：农政春耕20万两、工坊与火器12万两、科举与新学8万两、水利仓棚药仓5万两、边民平粜3万两、文官民生与边镇安业2万两。又以国库20万两设5路专项：防疫5万两、春赈归屯6万两并粮4万石、清鼠尸净井源2万两、六耳军3万两、吏部考成养廉4万两。凡银粮皆立专账，王承恩、房壮丽、李若琏、内阁4权互核，先赏后考，不许均分，不许冒领，不许挪项。

【军事】
命孙传庭、曹文诏、秦良玉乘贼疫后饥疲收陕，卢象升固宣大真保，杨嗣昌徐霞客紧缉六耳，宋应星孙元化续扩火器，90日内使陕贼不得复补、北疆不失、军情先至。
1. 孙传庭总陕晋豫剿抚，曹文诏、秦良玉分领机动兵，洪承畴专主粮赈归屯，春内继续压王嘉胤、王二、高迎祥、李自成、张献忠5部，不许任1部补给复起。以6部补给仍为0为底线，陕西新增裹挟不逾40人为底线、20人为上考，60日破小营120处为底线、150处为上考，180日诸贼主力合计减50%为底线、减65%为上考；敢勇营从归屯降众中择精壮无血债者编4000人为底线、6000人为上考，只许断其外援、护其粮道，不许独夺城、不许私劫民财。收益：把陕西春荒的饥民先锁在粮棚和归屯里，把贼粮和贼兵一起压住，免得一到开春又涨势。考成：30日五册齐，60日破小营，90日老营迁徙，180日减员达标，若任1部补给复起或新增裹挟破线，主将罚俸并限期补效。
2. 卢象升兼督宣大、蓟州、真保、大同春后续修与新军扩编，宋应星、孙元化分督器械火炮；春内新军扩至4万人为底线、4.5万人为上考，火铳季度产4500支为底线、5000支为上考，轻炮季度产45门为底线、55门为上考。宣府铸炮厂、京铸厂、官营火枪厂三处同验，工匠、铳管、火药、铅子、试放、木床、钻镗7册30日内齐备；大同、宣府、蓟州、真保、居庸、古北、喜峰、龙井、杀胡口、镇羌堡春修册10日一报、30日一验，遗炮仍须为0。收益：把冬季能守的墙，变成春季能打、能补、能续产的墙和炮。考成：底线为新军、火铳、轻炮、7册齐、遗炮为0；上考为车营、炮营、守口军都能轮训成战，用兵不空原防。
3. 杨嗣昌统六耳侦缉军，徐霞客仍副舆图测路，改以商队掩护、边外潜行、粮道核验、火器外泄缉查4路并进；春内六耳军补至3.5万人为底线、4万人为上考，可用粮道图500幅为底线、650幅为上考，贼营疑报420条为底线、560条为上考，准确率93%为底线、96%为上考，泄密仍须0。察哈尔、土默特、科尔沁、喀尔喀诸部与晋商、茶商、马帮往来，皆须入六耳黑册，不许六耳军掌税、掌刑、掌调兵。收益：让后金、蒙古、晋商的动静先露在纸上，北疆和陕西就能先手布防。考成：每5日1报边外，每10日1报粮道，每月1次总核；若泄密、扰民、误报成灾，杨嗣昌与徐霞客同受停俸。
4. 孙承宗总裁边防军议，着卢象升会山西、北直隶督抚，春前再验8镇烽堠、敌台、壕沟、拒马、火药、粮仓与护民入堡6册，3日一报、10日一验；毛文龙完整保东江，补给不低于70为底线、75为上考，仍只行小股袭扰、截盐铁、报兵马，不许擅并登莱。收益：春冰既消，边墙若不先验，冬里堵住的口子就会化成春天的缺口；东江若不断，就能逼后金分兵。考成：8镇春修册齐、东江月报不断、补给不跌、主工先成者加赏，擅自出塞野战者虽有斩获不叙功。

【内政】
命毕自严、洪承畴、宋应星、王徵先保春耕补库、治疫常备、归屯入册、工坊兴产，新春之前必令种子、农具、药仓、井渠、仓棚先到府县。
1. 毕自严总理钱粮，今春5项赏银26万两、50万两大赏天下、20万两五路专项皆由国库直发，不动内帑；50万两中，20万两专补春耕种子、农具、牛具、井绳、水车，12万两专给工坊、火器、铁炉、木床、车营修造，8万两专给科举、新学、西学与实学补录，5万两专给水利、仓棚、谷库，3万两专给边民平粜，2万两专给文官民生与边镇安业。收益：让钱先流到农田、工坊、学舍和仓口，不让它在衙门里空转。考成：底线为种子、农具、工坊原料、学舍物料按册到府，春赏到账率100%；上考为农、工、学三项各有可见成果，且不得互挪。
2. 洪承畴主陕西粥厂、归降营、归屯田，春内新增归屯1.2万人为底线、1.5万人为上考，西安、延安、凤翔、庆阳、渭南5路春播册30日内齐，敢勇营与粥厂守卫仍按30人守1厂。归屯丁口须具姓名、原籍、原属贼营、家口、田亩、农具6项，缺2项以上不得入功册；边耕边守，但不得私役为奴。收益：把还在游荡的饥民尽数塞进粮棚、春播和屯田，既少一个裹挟点，多一块可收税的地。考成：底线为归屯1.2万人、春播册齐、粥厂无劫粮无复叛；上考为归屯1.5万人、春粮先下地、秋可见收。
3. 宋应星、王徵督冬后春修井渠仓棚谷库与商屯戍边，井渠650处为底线、800处为上考，仓棚650处为底线、800处为上考，谷库100座为底线、130座为上考；宣大、陕西、山西商屯扩至20万亩为底线、30万亩为上考，边镇口粮自给率40%为底线、50%为上考。收益：把来春的粮种、水源、仓储和边镇口粮一起做成闭环，运粮路短了，饷银也就省了。考成：春前井渠、仓棚、谷库与商屯四册齐，种子、农具、牛具、井绳全到；偷卖官种、扣留农具者，官吏革职追赃，豪强加倍追还。
4. 陈新甲仍按左佥都御史督反贪、科举、新学、西学，李国普总铨选考成，钱谦益、史可法继续抚绅安民，新学由12学为底线、18学为上考，春季补录120人为底线、150人为上考，官绅子弟入学须甄试，不授官、不占科举正额。收益：把士绅和官僚的心气留在学舍和铨选上，不让他们把怨气堆成党争。考成：底线为新学开办、补录成册、反贪和考成各有实证；上考为士绅满意不降、官僚满意回升、学政不扰民。
5. 魏照乘会地方巡按、医官，续办病舍、药仓、净井、焚秽、埋葬5册，药仓108处为底线、132处为上考，病舍与净井逐旬报数，疫区不得封村断粮、不得弃尸入河、不得驱逐病民。收益：春疫一旦回头，粮食和人命都会一起漏；把疫仓做厚，春耕才能安心。考成：底线为药仓、病舍、净井全续，药材银不得挤占春耕银；上考为疫亡再减、净井全验、无虚报病亡。

【外交】
命来宗道、毛文龙、熊文灿、郑芝龙守蒙古互市、东江牵制、3港海贸与火器禁流，趁后金漠南重兵东顾之时分其势，不许增旧额乱边局。
1. 来宗道仍主蒙古互市与边外军情，张家口互市照旧10万两，先给7万两以守信义，余3万两凭军情、拒作向导、截马、禁硝铁实绩给付；察哈尔、土默特、科尔沁、喀尔喀诸部愿报后金调兵、转粮、借道者按实给赏。收益：以茶绢盐引把漠北拉成一面镜子，后金一动就先照出来。考成：底线为有效军情8条、拒作向导与截马各有实证；上考为12条以上，且后金入塞前3日先有告警。
2. 毛文龙保东江敌后牵制，铁山、义州停泊补水，东江补给不低于70为底线、75为上考；辽南小股登岸只焚粮囤、毁船械、截盐铁、报兵马，不许诱后金主力围攻皮岛。收益：东江不倒，宣大就不会被逼成单线。考成：底线为月报不断、每月2次有效袭扰；上考为补给更稳、辽南粮路持续迟滞。
3. 熊文灿、郑芝龙护天津、淮安、温州3港海贸税路，并守广州、泉州军器市舶司，海贸税年内8万两为底线、12万两为上考，火器换白银只准旧款火铳、佛郎机炮、陈旧铳管，不许红夷炮、火药方、火绳、铅模外流。收益：把旧炮烂枪换成真白银、真粮食，顺手给南洋和海商留活路。考成：底线为3港税册齐、军器换银4万两、热带粮1.5万石；上考为税银12万两、粮2万石且零外泄。
4. 诸部与海商往来皆归礼部、兵部、工部共核，朝鲜、琉球、澳门诸线只用于东江停泊、海贸税路、铸炮工艺、军情互通，不许私通后金与走私炮书。收益：把边外、海上、工艺三条线收在朝廷手里，既开白银路，又堵军机口。考成：底线为军情互通不绝、禁货案有册；上考为火器外泄为0、海商与边务不相冲。

【其他】
命王承恩、刘泽深、房壮丽、李若琏、李国普、陈新甲行4权互核与春季总考，补刑部、稳西学、续邸报、严查虚报挪赈，不许越权。
1. 王承恩掌账不掌刑，刘泽深掌刑不掌账，房壮丽审账，李若琏密核，内阁复核，司礼监封册，今春仍行4权互核；会核国库、内帑、4库、商税、盐课、矿税6账，并分实银、实粮、实药、账面冲抵4类。凡犒军、官赏、养廉、春赏、五路专项、火器、学政、赈银、归屯，皆单独成册，不许冲抵，不许虚报。收益：钱粮一出就能看见去处，谁吃谁拿一目了然。考成：底线为6账4类齐全、30日一报、追回贪冒银20万两；上考为月核不断、追回30万两以上。
2. 刘泽深会3法司，继续在陕西、山西、河南交界设流动查账6队，每队刑部司官、巡按御史、锦衣卫清慎官各1人，核赈银发放册、军饷实收册、粥厂米数、乡勇粮册、火器禁泄案；府县衙外仍设铜匦，告发属实者给追回赃款10%。收益：让赈、军、火器三线的钱都不敢在半路上掉。考成：底线为6队齐备、铜匦成案、追回贪冒银20万两；上考为6队不断档、月核不断、无兴大狱。
3. 邸报、公报、国事立议照秋旧制继续，春季邸报银仍按5万两专款办理，六栏为上谕、捷报、赈灾、廉吏、科普、辟谣，京师每日1刊，各省每旬1刊，里社每月1讲报生；凡重大军国事先经廷议后再登邸报，不许以谣言先入人心。收益：让百姓知道朝廷在办事，官僚知道赏罚有据，谣言就少一半。考成：底线为六栏不断、发行不断、民间谣言不成灾；上考为农民满意度再升2点、官僚满意度回升1点。
4. 专项审计与均平徭役并行，户部、都察院、吏部会同查各省钱粮、军饷、工程，目标追回贪冒银10万两为底线、15万两为上考；地方杂役折银先在3省试办，减民肩头，工匠、农夫得空春种。收益：把冗杂徭役压下去，把可追回的赃银拎出来。考成：底线为3省试办、追回10万两、无加派民田正税；上考为试办扩至6省、追回15万两、农民满意回升。

钦此。
