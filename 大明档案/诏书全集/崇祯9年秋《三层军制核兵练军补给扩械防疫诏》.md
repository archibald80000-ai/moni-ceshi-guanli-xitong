# 崇祯9年秋《三层军制核兵练军补给扩械防疫诏》

奉天承运皇帝，诏曰：

九年夏严边清野、边口禁行、北疆50万两专账、陕西封锁归屯及26万两常赏诸令继续有效，不得因换季停废。今秋后金或再试探宣大，国家主轴转为三层军制改革与全国大训练。此制不是给百万军队换名，而是实行一军一籍、一军一役，明确平时任务、战时任务、调兵权限、军饷、军功和可调数量。兵额原则上不增不裁，所有登记陆师、水师、京营、边军、都卫及特种军，士气与补给均须较季初实值各提高5点；基线95以上者提高至100。任一军未达，即该军未完成，不得以全国平均抵销。

【军事】
命孙承宗以北疆总裁兼领军制总筹，兵部、五军都督府、卢象升及各督抚总兵执行三层军制；秋季只做核兵、定役、编群、试点、轮训，不大裁军、不停饷、不抽空关宁、不大规模跨区换防。

1. 10日内全国每军分列账面、实点、可战、可立即调动4数，并定1项主要军役、1项战时备用军役；同一军、同一人不得重复列入机动、守备、治安三册。缺4数者不得计入战略兵力，重复冒饷者30日内追银10万两为底线、15万两为上考。总兵额季度新增不超过实数2%，底线与上考均不得突破5%。

2. 第一层经制机动军纳关宁可调精锐、白杆、登莱新军、北直隶新军、宣府车营及宣大精选骑炮，精锐池10万至12万人；30日内编东、中、西3战役群，各具铳、枪、车炮、轻骑、工兵、军医、运输和修械。60日内各完成1次实兵合操，90日实际可战8万人、5日可调5万人为底线，可战9万人、可调6万人为上考；不得拆炮营车营填洞，不得为上考抽空原防。

3. 第二层边墙守备军专守口、守城、炮垒、夜巡、烽堠、护民入堡、坚壁清野、守仓和拖敌，未经战区总裁与兵部双令不得跨区追敌。30日内核心关口主将、副将、继任、炮位、粮弹、入堡和第二线全册齐；90日核心关口零失守、守口覆盖95%、炮械可用95%、烽堠中断6时辰内恢复。

4. 第三层京营及地方军转役整训，保留军籍、基本饷与晋升，分可战轮训、工兵、转运、仓医、屯田养马5类。北京京营先试2万人，30日实到1.9万人为底线、2万人为上考；60日承担城防、修路、运粮械、守仓医护、修械养马；90日到岗率95%以上、逃亡低于3%、无哗变。南京及各省各选1营同试。

5. 国库另拨100万两并调军粮30万石、马料20万石：补欠饷伙食35万、训练弹药25万、粮运驿路20万、军医衣被10万、守口夜巡炮手及工兵运输绩效10万。3日先拨低补给军，10日实到95%，30日全国开训，90日每一支登记陆师、水师、京营、边军、都卫和特种军，士气与补给均较季初实值各升5点，上考各升7点；基线95以上升至100即达。任一军未达即该军未完成，不得以全国平均抵销。

6. 全国训练分野战、守备、后勤3科：野战练5日集结、车炮铳枪骑协同和伤员转运；守备练炮位、夜巡、入堡、清野、守仓；后勤练桥路、运输、修械、军医、防火防疫。武备学堂轮训基层军官1000人、炮工军官300人、军需军医官300人为底线，上考1200、360、360，结业30日到营率90%以上。军功分野战、守土护民、军需工程3册，护粮、修桥、救伤、保库、入堡、修械皆可记功。

【内政】
命毕自严、宋应星、王徵、魏照乘保障练兵、军备、防损防疫和秋冬生产；军费不得挤空灾粮，军工不得只报扩厂，防疫不得只建账。

1. 26万两无偿常赏继续照发：犒军5万、官赏5万、养廉5万、农耕10万、吏部考察1万，10日到账95%为底线、100%为上考。官僚、军人、农民、士绅、武勋及朝廷所列主要阶层，均须较季初实值净增1点为底线、2点为上考，任一主要阶层不得下降；军队士气提高5点另按军事条款验收，不以阶层满意代替军心。

2. 国库拨20万两设防损防疫专账：军营净水、厕沟、隔离和药材6万，军械仓防火防潮防鼠5万，军医病舍和疫区转运4万，秋冬衣被、帐幕、伤寒预防3万，紧急备付2万。10日内万人以上军营和重点仓厂完成水源、病舍、厕沟、火药分库检查；30日覆盖90%、上考100%；90日大规模营疫为0，疫病3日内隔离，军械霉坏、火灾、鼠损合计低于库存2%、上考1%。

3. 内帑拨50万两扩军备生产，不另建空壳大厂。京西军械总厂、宣府铸炮厂、京铸厂、官营火枪厂统一样式，分熟铁铜铅硫磺15万、火铳线10万、炮与车架8万、火药铅弹8万、修械备件5万、工匠薪医与安全4万。30日原料实到95%，90日合格火铳6000支、轻炮50门、红夷炮7门、甲盔1000副、修复旧械5000件为底线；上考6300支、52门、8门、1100副、5500件。合格率95%、军中返修率低于5%。

4. 新产和修复军械70%须在验收后10日内交经制机动军与低装备守备军，20%留战区备件，10%留厂周转；只有出厂未到营、到营无弹药、无工匠维护者不计成果。军工须使受援军械可用率提高3个百分点为底线、5个百分点为上考。

5. 全国实际播种土地继续每季净增5万亩为底线、8万亩为上考，只计已下种、有水源、有人耕作且30日未弃耕之田。陕晋豫继续甘薯玉米扩繁、土豆试种和归屯留存；边军屯田不得抽走野战训练时间，第三层屯田营和军属承担生产。季末报新增、复垦、归屯、商屯、灾毁、弃耕6数，以净增相抵。

6. 盐课、市舶、商税、矿课等经常性实收较核定前季增长5%为底线、8%为上考，一次追赃、卖库存和账面应收不得冒充。100万练兵补给、20万防损防疫、50万军备、26万常赏各立专账；夏季北疆50万两专款结余继续原项使用，不重复拨、不挪入军工。季末分列国库、内帑、实银、已拨未付、锁定专款和可自由支配。

7. 工匠、军医、运输夫与屯田军均须有薪粮和伤亡抚恤。事故当日救治、3日内抚恤，隐匿伤亡不得上考。地方官不得借全国训练强征无薪民夫、强占民粮；需用车辆牲畜须给价或立归还册，扰民案件较前季下降10%为底线、15%为上考。

【外交】
命来宗道、杨嗣昌、徐霞客、毛文龙、熊文灿、郑芝龙继续蒙古分化、东江牵制、海贸原料和边情预警，使军制改革不因外敌突袭或原料断绝而中断。

1. 张家口互市10万两旧额不增，7万两守信，3万两只奖提前报兵、拒作向导、截马拖粮、禁硝铁。10日内复核后金马匹、粮车、向导、硝铁、商队和八旗集结6类前兆；3类同现即红灯，4类同指一口即临战。重大情报双源验证率75%、准确率70%为底线，上考85%、73%；入塞预警力争5日，泄密为0。

2. 毛文龙完整保东江，补给较季初提高5点且不得低于70，每月1次有效袭扰为底线、2次为上考，只焚粮囤、毁船械、截盐铁、报兵马，不诱敌围岛、不擅并登莱。东江、登莱、朝鲜、蓟宣边报10日互通，海路不得连续30日中断。

3. 熊文灿、郑芝龙护天津、淮安、温州、广州、泉州旧港，优先输入军备扩产所需硫磺、铜铅、钢铁、药材、船材、量具和钻镗工具。50万军备专款中海外采购部分须30日到货首批，90日原料实到率95%；海贸实收入库较前季增5%为底线、8%为上考。只签合同、仍在海上不得计完成。

4. 外来样机和工艺须由明人工匠拆解、仿制、教学，秋季形成可独立复制工艺3项为底线、5项为上考，每项培养明人工匠10人以上。红夷炮图、火药方、铅模、钻镗图、核心工匠和军制军册外泄为0；荷兰、日本、澳门等商人不得筑堡驻军、独占港口或进入军营查阅三层军册。

5. 朝鲜、琉球及海商线继续传递后金和海路军情。后金若试探宣大，东江袭其辽南粮路，海商优先护运硫磺、铅料和药材；不得因秋季全国训练停断外交、互市和护航。季末报有效军情、后金少得军马向导、东江袭扰、原料实到、护航损失和禁货判决，无实际数者按未完成。

6. 礼部对皇太极僭号不遣贺使、不承认其对蒙古、朝鲜和辽东的宗主权，但不以辱使挑起无准备决战。持勘合商队可按固定路线入市，硝铁、火药、铅料、军器、工匠和地图一律禁出；查获通敌须报数量、主使、去向与判决，不得只报破案。

【其他】
命兵部、吏部、户部、都察院、五军都督府以真实军册、年度考成、继任和奖惩保障军制改革；凡无时限、无实际数、无完成率者不得称功。

1. 三层军制设1年考成：九年秋完成分类、四数、三群、京营试点和全国首轮训练；九年冬完成军饷、军功、训练和调兵细则；十年春扩大京营转役、军需和军官分科；十年夏全国总考。首季必须见精锐池与可调人数、守口覆盖、转役实数、军官到营、军械可用、五日动员、冒饷追回、士气补给和逃亡哗变，不得只报建册。

2. 临时军制总办由兵部尚书与孙承宗以正式官职兼领，每4季年考，满12季只能撤销、并入兵部与五军都督府常制、缩编为正式科司，或有B级以上证据续3年，不得自动成永久衙门。各战役群和转役试点须写正式主管、副职、继任和档案移交对象。

3. 季末一页御前总表按固定顺序列：全国各军四数及军役，三层人数，东中西群可调，守口覆盖，京营转役，军官训练，士气与补给逐军变化，军备实产实交，防疫防损，军费粮料，冒饷，逃亡哗变，各阶层满意，财政实收，实播土地。每项列基线、底线、上考、实际、完成率、证据与判定；无实际数者按未完成，不得以启动、推进、预计、待冬季考成代替。

4. 士气与补给提高5点必须逐军验收。季初95以上升至100即达；因大战、疫病或天灾未达者须报外部冲击和保全结果，免罚但限期补效；因克扣、空练、虚报、军功失信、将领苛虐未达者，主官降等。全国平均上升不能抵销任何一军下降或停滞。

5. 奖励分层落实。经制机动军按集结协同、主力保全、伤员转运记功；边墙军按守口、护民、保仓、夜巡、炮垒记功；后勤军按运输、工程、修械、军医、屯田记功。达到士气补给底线者按主帅、中层、士卒、工匠、军医分别赏，上考另给绩效银，不永久抬高26万两常赏。同一成果不得在3册重复领奖。

6. 调兵权明确：经制机动军由战区总裁与兵部共调，边墙守备军原则不离本防，地方后勤军平时归督抚、入战区归后勤官。任何总兵不得把同一军重复报为守城、野战、治安；不得借改革私扩亲兵、截留新械、强占屯田或任意换将。改革期间不大裁军、不停京营饷、不抽空关宁、不把新军扩至5万、6万。

7. 四权互核照旧：王承恩掌账不掌刑，房壮丽与都察院审账，李若琏暗核，法司定罪。各专账每10日报应拨、实到、已用、在途、结余、实物和受益军队；只有账册没有粮械训练效果者按未拨。隐瞒疫病、事故、逃亡、哗变和军械损坏者，从重问责。

钦此。
