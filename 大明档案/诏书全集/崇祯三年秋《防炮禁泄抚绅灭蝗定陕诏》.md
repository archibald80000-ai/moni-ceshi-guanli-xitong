# 崇祯三年秋《防炮禁泄抚绅灭蝗定陕诏》

- 时间：崇祯三年秋
- 状态：已归档，待游戏执行反馈
- 归档说明：本诏承接崇祯三年夏季朝政纪要。夏季反馈显示陕西民心二十二、动乱风险九十二，起义军约五万五千九百二十一人；江南防蝗翻耕仅五六成，秋蝗仍有中等概率；后金启动红夷大炮获取计划；阉党因魏忠贤五百万死限满意度暴跌。本诏以禁炮图外泄、江南灭蝗抚绅、陕西六个月困剿、阉党追缴降温为秋季主线。
- 下一季提示：崇祯三年冬诏书须转入开源节流与财政现状全盘拆解，重点参考个人战略笔记“财政现状全盘拆解（图内数据核算）”。

奉天承运皇帝，诏曰：

【军事】

命孙传庭总督陕西剿寇，分三阶段六个月困贼、招降、聚歼，先断粮道、收饥民，后图决战。

陕西旱极而蝗，民心二十二，动乱风险九十二，王二、王嘉胤、高迎祥、李自成诸股未平，张献忠又新起，贼势合约五万五千九百余。若遽求大战，则官军九千至万人难以当五倍之众；若坐视流民入贼，则陕西不可复收。今准孙传庭所奏，以六个月为限，分三阶段行事：前两月困兽断粮，曹文诏率精骑二千扰王二老营，夜袭、截粮、焚械，不许孤军深入；秦良玉白杆兵三千分守商洛、蓝田、武关，堵高迎祥、王嘉胤南下；孙传庭坐镇西安，以中军五千为总预备。中两月招抚瓦解，洪承畴于渭南、咸阳、宝鸡、凤翔、延安设粥厂与归降营，降者给粮编册，老弱归农，青壮编屯。后两月聚歼残部，王二、高迎祥、王嘉胤、李自成、张献忠或擒或斩，其胁从无血案者免死。

工部拨火铳五百杆、轻型火炮十门、火药三千斤、铅子一万发、盔甲八百副、刀矛三千柄；太仆寺拨战马三百匹；户部拨银十五万两，其中十万两充军饷赏银，五万两充招抚安置。湖广巡抚三个月内续运粮十二万石入陕，专供降众安置与百姓复耕。孙传庭得以尚方剑摘印四镇拒战、克饷将官，事后报兵部、都察院备案；然不得擅杀降众，不得纵兵入村搜粮。崇祯四年春廷核三事：贼首是否破，百姓是否归农，四镇是否止叛；有一不成，孙传庭自请入京待罪；若粮饷火器迟误，则追问户部、工部、转运官，不独罪前线。

【内政】

命温体仁督浙江、史可法督南直隶、魏照乘督江西，六十日内江南滩涂翻耕九成，钱谦益以大学士衔巡抚苏松常，专司劝绅助蝗、补欠、稳士望。

江南秋粮，系京师与九边命脉。前季翻耕仅五六成，秋蝗之患尚在。今准温体仁所奏，浙江分浙西、浙东、浙南三片，南直隶以苏松常镇为重，江西以沿江沿湖为重。各府县五日内丈量滩涂，十五日内造册，四十五日内翻耕九成，六十日内沟渠、圩堤、捕蝗器具俱备。翻耕须深耕五寸、碾压、漫灌、撒灰，四步俱全方准销册；每百亩设蝗正一名、蝗副二名、民夫二十名，逐日呈报。南京户部再借银五万两，内帑另借银一万五千两，合防蝗旧银支用；浙江六万、南直隶六万、江西三万，余为机动救急。工部加印《捕蝗要术》五百册，每县备捕蝗网五百面、蝗蝻袋一千只、火把三千束、石灰一千斤。

钱谦益不携缇骑，不张声势，巡抚苏松常三府，专劝士绅补缴积欠、出银雇夫、开义仓助防蝗。士绅主动补缴积欠者，免究旧案；捐粮百石、银百两以上者旌表；捐输多者准减护商修渠费一等。然阻挠丈量、隐匿滩涂者，百亩以下罚银二十两，百亩以上五十两，千亩以上百两并枷号三日；侵吞工本银者革职流放。若六十日后浙江、南直隶、江西翻耕不及八成，督臣罚俸；不及七成，知县免职；秋后蝗起而册内无实工者，督臣军法从事。地方不得借防蝗加派田税，不得强征无偿夫役。

【外交】

命孙承宗、卢象升、袁崇焕、毛文龙、来宗道严防后金谋取红夷大炮，东江守牵制，蒙古断向导，朝鲜与海商禁泄火器图法。

己巳之变后，皇太极知其短在攻城重器，今密谋红夷大炮，或收买宣大蓟镇将官，或经朝鲜、蒙古诱取西洋匠人，或由晋商窃运图纸火药。此为心腹大患。命卢象升以九边验饷总督兼查火器外泄，宣府、大同、蓟州、山海关、登莱、天津诸处，三十日内造火炮、火药、铅铁、炮匠、图册五册；军中火炮不得私移一门，火药不得私卖一斤。凡边将、商人、译人、传教士私售炮图、火药、铅铁、铸炮器具与后金、蒙古、朝鲜奸商者，以通虏论斩，家产入官。汤若望、公沙的西劳等西洋技术人员只许在工部、兵部指定工所译书、验炮、授艺，不得入边镇测城，不得私会商旅。

东江五策既转常额，不宜骤然扩成重费大军。毛文龙所奏扩军备战四条，准其分期试行，不准一季尽给。登莱新军三千暂先调一千五百赴皮岛，三批渡海，冬前到齐，明春考核；每季饷银先拨二万五千两，粮每月五百石，火铳先给一千五百杆、火炮十门。东江轻骑二千暂先选辽民八百，购马八百匹，驻义州外牧场须礼部与朝鲜议定，不得强租，不得索朝鲜粮饷。登莱至皮岛海运章程照准，每季福船、沙船编队护送，延误十日罚，失船失饷查责。东江、宁锦、宣大、朝鲜互通军情，后金借道或谋炮有实报者赏；袁崇焕不得擅并东江、擅杀毛文龙，毛文龙不得虚冒兵饷、私设税卡、擅并登莱水师。

【其他】

命王承恩、李若琏、房壮丽、袁可立收束肃贪，废魏忠贤三十日五百万死限，改两月实产核卖，查赃不激变，反腐不断线。

前令魏忠贤三十日凑银五百万两，数额过峻，恐激阉党旧网反噬，今作废。魏忠贤限两月内变卖全部私产，由王承恩、房壮丽监卖核验，以八十万两为实核上限，不足则据实产追缴，不得虚额逼命。崔呈秀、田尔耕、周应秋、张瑞图等核心党羽分档认缴，富者十万至三十万，薄产者一万至五万；自愿缴足、无杀人侵赈重案者，不株连妻儿。底层阉宦家资不足万两者免缴，只登记备案。期满核实无隐匿，免魏忠贤凌迟，削权闲居；若私召旧党、藏匿赃银、交通后金，立下刑部。

京畿百里肃贪十七犯既追回二十万两，仍循七二一例：七成解陕西军饷与赈灾，二成补国库，一成支查案脚价。江南清查仍行一年密核，不得公开逐户清丈，不得夜巡暗抄民田；钱谦益、史可法、温体仁在江南以防蝗、补欠、劝输为主，厂卫只查已列实证。毕自严四权分离继续施行：户部记账，都察院审计，内阁考成，司礼监复核，刑部定罪。秋季考成十事：陕西粮是否入陕，贼势是否止涨，张献忠是否被遏，江南翻耕是否九成，士绅满意是否回升，京畿赃银是否入库，阉党风险是否下降，关宁火器是否无外泄，东江试扩是否成册，后金谋炮是否有线索。实绩者升赏，虚报者降调，扰民误国、通虏泄炮者重治。

钦此。
