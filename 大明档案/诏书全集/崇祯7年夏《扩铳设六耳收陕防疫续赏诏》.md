# 崇祯7年夏《扩铳设六耳收陕防疫续赏诏》

奉天承运皇帝，诏曰：

朕览崇祯7年春诸册：威望至`70`，腐败降至`35`，陕西5股义军补给俱为`0`，新增裹挟约`120人`，新军约`1.76万人`，火铳库存`5.27万支`、季度产量`1000支`，轻型火炮库存`530门`、季度产量`15门`。此皆诸臣用命之效，然贼虽饥疲而未灭，疫气虽防而未绝，军器虽积而产能未足。今夏诸政，不得复以旧额自安，须在春季实绩之上加紧拔高。先申赏格：本季犒军银`5万两`、官僚赏银`5万两`、养廉银`5万两`照旧发放；农民补耕赏银`10万两`改作夏季补种、归屯、疫区农具与秋播备种；吏部考察银`1万两`专供验册、差旅、誊录、取证，不得宴饮馈送。凡银两发放，皆须实发本人、画押入册、4权互核；有克饷、挪赈、虚领、冒功者，先停职，后交审。

【军事】
命孙传庭收陕、卢象升扩新军、宋应星孙元化扩铳炮、杨嗣昌徐霞客建六耳侦军，`90日`内使贼粮不复、火器增产、军情先行。

1. 孙传庭以陕西巡抚兼总督剿寇事，节制陕西、山西、河南3省剿抚兵马；洪承畴专主粮赈归屯，曹文诏领精骑`5000人`，秦良玉领白杆兵守商洛、蓝田、武关、汉中诸要。王嘉胤、高迎祥、王二、李自成、张献忠5股贼众补给既俱为`0`，今夏以“不得复粮”为底线，凡任1股补给复至`1`以上，该路将官罚俸`3月`，督抚具折自陈。曹文诏专行夜袭、断粮、截马、焚贼仓、破小营，不许深入大山孤战；秦良玉截南下就粮之路；洪承畴随军立粮棚、归降营、粥厂，免饥民畏死复投贼。`60日`内破小营`100处`为底线、`130处`为上考；陕西新增裹挟不逾`80人`为底线、不逾`50人`为上考，力争归`0`；`90日`内迫`2股`老营迁徙或溃散为底线，迫`3股`为上考；`6个月`内诸贼主力合计减`40%`为底线、减`60%`为上考。擒斩首恶`1名`，或使`2股`贼众降散过半者，另列上功；杀良冒功、劫粮扰民、逼降民复叛者，以军法治。

2. 卢象升兼督新军3年扩编，宋应星总新工新军，孙元化分督器械火炮。自今仍废“汰旧”之名，只提拔、不裁旧；京营5军营、神枢营、神机营旧兵中，识字习武、无逃兵劣迹者准应试入新军，原营未入选者仍留旧额。新军由约`1.76万人`扩至`2.5万人`为底线，扩至`2.8万人`为上考，3年总额仍定`5万人`。入选本人实赏`2两`，主训军士每练成`1人`实赏`1两`，每名新兵只准`1名`主训官领赏；蓟镇、宣府各出精锐步卒`500人`、炮手`100人`，合`1200人`为骨干教习，每月加银`2两`，分批调入，不空原防。虚冒新兵、重领赏银、借扩军裁旧兵者，革职追赃；达上考者，卢象升、宋应星、孙元化各按实功升叙。

3. 宋应星、孙元化于官营兵仗局外新建官营火枪厂`1座`，用银`20万两`，专取市舶、盐课、矿税、节冗结余支应，不得挤占陕西赈银、农民补耕赏银、东江补给、犒军银、官僚赏银、养廉银。`30日`内定址、定匠、定料、定炉；`60日`内成炉房、木床、钻镗、试铳、火药分库5册；`90日`内试产。崇祯7年秋起，火铳季度产量由`1000支`增至`2000支`为底线、`2300支`为上考；轻型火炮季度产量由`15门`增至`20门`为底线、`25门`为上考。火药、熟铁、铳管、匠户皆另册封存，遗失`1件`即查，私卖后金者以通虏论。

4. 杨嗣昌主六耳侦缉军军情统筹，徐霞客为舆图测路副总，取屯田军、乡勇、边堡熟路兵、归屯青壮中清白精锐，夏季先选`1.2万人`，秋季补足`2万人`训练册。六耳军只掌侦报、舆图、暗号、粮道、边情，不得审案、征税、调兵、抄家、刑讯；其线索交孙传庭、卢象升、袁崇焕、毛文龙、刘泽深、王承恩按原职办理。入选本人赏`2两`，举荐合格赏`5两`，举荐赏须训练`30日`合格后给付。夏季泄密为`0`，扰民案不逾`5起`，陕西粮道图`100幅`、贼营疑报`150条`为底线；秋季5路外派，冬季总验。夏秋2季皆达底线而1季上考者，崇祯7年冬授杨嗣昌正`3品`六耳军主将实职；徐霞客按舆图、水源、道路实绩，升兵部职方司员外郎或郎中。泄密、通贼、私刑、索粮者，不入宽典。

5. 孙承宗仍总裁边防军议，袁崇焕只办辽西换防与宁远、山海关前哨收容，不许出塞浪战；毛文龙完整保东江镇，专行小股袭扰、截盐铁、报后金兵马，东江补给不得低于`65`，军册、船册、火器册按月报兵部。辽西遗炮为`0`，边墙外遗民为`0`，大同、宣府、蓟州诸口烽堠不断报。守口、夜巡、护民入堡、炮手退敌者叙功；擅自出塞野战，虽有斩获，不叙功。

【内政】
命毕自严、洪承畴、宋应星、王徵续发5项赏银与补耕防疫钱粮，补齐春季种具`8成`未满之缺。

1. 毕自严以户部总理钱粮，今夏5项银分账支给：犒军银`5万两`直发诸营，官僚赏银`5万两`给办疫、赈旱、清边、核账、推种、督运有实者，养廉银`5万两`按九品考第给基层州县、仓场、驿递、医药、工务吏员，农民补耕赏银`10万两`给夏季补种、归屯、疫区农具与秋播备种，吏部考察银`1万两`给验册、差旅、誊录、取证。5项合计`26万两`，不得均分，不得挪作宴饮、迎送、修署。王承恩掌账，房壮丽审账，李若琏密核，内阁复核；每`10日`具实发数、未发数、驳回数、追赃数入册。

2. 洪承畴主陕西粥厂、归降营、归屯田。春季归降入屯约`4000人`，夏季新增归屯`6000人`为底线、`9000人`为上考；归屯丁口须有姓名、籍贯、原属贼营、家口、耕地、农具6项，缺`2项`以上不得入赏册。粥厂守卫仍以老成兵丁`30人`守`1厂`，不许向饥民索钱索粮；疑似贼探者先隔审，不得株连同棚饥民。归屯青壮可编屯田营，边耕边守，不得私役为奴。降而复叛且劫粮杀人者治罪；胁从未杀官劫库而自首者给粮、给种、给具。

3. 宋应星、王徵督夏季补种与秋播备种。春季种具到位约`8成`，今夏须补齐至`100%`为底线，按灾区丁口另备秋播种具`30%`为上考。陕西、山西、河南、乌思藏按地宜分给粟、黍、麦、豆、耐瘠杂粮与农具、水车、井绳；灾区无偿给付，常省采用种贷，秋收后还种不取息。每县设种圃`1处`，府仓设存种册，发种须有村正、里甲、农户`3方`画押。倒卖官种、以劣换良、扣留农具者，官吏革职追赃，民间豪强加倍追还。

4. 陕西、山西疫气未尽，洪承畴、魏照乘、地方巡按会医官设病舍、药仓、净井、焚秽、埋葬5册。陕西疫区病舍`50处`为底线、`80处`为上考；山西、河南旧疫村须每`5日`报病亡、迁徙、给药、给粮数。不得封村断粮，不得弃尸入河，不得驱逐病民入邻县；病民粥药同给，老弱先给。药材银`2万两`从疫前药仓库支给，不得挤占补耕赏银；贪药价、囤药材、虚报病亡者，交刘泽深会3法司审。

5. 钱谦益、史可法继续抚绅助饷与新学安民。江南秋前不新增隐田追缴，不公开全域清丈；士绅捐粮、献种、修渠、助药仓、助伤兵棉衣者，给匾、记志、商税减等`1次`，但不得凭捐免罪、不得借名侵吞官种。应天、苏州、松江、常州、杭州、嘉兴6学继续收实学子弟，农、算、工、医、火器诸科优先，官绅子弟入学须甄试，不授官、不占科举正额。

【外交】
命来宗道、毛文龙、熊文灿、郑芝龙守蒙古互市、东江牵制、5口海贸禁炮旧制，不增旧额而加军情核验。

1. 来宗道仍主蒙古互市与边外军情。互市循春季旧额`10万两`，先给`7万两`以守信义，余`3万两`凭军情、拒作向导、截马、禁硝铁实绩给付，不增旧额，不断旧信。察哈尔、土默特有报后金远征、退兵、转粮、借道者，按实给赏；科尔沁、喀喇沁愿报路线、拒为向导者加茶绢盐引，私导后金入塞者停赏、绝市、入黑册。宣大互市官每`10日`报市马、茶绢、盐引、军情4册；虚造军情领赏者革职追银。

2. 毛文龙保东江敌后牵制，仍以皮岛为根本，铁山、义州停泊补水，辽南小股登岸只焚粮囤、毁船械、截盐铁、报兵马，不求大捷，不许诱后金主力围攻皮岛。东江边报每月送兵部，并抄山海关、蓟宣、登莱；后金有远征林丹汗或调兵转粮之机，东江可择风信袭扰辽南粮路，事后`10日`具报，不得擅并登莱水师，不得索朝鲜粮饷，不得私设税卡。东江补给不得低于`65`，船册、粮册、火器册缺报`1月`，毛文龙罚俸；军情有效使后金回兵或分兵者，东江将士给赏。

3. 熊文灿、郑芝龙护广州、宁波、泉州、漳州、登莱5口海贸税路，并禁硝磺、熟铁、炮书、炮匠北流。大商分级纳税，小商、小贩、近海渔户不得骚扰；海贸税、盐课、矿税中应拨火枪厂者，须立专账，不得私扣。郑芝龙护商船队每月报船数、税数、禁货、获私4册；获硝磺、炮书、熟铁北贩实证者，按值给赏`10%`；私纵1船者，主事官罚俸`6月`，再犯革职；通后金者以通虏论。

4. 朝鲜、琉球、澳门诸线只用于东江停泊、海贸税路、铸炮工艺、军情互通。外籍炮匠可教铸炮、测算、钻镗，不得入兵部密册，不得知山海关、蓟宣、东江军机。汤若望、公沙的西劳等西学人员只许在宋应星、孙元化名下办理历法、炮术、测算、工艺，不授刑名、税课、兵权。泄火炮尺度、火药配方、铳管工艺者，不论华夷，按军法治。

【其他】
命王承恩、李若琏、房壮丽、刘泽深、李国普行4权互核与夏秋2季考察，冬季验杨嗣昌、徐霞客、宋应星、卢象升升降。

1. 王承恩掌账不掌刑，刘泽深掌刑不掌账，房壮丽审账，李若琏掌密核，内阁复核，司礼监封册，仍行4权互核。今夏会核国库、内帑、4库、商税、盐课、矿税6账，并区分实银、实粮、实药、账面冲抵4类。凡犒军、官赏、养廉、农赏、吏部考察、火枪厂、六耳军首赏，皆单独成册；不得以账面冲抵冒称实发，不得把赈粮折银虚报，不得把官种算作商税入库。每`30日`王承恩呈账册，房壮丽附审语，李若琏附密核，李国普附考第。

2. 刘泽深会袁可立旧章与3法司，继续在陕西、山西、河南交界设流动查账4队，每队刑部司官、巡按御史、锦衣卫清慎官各`1人`，核赈银发放册、军饷实收册、粥厂米数、乡勇粮册、火器禁泄案。府县衙外仍设铜匦，告发属实者给追回赃款`10%`；诬告`3人`以上反坐；证据不足不得兴狱。王承恩不得越权定罪，锦衣卫不得借密报私拿士绅，刑部不得借审案查账夺银；违者同以越权论。

3. 李国普总铨选考成，夏季新增4硬8辅。4硬为：陕西5贼补给维持`0`、新增裹挟不逾`80人`；新军达`2.5万人`且虚冒不逾`1%`；火枪厂`90日`试产并成5册；六耳军泄密`0`且首批`1.2万人`成训。8辅为：小营破`100处`、归屯新增`6000人`、补种具至`100%`、病舍`50处`、东江补给不低于`65`、互市军情有效`6条`、海贸禁炮零外泄、官僚与军人满意不跌。达底线者留任记功；达上考者晋`1阶`或加衔；未达底线者停本季赏银、九品考第降`1级`；因洪疫不可抗者准限期补效，虚报者不准。

4. 吏部、内阁同立诸臣功过册。孙传庭、洪承畴、曹文诏、秦良玉以定陕实绩考；卢象升、宋应星、孙元化以扩军、扩铳、零虚冒考；杨嗣昌、徐霞客以六耳选训、舆图准确、扰民泄密考；来宗道、毛文龙、熊文灿、郑芝龙以互市军情、东江补给、海贸禁炮考；毕自严、王承恩、李若琏、房壮丽、刘泽深、李国普以5项赏银实发、6账4类清楚、贪腐不反弹考。冬季总验，杨嗣昌合格授正`3品`六耳军主将；徐霞客合格升职方司员外郎或郎中；宋应星、卢象升、孙元化达火器新军上考者升叙。贪挪、克饷、遗炮、通虏、扰民者虽有他功，皆先问罪。

钦此。
