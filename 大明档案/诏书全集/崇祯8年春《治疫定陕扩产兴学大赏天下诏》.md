# 崇祯8年春《治疫定陕扩产兴学大赏天下诏》

奉天承运皇帝，诏曰：

先申赏格：本季犒军银5万两、官僚赏银5万两、养廉银5万两、农民春耕赏银10万两、吏部考察银1万两照旧发放，不得短给，不得均分，不得改拨。另以内库拨50万两大赏天下，专分5路：农政推种修渠库20万两，工部增产火器冶造库12万两，科举新学实学库8万两，文官民生水利赏格库5万两，边民市井安业平粜库5万两。又以内帑10万两、国库10万两，合20万两，另设5路专项：防疫治疫5万两，春赈归屯6万两并粮4万石，清鼠尸净井源2万两，六耳军专款3万两，吏部考成养廉4万两。凡本季得赏者，军前守口、断粮、护民、办疫、修渠、推种、兴学、核账皆先赏后考；克扣、冒领、虚报、挪用者，虽有他功，先停职下狱。

【军事】
命孙传庭、曹文诏、秦良玉乘贼疫后饥疲，90日内分割粮道、焚仓截马、压诸贼不得复补；卢象升固宣大，宋应星、孙元化扩火器，杨嗣昌统六耳军侦缉晋商炮书与蒙古借道，不许主动与后金决战。
1. 孙传庭仍以陕西巡抚兼总督剿寇事，坐镇西安，节制陕西、山西、河南3省赴陕剿抚兵马；洪承畴专主粮赈归屯，曹文诏领精骑5000人，秦良玉领白杆兵守商洛、蓝田、武关、汉中。今春以5股流贼补给不得复起为死线，王二、王嘉胤、高迎祥、李自成、张献忠任1股补给复至1以上，该路总兵罚俸6月，巡抚具折待罪。曹文诏专行夜袭、断粮、截马、焚仓、破小营，不许深入大山孤战；秦良玉专断南下就粮诸道，不许擅离关口；洪承畴于西安、延安、凤翔、庆阳、渭南续设归降营、粥厂、粮棚，兵到处先立粮棚，不使饥民畏死复投贼。30日内成兵册、粮册、路线册、招降册、粥厂守卫册；60日内破小营寨100处为底线、130处为上考；90日内迫2股老营移徙、溃散或分裂为底线，迫3股为上考；180日内诸贼主力合计减30%为底线、减50%为上考；本季陕西新增裹挟不逾80人为底线、不逾50人为上考，力争归0。擒斩首恶1名，或使2股贼众降散过半者，另列上功，赏银500两至2000两，军前立碑记名。
2. 卢象升兼督宣大、蓟州固防与新军扩编，仍行“只提拔、不裁旧”。宣大、蓟州、大同守口军、夜巡军、护粮军、炮手营，凡冬季有功者先发犒军银5万两中的应得份额；大同、宣府、蓟州守口、护民、修墙、验炮诸营，90日内须补齐城上火药、铳炮、滚木、礌石、夜巡、护民入堡6册。大同、宣府、蓟州烽堠、敌台、壕沟、拒马、护粮队再验1遍，遗炮仍须为0。擅自出塞野战，虽有斩获不叙功；守口、夜巡、护民入堡、炮手退敌者，加倍叙功。宣大、蓟州、大同本季不得抽调逾实兵2成赴陕，原防须留7成以上。
3. 宋应星总新工新军，孙元化分督器械火炮。宣府铸炮厂本季开炉试产，年产红夷大炮6门之局不得改；火铳季产冬季已达3000支，今春须稳在3000支为底线、3600支为上考；轻型火炮季产32门为底线、40门为上考。工部增产火器冶造库12万两内，先拨4万两给宣府铸炮厂，3万两给官营火枪厂，2万两给熟铁、木床、钻镗、铳管、试放，2万两给火药、铅子、火绳，1万两给匠户安置与废品回炉。大同、宣府、蓟州、山海关缺炮缺铳者优先补给，不许先供空库后供实战。
4. 杨嗣昌总六耳侦缉军，徐霞客以员外郎衔专副舆图测路。今春六耳军只掌侦报、舆图、暗号、粮道、边情、疫区流徙，不得审案、征税、调兵、抄家、刑讯。六耳军专款3万两，只许支舆图、脚价、暗哨、密语、伤病、回报，不许另立杂费。陕西粮道图新增120幅为底线、180幅为上考；贼营疑报新增180条为底线、260条为上考；后金、蒙古、晋商炮书线索15条为底线、24条为上考；准确率须守72%以上，泄密仍为0。军情若实使官军焚贼仓、夺粮车、截炮书、破借道，杨嗣昌、徐霞客与分路主官并叙功；若越权扰民、假报冒功、勒索商旅，一律夺职。
5. 孙承宗仍总裁边防军议，袁崇焕只办宁远、山海关前哨收容与辽西换防余务，不许出塞浪战；毛文龙完整保东江镇，专行小股袭扰、截盐铁、报兵马，不得擅并登莱，不得索朝鲜粮饷。关宁、宣大、蓟州、东江各成月报，东江补给不得低于65，宣大遗炮仍须为0，蒙古借道若有实情，先报兵部、再报六耳，不得迟误。

【内政】
命毕自严、魏照乘、洪承畴、宋应星、王徵总治疫、春赈、归屯、推种、兴工，先把50万两春季大赏用于农工学政，再把20万两5路专项分账实拨，不加民田正税，不行全国清丈。
1. 毕自严以户部总理钱粮，今春旧5项照发之银26万两，仍照旧章分账画押。另以内库50万两大赏天下，立5库：农政推种修渠库20万两，工部增产火器冶造库12万两，科举新学实学库8万两，文官民生水利赏格库5万两，边民市井安业平粜库5万两。又以内帑10万两、国库10万两合20万两，另立5路专项：防疫治疫5万两，春赈归屯6万两并粮4万石，清鼠尸净井源2万两，六耳军专款3万两，吏部考成养廉4万两。凡3层银粮，皆不得互相冲抵，不得挪宣大固边、东江补给、陕西药粮既有专库。每10日王承恩呈实发数、未发数、驳回数、追回数，房壮丽附审，李若琏附密核，内阁复核。
2. 魏照乘会太医院、地方巡按、医官总办防疫。防疫治疫5万两，先补药材、粗布、石灰、棺木、煎药锅、隔棚、医官脚价。陕西、山西、河南、甘肃各设常设药仓与病舍，陕西、山西各增医官20人，河南、甘肃各增10人。病舍100处为底线、150处为上考；常设药仓120处为底线、180处为上考；春分前净井、焚秽、掩埋、隔离、施药5册必须齐备。不得封村断粮，不得弃尸入河，不得驱病入邻县。病故家属每户给抚恤银2两，粥药同给。清鼠尸净井源2万两专用，石灰深埋、井口加盖、仓场熏洗，春分前三省须毕；虚报病亡、囤药牟利、挪药银者，以侵赈论。
3. 洪承畴主陕西春赈归屯，孙传庭副核名册。春赈归屯6万两并粮4万石，只许给粥厂、归降营、屯田营、病民药汤，不得拨作边防军饷。归降营验身、验籍、验病、验械4项并行，病民先医后屯，壮者编屯田营，老弱入赈籍。今春新增归屯1.2万人为底线、1.8万人为上考；归屯田春播入册8万亩为底线、12万亩为上考。各粥厂加药汤，每厂守卫老成兵30人，不许向饥民索钱索粮。若归屯册有人无地、有人无种、有人无具，洪承畴与地方州县同罪。
4. 宋应星、王徵总领农政推种修渠与工坊兴作。农政推种修渠库20万两内，先拨8万两买谷种、豆种、麦种、耐旱杂粮种，4万两办农具、水车、井绳、牛具，4万两修井渠、堰坝、沟洫，2万两补仓棚、谷库，2万两补各省种圃与试验田。今春井渠600处为底线、900处为上考；仓棚650处为底线、900处为上考；谷库120座为底线、180座为上考；新增开垦复种60万亩为底线、90万亩为上考。番薯、玉蜀黍、早熟麦豆择地试种，灾区种子无偿给付，常省采用种贷，秋收后还种不取息。倒卖官种、以劣换良、扣留农具者，官吏革职追赃，豪强加倍追还。
5. 科举新学实学库8万两，礼部、国子监、各省学政分办。应天、苏州、松江、常州、杭州、嘉兴6学继续办，另于北直隶、山东、湖广、山西、河南、福建新开6学为底线、再开12学为上考，合计12学底线、18学上考。收实学子弟1200人为底线、1800人为上考；农、算、工、医、火器、西学译算诸科并举。秋前定恩科章程，补录实学、律学、算学、农学、火器学诸生150人为底线、220人为上考。官绅子弟可入学，但须甄试，不授官、不占正科额。陈新甲监督新学名册与会试条陈，不许借新学植党。
6. 钱谦益、史可法继续抚绅助饷与安民。江南不新增隐田追缴，不公开全域清丈；士绅捐粮、献种、修渠、助药仓、助学舍、助工坊者，给匾、记志、商税减等1次，但不得凭捐免罪、不得借名侵吞官种与官银。文官民生水利赏格库5万两，只赏办疫、修渠、安民、督运、推种有实者，不得均分。

【外交】
命来宗道、毛文龙、熊文灿、郑芝龙守蒙古分档互市、东江牵制、5口海贸禁炮旧制，续稳白银税源，截断后金火器输入，不扩大高耗银外战。
1. 来宗道仍主蒙古互市与边外军情。互市照冬季旧额10万两，先给7万两以守信义，余3万两凭军情、拒作向导、截马、禁硝铁实绩给付，不增旧额，不断旧信。察哈尔、土默特报后金调兵、转粮、借道、归师者，按实给赏；科尔沁、喀喇沁愿报路线、拒为向导者加茶绢盐引，私导后金入塞者停赏、绝市、入黑册。今春有效军情10条为底线、15条为上考；虚造军情领赏者革职追银。
2. 毛文龙保东江敌后牵制，仍以皮岛为根本。辽南小股登岸只焚粮囤、毁船械、截盐铁、报兵马，不求大捷，不诱后金主力围攻皮岛。东江边报每月送兵部，并抄山海关、蓟宣、登莱；后金若借蒙古故地转兵，东江可择风信袭粮路，事后10日具报。东江补给65为底线、70为上考；船册、粮册、火器册缺报1月者罚俸。不得擅并登莱水师，不得索朝鲜粮饷，不得私设税卡。
3. 熊文灿、郑芝龙护广州、宁波、泉州、漳州、登莱5口海贸税路，并禁硝磺、熟铁、炮书、炮匠、火药方、铅子模具北流。大商分级纳税，小商、小贩、近海渔户不得骚扰；海贸税、盐课、矿税中应拨工坊、学舍、药仓者，须立专账，不得私扣。郑芝龙护商船队每月报船数、税数、禁货、获私4册；获硝磺、炮书、熟铁北贩实证者，按值给赏10%；私纵1船者，主事官罚俸6月，再犯革职；通后金者以通虏论。
4. 朝鲜、琉球、澳门诸线只用于东江停泊、海贸税路、铸炮工艺、军情互通。外籍炮匠可教铸炮、测算、钻镗，不得入兵部密册，不得知山海关、蓟宣、东江军机。西学人员只许在宋应星、孙元化名下办理历法、炮术、测算、工艺，不授刑名、税课、兵权。陈新甲奉旨护持新学与西学名册，但不得干预工部炮局制造。泄火炮尺度、火药配方、铳管工艺者，不论华夷，按军法治。

【其他】
命王承恩、刘泽深、房壮丽、李若琏、李国普行4权互核，陈新甲督反贪、科举、新学、西学稽核，务使文武分权、账刑分离、赏罚明白，兼安官僚之心，不使朝堂因军政偏重再起怨望。

1. 王承恩掌账不掌刑，刘泽深掌刑不掌账，房壮丽审账，李若琏密核，内阁复核，司礼监封册，仍行4权互核。今春会核国库、内帑、4库、商税、盐课、矿税6账，并区分实银、实粮、实药、账面冲抵4类。凡犒军、官赏、养廉、农赏、吏部考察、50万两春赏、20万两专项，皆单独成册；不得以账面冲抵冒称实发，不得把赈粮折银虚报，不得把官种算作商税入库。每30日王承恩呈账册，房壮丽附审语，李若琏附密核，李国普附考第。
2. 刘泽深会3法司，继续在陕西、山西、河南交界设流动查账4队，每队刑部司官、巡按御史、锦衣卫清慎官各1人，核赈银发放册、军饷实收册、粥厂米数、归屯粮册、火器禁泄案。府县衙外仍设铜匦，告发属实者给追回赃款10%；诬告3人以上反坐；证据不足不得兴狱。王承恩不得越权定罪，锦衣卫不得借密报私拿士绅，刑部不得借审案查账夺银；违者同以越权论。
3. 李国普总铨选考成，今春改立4硬10辅。4硬为：陕西5贼补给维持0且新增裹挟不逾80人；防疫药仓、病舍、净井诸册如期实到；火铳季产不低于3000支、轻炮不低于32门；50万两大赏天下与20万两专项分账无挪移。10辅为：小营破100处、归屯1.2万人、井渠600处、仓棚650处、谷库120座、新学12所、补录实学诸生150人、东江补给不低于65、有效蒙古军情10条、官僚满意止跌回升。达底线者留任记功；达上考者晋1阶或加衔；未达底线者停本季赏银、九品考第降1级；因疫荒不可抗者准限期补效，虚报者不准。
4. 陈新甲由吏部保举，擢左佥都御史，专督反贪、科举、新学、西学事，不兼巡抚，不掌兵，不理军饷。90日内须具反贪复勘册、会试条陈册、新学名册、西学护持册4册；180日总验。若能整饬学政、补实新学、肃清借学营私、平衡士林与西学之议，成底线者加衔记功，达上考者再议升转；若借学植党、借反贪牵连无辜、压制西学工艺、朋附门户者，即夺职听勘。
5. 钱谦益、史可法仍主江南士绅安抚与文官民生之心。今春特别明示：军政虽急，文官民生、水利、学政亦有专赏。凡办疫、修渠、办学、赈民、核账、督运有实者，官僚赏银5万两与文官民生水利赏格库5万两合并分档，不得只向军前倾斜。官僚满意若再下滑，则内阁与吏部具折自陈；若回升至40为底线、45为上考，则李国普、陈新甲、钱谦益、史可法并叙功。

钦此。
