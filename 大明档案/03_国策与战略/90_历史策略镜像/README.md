# 国策路线：历史兼容镜像

本目录是旧版 `data/strategy.json` 的 Markdown 汇总入口，用于程序兼容和历史检索。

- 它会同时包含执行中、待执行、已写入诏书、下一季建议、长期规划和历史项目。
- 因此，它不是“当前长期国策清单”，也不能单独证明策略已经下诏或完成。
- 当前长期制度请读 `../01_制度规则/关键制度源头/01_长期国策有效清单.md`。
- 年度和跨季方向请读 `../02_战略方针/README.md`。
- 当前执行项目请读 `../../00_总览/战略项目台账.md`。

程序可以继续更新 `国策路线.md`，但 AI 不得再把该汇总文件整体当作当前国策。
