# 已执行方案目录

本目录中的方案均经玩家确认，属于曾在实际游戏流程中采用、下令或执行过的真实历史资料，不再按“备选方案”处理。

## 证据边界

- 这里证明某项方案曾进入执行流程，可用于追溯当时的目标、安排和设计思路。
- 方案正文中的兵额、钱粮、产量、期限等可能是命令值或目标值；实际完成量仍以对应季度朝政纪要、游戏截图和当前快照为准。
- 本目录不是当前国策入口，也不是新方案草稿区。不得因为历史方案写有“长期”“继续”就自动判定其在崇祯十二年春仍然有效。
- 当前有效长期制度查 `../01_制度规则/关键制度源头/01_长期国策有效清单.md`；新国策方案统一进入 `../04_国策设计/`。

## 当前内容

- 辽东、东江与己巳阻断：辽东均衡、东江五策、坚壁清野、辽东行动与密侦方案。
- 军工与工业：京西兵工厂、火器换代、天工格物。
- 情报训练：六耳军训练方案；长期情报制度源头另见 `../01_制度规则/关键制度源头/`。
- 季度专项：夜袭马场、开厂增税、五年春开局等当时实际采用过的方案。

跨年度总方向位于 `../02_战略方针/`；正式下达的命令位于 `../../01_季度政务/02_诏书/`；实际结果位于 `../../01_季度政务/03_朝政纪要/`。
