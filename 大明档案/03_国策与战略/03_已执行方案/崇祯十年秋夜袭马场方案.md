崇祯十年秋-夜袭马场
夜袭方案：铁岭马场为主 · 鞍山驿粮仓为辅
目标——马匹全收、粮草得手、速决全归我手一、核心目标

- 主攻：沈阳以北铁岭卫马场（约800匹战马，守兵约100，木栅无高墙，有喂马旧部可下药）。
  → 抢马为主，能带走多少算多少，余者纵火惊散或射杀，不留清军。
- 辅攻：辽阳以西鞍山驿粮仓（约8000石，守兵不足100，驿丞可策反）。
  → 烧仓或抢运能运走的部分，重点切断运粮要道。
- 原则：夜袭、速决、得手即撤，所有缴获马匹、粮草、物资当场归我，不留、不弃、不分散。

二、兵力与任务

- 主力：新军精锐2500–3000人（优先骑兵与轻装火枪手）+ 关宁/转役精锐500人。
  新军直接受益：抢到的马匹立刻交新军骑走，当场提升新军骑兵实力与士气。
- 内应配合：  
  - 铁岭喂马旧部：提前下药，使马匹夜间昏沉。  
  - 鞍山驿丞：先付银200两，开仓门或减少巡丁。  
  - 祖大寿暗线：提供实时路线与撤退指引。
- 指挥：前线由黄得功或指定可靠将领带队，卢象升遥控，祖大寿负责内应与退路。

三、行动步骤（必须速决）

1. 时机：无月或浓云夜，清军夜巡最松时段（祖大寿提供具体时辰）。
2. 铁岭马场（先打）：  
   - 沿辽河故道潜入 → 内应下药生效 → 精兵破栅 → 抢马（优先好马）→ 能骑走的立刻由新军骑手控制 → 余马纵火惊散或处理 → 快速撤离。
3. 鞍山驿粮仓（同时或稍后）：  
   - 侧翼小路逼近 → 驿丞开仓 → 抢运能运部分 + 火攻其余 → 得手即走。
4. 撤退：统一走柳河故道/预定路线，祖大寿暗线接应，全程轻装快速。
5. 当场处理：  
   - 马匹：立刻点交新军，编入骑兵序列。  
   - 粮草与物资：能运则运，不能运则烧；当场按缴获数量给参战官兵奖励（银两或实物），激励士气。

四、预期效果

- 军事：清军损失战马数百匹 + 粮台被毁，辽东机动与补给大挫。  
- 新军：直接获得大批战马，骑兵实力与实战经验双提升，士气忠诚再涨。  
- 全国：捷报一出，军人与民心再振，抵消此前负面。  
- 暗线：祖大寿价值再次验证，后续可继续加压。

五、密旨要点（可直接下）「准以新军为主力，夜袭铁岭马场并鞍山驿粮仓。马匹全部交新军，粮草物资能收尽收，当场论功行赏。祖大寿全力配合内应与路线。速战速决，得手即撤。捷报至日，重赏。」
