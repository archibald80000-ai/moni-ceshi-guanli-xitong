# 战略方针目录

战略方针回答“未来一年或若干季度优先往哪里走、资源先给谁、哪些红线不能破”。它不是永久国策，也不是已经发生的结果。

## 与其他目录的区别

| 目录 | 核心问题 | 默认有效期 |
|---|---|---|
| `01_制度规则/关键制度源头/` | 国家长期按什么规则运行 | 直至修订或废止 |
| `02_战略方针/` | 未来一段时间优先实现什么 | 文件注明的年度或季度范围 |
| `03_已执行方案/` | 过去某个目标实际采用过什么方案 | 历史执行材料，实际结果另查纪要 |
| `04_国策设计/` | 准备建立或修订什么长期制度 | 提案，须经密谈、诏书与反馈验证 |
| `01_季度政务/04_执行任务/` | 本季试什么、做到多少 | 一季或注明的试行期 |
| `01_季度政务/02_诏书/` | 玩家实际下达了什么 | 自下诏起，按条款续行或到期 |

### 历史计划与复核

保存原始方案、长期记忆和事后复核。它们是真实且曾进入执行流程的计划／规则原稿，但不能覆盖正式诏书和游戏结果。

## 新战略方针最小字段

- 起止季度；
- 决定性主攻、两项硬支援、维持线；
- 继承的长期国策；
- 暂停或试行的政策；
- 资源上限与禁止事项；
- 每季度验收点；
- 到期后的结案、续期或改版。
