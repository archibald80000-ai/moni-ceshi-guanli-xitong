# AI起草与档案规则

本目录保存诏书模板、writeimperial 规则和滚动记忆，只约束 AI 怎样读档、计算和写作。

这些文件不属于游戏内国策，不能用来证明某项政策已经下诏或完成。

## 因果合同

- 规则源流归档稿：`政令与诏书技能规则归档稿.md`，保留原文和历史哈希，不直接作为可调用 Skill。
- 正式本地 Skill：`skills/writeimperial-causal-ledger/SKILL.md`。
- 使用范围：皇庄、农业、军工、矿业、商贸、水利、赈灾、整军和大型建设等需要“资源—投入—产出—成本—收益—验收”闭环的政令。

正式 Skill 可以整理政策推演和验收合同，但不得把推演目标写入朝政纪要或当前事实；实际结果仍须等待下一季度游戏反馈。
