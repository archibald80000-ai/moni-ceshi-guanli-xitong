# 制度规则目录

本目录只回答两个问题：国家长期按什么制度运行，以及 AI 应怎样读取这些制度。

## 必读入口

1. [关键制度源流总览](关键制度源头/00_制度源流总览.md)
2. [长期国策有效清单](关键制度源头/01_长期国策有效清单.md)
3. [季度试行与非永久政策清单](关键制度源头/02_季度试行与非永久政策清单.md)

## 子目录职责

| 子目录 | 内容 | 是否属于游戏内长期国策 |
|---|---|---|
| `关键制度源头/` | 考成、分权、军制、情报、国本等制度原稿与源流索引 | 是，但完成情况仍须 L3 结果证明 |
| `AI起草与档案规则/` | 诏书模板、技能规则和滚动记忆 | 否 |
| `游戏机制与参数/` | 游戏循环、参数和公开机制整理 | 否 |

战略方向不放在这里：年度或跨季优先级进入同级 `02_战略方针/`，新制度方案进入同级 `04_国策设计/`，历史已执行方案进入同级 `03_已执行方案/`，当季试行和硬目标进入 `01_季度政务/04_执行任务/`。
