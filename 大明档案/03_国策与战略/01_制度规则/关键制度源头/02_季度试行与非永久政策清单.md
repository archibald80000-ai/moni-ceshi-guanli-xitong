# 季度试行与非永久政策清单

> 目的：防止 AI 把历史上某一季的试行税率、预算、行动目标和旧计算公式，当成当前仍须执行的全国国策。

## 一、制度试点

| 事项 | 原始性质 | 正确处理 |
|---|---|---|
| 一条鞭折银核账 | 崇祯元年冬的统一核账工具 | 只保留“统一折算、便于稽核”；不等于全国摊丁入亩或全面清丈 |
| 沿海分等工商费 | 五口阶段试行 | 税率、港口和对象到期复核，不自动推为全国商税 |
| 鱼鳞册一年密核 | 一年期秘密查账 | 只能提供核验线索；未到公开清丈条件不得直接拿人追赃 |
| 皇田、王田试征 | 局部税源试点 | 不代表民田正税提高，也不代表全国推广 |
| 政策沙盒 | 两季度试验机制 | 每个沙盒到期必须扩面、修正或终止 |
| 京营转役首批 | 军制试点 | 后续已被三级军制吸收；旧首批人数不是当前固定兵额 |

## 二、季度行动，不属于国策

- 夜袭马场、焚粮、夺械、某一路辽东破袭；
- 某季赈银、犒军银、宣传银、开厂专款和工程首期拨款；
- 浙江调粮一万石、内帑四万两修堤等一次性救灾处置；
- 十一年冬查禁社团、解散聚会等高压维稳行动；
- 某季新增工厂数、工程数、军械产量、移民人数和销售额；
- 某一任临时总办、专使、查账队或试点机构。

它们可以证明当季采取过行动，但除非后续诏书明确续行，不能自动写入十二年春长期国策。

## 三、跨季项目，不属于永久制度

| 项目 | 当前期限或验收点 | 判断规则 |
|---|---|---|
| 七十六处水泥工程 | 计划崇祯12年夏总验 | “全部启动”不等于“全部完工” |
| 皇家琉璃百窑 | 延期至12年春达产 | 投产窑数、产量、交货、实收分开 |
| 全国驿道仓储物流首期 | 计划12年秋完工 | 逐站工程和运营账验收 |
| 五港预约 | 交货后再算实收 | 定金、订单、在途不得算销售 |
| 四总社十城联营 | 每季独立核算 | 股本、库存和内部划拨不得算收入 |
| 辽东六线 | 每线每季复核 | 情报过期或暴露必须降级、停线或换线 |

## 四、已经失效或被替代的通用规则

- 旧版统一“底线加30%、上考加50%”不再适用；现按任务类型、实际基线和执行系数计算。
- 上一季诏书目标不能作为下一季实际基线。
- 兵额、固定赏银和常设机构不得因换季自动增长。
- 产能、预计、启动、在途、定金和账面冲抵不得视为实际成果。

## 五、季度试行转为长期制度的条件

1. 有正式诏书明确续行或固化；
2. 至少取得一季游戏结果，证明直接产出和制度效果；
3. 负责人、正式主管机关、预算来源、审计、继任和日落规则齐全；
4. 未造成不可接受的扰民、越权、腐败或财政负担；
5. 写入 [01_长期国策有效清单.md](01_长期国策有效清单.md) 后，才作为默认持续政策读取。
