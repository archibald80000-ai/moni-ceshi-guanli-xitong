# 03_国策与战略

这里回答“长期按什么制度治理”“未来优先做什么”“新制度怎样设计”和“过去实际采用过哪些方案”。游戏实际结果仍只进入季度纪要和当前事实档案。

| 目录 | 含义 |
|---|---|
| `01_制度规则/` | 当前长期国策、制度源流、AI规则和游戏机制 |
| `02_战略方针/` | 年度与跨季优先方向、资源边界、已批准跨季项目 |
| `03_已执行方案/` | 玩家确认曾采用或执行过的历史方案；目标数不等于实际结果 |
| `04_国策设计/` | 新长期国策、制度改版与废止提案的唯一工作区 |
| `05_玩家笔记/` | 玩家教训、偏好和尚未形成正式方案的想法 |
| `90_历史策略镜像/` | 旧策略 JSON 生成的兼容汇总，不判定当前国策 |

新国策先在 `04_国策设计/` 明确基线、机制、试行和退出条件；取得正式诏书与游戏反馈并由玩家确认固化后，才写入长期国策有效清单。
