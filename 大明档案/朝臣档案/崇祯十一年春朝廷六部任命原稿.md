# 朝廷六部任命



六部统一定额：

- 尚书1人；
- 左侍郎1人；
- 右侍郎1人；
- 堂官6人。

合计54个核心职位。

### 吏部

- 尚书：周延儒；
- 左侍郎：郑三俊；
- 右侍郎：史可法。

六堂官分掌文选、考功、验封、稽勋、考成稽核、养廉核发。

### 户部

- 尚书：毕自严；
- 左侍郎：王三善；
- 右侍郎：蔡懋德。

六堂官分掌度支、仓场、盐铁、市舶、农政、通货。

### 礼部

- 尚书：来宗道；
- 左侍郎：倪元璐；
- 右侍郎：何宗彦。

六堂官分掌仪制、祠祭、主客、精膳、新学科举、邸报。

### 兵部

- 尚书：卢象升；
- 左侍郎：杨嗣昌；
- 右侍郎：徐霞客。

六堂官分掌武选、职方、车驾、武库、军制改革、三级军营务。

### 刑部

- 尚书：刘泽深；
- 左侍郎：方岳贡；
- 右侍郎：金光辰。

六堂官分掌律例、审决、恤刑、赃罚、四权互核、锦衣协查。

### 工部

- 尚书：宋应星；
- 左侍郎：孙元化；
- 右侍郎：王徵。

六堂官分掌营缮、虞衡、都水、屯田、军械总局、四社监督。
