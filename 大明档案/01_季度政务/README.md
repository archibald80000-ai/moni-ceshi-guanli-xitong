# 01_季度政务

每回合只走一条线：上季结果 → 本季密谈 → 正式诏书 → 执行任务 → 下季反馈。

| 目录 | 内容 | 事实效力 |
|---|---|---|
| `01_密谈/` | 拟诏问题、臣工意见和备选路线 | 非事实 |
| `02_诏书/` | 玩家正式提交的诏书 | 证明已下令 |
| `03_朝政纪要/` | 游戏AI返回的季度结果 | 游戏结果 |
| `04_执行任务/` | 当季目标、试行、督办和验收尺度 | 待反馈 |
| `05_当前工作台/` | 当前季度缺口与准备材料 | 工作入口 |
| `data/quarterly_workflows.json` 与当季 `季度闭环工作单.md` | 密谈、核验、草稿、玩家确认、反馈回填的协作材料 | 不能单独证明事实 |
| `季度记录汇总（系统生成）.md` | JSON历史记录的阅读镜像 | 兼容汇总 |

推荐通过网页“季度闭环”维护工作单。工作单会落在 `05_当前工作台/<年份>/<季节>/季度闭环工作单.md`，但不会自动把草稿写入正式诏书，或把未收到的游戏反馈写入朝政纪要。完整协作规则见 `../00_总览/AI协作与季度闭环操作手册.md`。
