# 崇祯五年春季朝政纪要

# ——急饷堵大同，三省联控断流民，后金北征塞外



## 朝政纪要



陛下本季颁下数道紧要谕旨，涵盖军事、内政、外交及财政考成四大端。军事上，旨命卢象升以兵部尚书衔总督大同、宣府、蓟镇急防，十日内遣部院官赴大同核实五册，户部拨急救银十二万两、粮三万石、马草折银二万两，三十日内实到营中；左良玉暂署大同机动副将，领精骑步卒二千专司夜巡哨探；袁崇焕续撤辽西前突堡寨，六十日内撤民、撤粮、撤炮入宁远、山海关，不能运者毁之；孙元化署登莱军械海运督办，核船炮匠册；毛文龙东江镇趁后金北征袭扰辽南粮囤盐场。内政上，命孙传庭总陕晋豫截流剿抚，洪承畴坐镇西安主赈务，三十日内设归降营、粥厂、屯田棚于潼关、蒲坂、黄河渡口、晋南、豫西等处；户部拨赈抚银十五万两、粮八万石、屯田种具银三万两；史可法巡按河南山西，查赈务积弊；魏照乘改督简易常平仓与疫前仓储；徐霞客测陕晋豫流民道路水源图；王徵督造水车铁锄辘轳。外交上，命来宗道维持蒙古互市，熊文灿、郑芝龙护海贸禁炮，礼部续联朝鲜。财政上，命毕自严、王承恩立四库分账，李若琏署密核副使，三硬七辅考成。



现将各项诏令执行实情与因果始末分条奏报如下：



**一、大同急饷与左良玉到任**



户部奉旨，自国库拨银十二万两、粮三万石、马草折银二万两（合计约十六万两等效），三十日内解往大同。然因军人阶层满意度仅十七，对朝廷命令消极抵制，实际到营效率约七至八成。大同边军士气由三十回升至三十四，补给由五十二升至六十，忠诚度由五十四升至五十六，止住了士气逼近二十溃败底线的滑坡趋势。底线“大同士气不再跌破二十”已守住。



左良玉暂署大同机动副将，领精骑步卒二千专司夜巡、哨探、烽堠接火、三日驰援，受卢象升节制。左良玉原为辽东副总兵，为人桀骜不驯、作战勇猛但军纪败坏。卢象升以兵部尚书衔强力监督，诏书明令不得纵兵入村索粮，此约束得以部分执行。到任后，大同士气因勇将提振再增一（已在急饷效果中合并体现），但驻地附近民心因军纪问题微降，山西民心由四十四降至四十三。满桂重伤未愈，保留大同总兵原职，机动营实际由左良玉代领。



**二、辽西换防与东江牵制**



袁崇焕奉旨专办锦州以东、大凌、小凌、右屯、松山、塔山诸前突堡寨第二批撤民、撤粮、撤炮。孙元化加署登莱军械海运督办，核登州、天津、宁远船册、炮册、匠册，遇陆路受阻即以海船转运。因国策【研究海道针经】及【文武分工原则】之长期影响，海运效率稍有提升，后勤行政管理效率亦有所提高，撤运工作得以推进。底线“辽西遗炮为零”正在执行中。



毛文龙东江镇奉旨趁后金北征林丹汗之际，遣小股舟师袭扰辽南粮囤、盐场、船械。东江镇执行攻击任务后，补给因战斗消耗由六十五降至六十，但成功牵制后金后方，迫其分兵守后。皮岛未被围攻。



**三、陕晋豫三省联动封控与赈抚**



孙传庭奉旨总陕晋豫截流剿抚，洪承畴坐镇西安主赈务。三十日内，潼关、蒲坂、黄河渡口、晋南、豫西、米脂、延安、商洛诸处设归降营、粥厂、屯田棚。户部拨赈抚银十五万两、粮八万石、屯田种具银三万两。受军人和士绅双重抵制，实际执行效率约六至七成，但仍可分流部分饥民不投贼。



陕西春耕赈抚一年期评估于本季完成。此前投入内帑四十万两及湖广调粮十五万石，加之四仓存粮约十二至十四万石、粥厂运作及以工代赈，共同遏制大规模饥荒死亡。旱情从严重降为中等，但蝗灾持续。饥荒死亡约三千至五千人（远低于无赈济情景），约八千至一万二千饥民编入工程营。陕西民心由二十升至二十三，动乱风险由九十四降至九十二。起义军裹挟增速放缓：五支起义军合计新增约二千二百辅兵（低于冬季二千七百人），总兵力约七万二千三百人。



曹文诏精骑断粮道、秦良玉守商洛蓝田武关，使起义军补给受困。王二、王嘉胤、高迎祥三部士气各降一点（王二由二十四降至二十三，王嘉胤由二十七降至二十六，高迎祥由二十七降至二十********、徐霞客测图与王徵督造农具**



徐霞客以兵部职方司主事身份，三十日内测黄河渡口、潼关、蒲坂、晋南豫西山路、水井、险隘，绘成《陕晋豫流民道路水源图》供孙传庭封口设卡。其地理学专业能力使测图精准可用，下季度剿寇效率可能小幅提升。



王徵加督水车、井渠、屯田农具，协工部尚书宋应星造水车百具、铁锄千柄、简易辘轳五百具，优先给陕西旱区与河南流民屯棚。王徵精通中西学问，曾与邓玉函合译《远西奇器图说》，农具设计制造质量有保证。预计崇祯五年夏季完成验收。



**五、史可法巡按与魏照乘改任**



史可法以右佥都御史衔加巡按河南山西职能，专查州县借赈扰民、豪强闭仓抬价、军士杀良冒功。其奏章与王承恩密册互核，形成都察院与内廷双重监督。



魏照乘由江西防蝗旧任改督简易常平仓与疫前仓储，先在河南、山西、陕西交界州县立小仓，每县至少备粟二百石、药材十箱，并造鼠毙、疫疾、井水、粮仓四册。



**六、疫前防范启动**



内帑拨药材银二万两（内帑其他支出由每季一万两增至三万两）。太医院会礼部、户部及地方府县，三十日内造北直隶、山西、陕西、河南、山东五省疫册，各府设空屋为病舍，备艾、苍术、石灰、醋、粗布、棺木。底线：疫未发而册药俱备者记功，疫发隐匿不报、弃尸入河、盗卖药材者从重。



**七、廷议总清算与沿海商税**



廷议总清算一年到期，皇帝决定继续冷冻——不发动大规模清洗，证据封存，保持“只查账不查封”状态。腐败分子恐慌缓解，但证据持续积累。腐败度维持五十不变。



沿海商税三等制试办到期，已转为常法，每季约增六至九万两专项收入。熊文灿、郑芝龙继续护五口海贸，禁炮硝北流。郑芝龙忠诚度三十，在已招安框架下维持合作。



**八、四库分账制度确立**



毕自严、王承恩奉旨立四库：大同急救库（只给急饷、口粮、马草、烽堠）、陕晋豫赈抚屯田库（只给粥厂、归降、屯田、种具）、辽西换防库（只给撤民、撤粮、撤炮、海运）、疫前药仓库（只买药材、净井石灰、病舍木料、粮仓鼠患器具）。四库各存正副册，户部一册、内廷一册、都察院一册，月终互核。三硬底线（大同急饷实到、陕晋豫流民粮册归降屯田册成、辽西遗炮为零）一项不成主官不得升迁。



李若琏署北直隶、大同、辽西三路密核副使，统锦衣卫清慎校尉二十四员，只查账册、实物、签押、仓粮、炮械，不许夜入民宅、拷掠取供、借疫册扰民。



**九、后金远征林丹汗与蒙古互市**



皇太极趁春季草青，率八旗精锐约五至六万及科尔沁部约一万五千北征察哈尔林丹汗。来宗道奉旨维持察哈尔、土默特互市常额十二万两加军情赏格三万两，实到不低于七成（约十万五千两每季）。林丹汗若遣使乞粮马药箭镞，只给可守可走之物，不给火炮火铳。大同哨探与蒙古互市监察官每十日互抄军情，确认后金主力北向后，大同、宣府闭堡聚民、整骑夜巡，勿出塞邀功。科尔沁、喀喇沁诸部若报后金行军路线、拒作向导者，加给马市优先、盐引小额。此三路并举（东江袭扰、蒙古互市情报、蓟宣大同哨探）可耗后金粮马、迟其归师，但不足以改变战局。



**十、贵州、四川、云南三省及福建、江南局势**



西南三省奢安之乱平定近两年，处于战后恢复期。四川民心六十二、贵州五十七、云南五十八，相对稳定。川兵五千北上援陕削弱四川本地防御，但秦良玉留一部驻川震慑土司，本回合无特殊事件触发。



福建郑芝龙已被招安授福建副总兵，忠诚度三十，海军实力远超福建水师。五口商税三等制已转为常法，郑芝龙月呈船册、人册、炮械册、税册。福建叛乱风险四十偏高，与郑芝龙势力半独立状态有关，本回合无特殊事件触发。



江南（南直隶、浙江、江西）已从蝗灾中恢复大半。南直隶民心六十二、浙江七十五、江西六十二，均相对稳定。士绅满意度三十七处于中等偏低水平，主要因防蝗考成压力、隐田密核、百一工税试征等累积。士绅对新一轮疫册造册可能产生新的抵触。



## 数值变化说明



**国库余额（-7,667,251两 → -8,092,251两）**：国库其他支出由每季五十六万一千两增至八十八万一千两。其中拨付大同急救银十二万两、粮三万石、马草折银二万两（合计约十六万两等效），拨付陕晋豫赈抚银十五万两、粮八万石、屯田种具银三万两（合计约二十六万两）；另有沿海商税三等制转为常法，每季增约六至九万两，部分抵消支出。综合各项收支，国库赤字加深。



**内帑其他支出（每季一万两 → 三万两）**：内帑拨药材银二万两用于疫前防范，故内帑其他支出由每季一万两增至三万两。



**陕西民心（20 → 23）**：陕西春耕赈抚一年评估正面，旱情从严重降为中等，四仓存粮加粥厂运作及以工代赈遏制大规模饥荒死亡，民心回升。



**陕西动乱风险（94 → 92）**：春耕赈抚见效，灾民被分流编入工程营，起义军裹挟增速放缓，动乱风险下降。



**河南民心（21 → 23）**：三省联动粥厂设立，分流饥民，民心微升。



**山西民心（44 → 43）**：左良玉到任大同机动副将，其军纪败坏导致驻地附近民心微降（联动粥厂本可加一，扰民减一，净变化为零后再因军纪问题额外减一）。



**大同边军士气（30 → 34）**：户部拨付急饷约七至八成到营，左良玉勇将提振士气，止住溃败滑坡。底线“士气不再跌破二十”已守住。



**大同边军补给（52 → 60）**：急饷到营，粮草马草到位，补给显著改善。



**大同边军忠诚度（54 → 56）**：急饷发放缓解欠饷不满，忠诚度微升。



**宣府边军士气（39 → 40）**：大同急饷及卢象升督军提振临近边镇士气，宣府士气微升。



**蓟州边军士气（36 → 37）**：同上，蓟镇士气微升。



**东江镇军补给（65 → 60）**：毛文龙遣小股舟师袭扰辽南粮囤盐场，战斗消耗补给，补给下降。



**王二起义军士气（24 → 23）**：曹文诏精骑断粮道，三省封控线限制补给，士气下降。



**王嘉胤起义军士气（27 → 26）**：同上，士气下降。



**高迎祥起义军士气（27 → 26）**：同上，士气下降。



**军人阶层满意度（17 → 19）**：大同急饷缓解部分不满，但山东镇军满饷率仅三成、河南都卫三成，整体欠饷未解决。满意度微升，仍抵制命令但叛逃势头减缓。影响力维持八十不变。



**士绅阶层满意度（39 → 37）**：疫册造册和仓储要求增加基层负担，士绅满意度微降。影响力维持七十不变。



**农民阶层满意度（4 → 6）**：陕西赈抚延续加三省联动粥厂缓解部分饥荒压力，满意度微升。



**东林党满意度（32 → 34）**：孙承宗留阁、史可法巡按，东林党势力稳固，满意度微升。



**皇党满意度（37 → 39）**：王承恩四库分账、李若琏密核、卢象升前线督军，皇党控制力增强，满意度微升。



**皇党影响力（55 → 57）**：同上，皇党影响力增强。



**大明威望（43 → 44）**：皇帝整顿财政、加强边防、联动三省展现治理能力，威望微升。



**腐败度（50 → 50）**：廷议总清算继续冷冻，四权分离查账制度持续运作但无新抓捕，腐败维持不变。

**左良玉**：原任辽东副总兵，本季加“暂署大同机动副将”衔，领精骑步卒二千受卢象升节制。



**孙元化**：原任登莱巡抚，本季加“署登莱军械海运督办”衔。



**史可法**：原任右佥都御史、督催南直隶防蝗，本季加“巡按河南山西”衔。



**魏照乘**：原任督催江西防蝗，本季改任“督简易常平仓与疫前仓储”。



**王徵**：原任辽海监军道，本季加“督水车井渠屯田农具”衔。



**徐霞客**：原任兵部职方司主事，本季加“测陕晋豫流民道路水源”职。



**孙传庭**：原任陕西巡抚、总督陕西剿寇、获尚方剑、兵部右侍郎，本季加“总陕晋豫截流剿抚”衔。



**洪承畴**：原任总理陕西赈务招抚、增设延安绥德鄜州收容点、陕西按察副使，本季加“坐镇西安主赈务”衔。

**王承恩**：原任司礼监秉笔太监、东厂提督、节制魏忠贤南下清查、锦衣卫巡查总管、掌秘密调查阉党旧赃东林贪墨、持节督办京畿肃贪、监卖核验魏忠贤私产、总全国四账稽查，本季加“会四库分账”衔。

**满桂**：大同总兵，重伤未愈，保留原职，机动营实际由左良玉代领。



## 总结



大同急饷到营堵住了边镇最危险缺口，三省联动封控分流饥民遏制起义军裹挟增速，四库分账制度确立使财政管理趋向专款专用，后金北征林丹汗为明军赢得牵制之机。然国库赤字进一步加深至八百余万两，军人阶层欠饷未解、士绅阶层对疫册负担不满，起义军总兵力仍超七万二千人，对孙传庭约一万五千官军形成近五比一兵力悬殊。局势在危机中勉强稳住，但根基仍极脆弱。
