# 崇祯11年冬《刷新军建足械兴商裕民收官诏》

奉天承运皇帝，诏曰：

十一年秋，王三善、蔡懋德接掌财赋，靖边授旗，百万亩屯田验实八十万亩，辽东破袭夺马八百五十、得械四千四百、焚粮三千七百石，琉璃总厂实销十五万、净收益六万，海贸、盐课、防疫皆有实效。然三军仅战兵八万二千、辅兵三万五千、侦骑二千，满编约八成五至九成；红夷炮原令五百门仅成十五门；二十六处建筑仅北直四处及南直约五六处完工，军械到团、建筑逐项和全国面板仍未完整刷新。

今据御前确认，朕权威九十九，朝堂腐败为零，军民士绅与各派人心皆安，军人、农人满意度九成以上；国库每季真实结余二百万两以上，专款一季结清；文武匠才与商贾充足，两京十三省顶级富商逾万；军政、通商、防疫、基建诸制已成。故今冬不再以钱粮、人手、阻力为辞，以“军械实发到团、三军实编收口、四类面板同步刷新”为决定性主攻，以火炮产能改造、二十六处建筑全验为两项硬支援；工商收益、人才到岗、民生防疫继续年度收官。

凡兵、械、炮、马、厂、仓、港、渠、税、民心发生变化，必须同日回填国家总面板、三军九团面板、军械库存面板、建筑面板和省级面板。任一面板未更新、同一数字前后不一或只报总数不报到营到用，相关任务一律判失败。

【军事】

命孙承宗总裁冬季军政，卢象升总领兵籍与战备，徐霞客总核军械马政，杨嗣昌只核情报和数据；满桂、左良玉、黄得功及九军团主官逐团具结。

1. 三军定额仍为战兵九万、辅兵四万五千、直属侦骑五千，总额十四万，不另扩纸面兵额。九十日实到战兵不少于八万九千一百、辅兵四万四千五百五十、侦骑四千九百五十，各团满编率不低于九十九；五日可调六万二千、训练九十八、军械可用九十九、正饷到账九十九、逃亡低于一。靖边既已授旗，不得撤号，虎大威未达者按缺额逐旬补齐。

2. 兵部三日内统一秋季库存冲突，以实物复点为准；十日内建立九团装备分册。每团必须列冷兵器、火铳、燧发枪、甲胄、轻炮、红夷炮、战马的理论、拨出、到营、可用、在修、报废和缺口。燧发枪现存一万支，九团实发九千、武备与维修储备一千；火铳每团三千二百，轻炮每团六十，战马每团三千，直属侦骑五千匹；红夷炮一百零五门按天枢四十、地维三十五、人和三十实装，均须试射画押。

3. 甲胄库存六万七千一百副为秋初口径，冬季新交六千副、上考八千，优先补天枢、合锋、靖边；各团须报有甲战兵和过渡棉皮甲实数。冷兵器、火铳库存充足，不得以库存充足代替到营；军械实发率、可用率任一低于九十九，该团不得评上等。

4. 原增造红夷炮五百门总令不撤，但改为产能与交付双考。宋应星、汤若望九十日交合格新炮六十门、七十二门上考，将年产能力由三十三门提高至二百四十门；每炮须有炮身、炮架、药弹、炮组和试放记录。另交线膛枪六十支、机动野战炮十二门，完成射程、故障、返修和改型册；十二年秋前累计补足五百门。

5. 九级军阶实名、实职、实辖、记功、等次、赏银和处分覆盖百分百。武备首批应毕业一千零四十、试任到岗九百三十六；冬季再招一千三百。单位六项评分与个人三项评分同日写入军团面板，五次有效记功方升一级，军阶不得代替实职兵权。

6. 辽东以祖大寿八处乙级情报维持压力，不为收官强求大袭。黄得功、吴三桂只在内应、退路、援军预警齐备时择一处短袭；底线夺马五百、得械三千、焚粮二千五百石、归队九十三、伤亡低于八。情报不足则改截硝、误调、断运，不攻坚、不追敌、不以无辜人员造功。

【内政】

命首辅王三善总年度收官，蔡懋德总财政执行，宋应星总建筑军工，周延儒总人才考成；四权互核恒久施行，腐败维持为零。

1. 国库冬季真实净结余不低于二百万两、二百二十万上考；所有专款当季分账、当季关账。四总社冬季实销四十五万、五十万上考，净收益十二万、十四万上考，实税五万、六万上考；全年累计实销不低于一百一十五万、净收益三十万、实税十二万。股本、库存、内部调拨和应收不得冒充收入。

2. 秋季二十六处建筑原令继续。北直四处和南直已成者复验，其余十六至十七处三十日完成主体、六十日设备交割、九十日全部投入使用。每处必须更新名称、地区、主管、预算、实支、工程量、完工率、使用率、维护费变化、运输损耗变化和产能收益；二十六处完工率百分百、使用率九十五、维修或运输成本下降十二为底线。缺一处逐项数据，建筑总任务判失败。

3. 皇家琉璃由熊文灿经营、内廷监事审账，冬季透明器一百四十件、彩色器二百五十件，实销二十万、净收益八万，工资到账百分百、泄密为零。两京十三省逾万富商实行实名竞售，不限虚价，只认成交与入库；禁止以权势强买强卖。

4. 百万亩屯田清册、验实九十、实耕八十万维持，不盲目增册；冬季重点考亩产、入仓、农户余粮和税户。实耕留存九十五、商品粮较秋增八、屯户粮银收入增三点为底线，粮价上涨不得超过五。三级屯田军三万二千人实岗九十五以上。

5. 山陕豫鼠疫死亡由二万八千压至一万八千以内、一万二千上考；军营疫损再降三成。全国军人、农民满意度维持九十以上，其他群体不得净降超过一点；水利、种粮、商贸补助只按实际受益户发放，不再普遍撒银。

6. 文科、工科、武备三线冬季实际毕业到岗合计不少于一千五百人；秋冬特科再录三百六十、御前特荐三人，艺学局实训到岗二千。只入学不毕业、只录取不到岗者不计人才产出。

【外交】

命何宗彦暂总礼部与海贸，倪元璐主邸报新学；吏部三日推礼部尚书与海贸总核候选三人，朕十日钦定。熊文灿专掌寰海经营，不兼地方行政。

1. 广州、泉州、天津、淮安、温州五市舶与登莱军港继续统一税票。冬季六口实税二十二万、二十四万上考，商贸货值较秋增十、十二上考，平均报关三日、上考二日；逐港更新货值、税银、船次、损耗、欠税和主要商户，不得只报增长率。

2. 长芦、山东、浙江盐课冬季新增实课五万、六万上考；张家口互市旧额不增，实购战马一千匹、耕挽畜一千五百头，损耗低于六。沧溟军团及三水师护航九十日不断，海运损失率低于三。

3. 皇家琉璃、棉纺、农具、水机和非核心军需扩大外销，新增大额订单须报预付款、交货、实收与税银。炮图、火药方、线膛工艺、母机和核心匠师不得出境；完成两次诱饵测试和两路审计，泄密为零。

4. 祖大寿、沈应时、黄蜚专线继续；甲级军情同报御前、孙承宗、黄得功。每季八处目标必须更新储量、守兵、换班、内应、路线和证据日期，旧情报超过三十日未复核自动降一级。

【其他】

命内阁、兵部、户部、工部在季末同日刷新全套面板，不得先报捷、后补数。

1. 必更面板为：国家总面板、六部人事、三军九团兵力、九级军阶、军械库存、九团装备到营、二十六处建筑、四总社、六口海贸、两京十三省及辽东省级面板。每项均列秋末基线、冬季投入、实际结果、完成率、证据等级、责任人和判定。

2. 面板刷新以兵籍、饷册、武库领讫、军团签收、工程验收、税银入库六证互核。同一兵、械、炮、马、建筑、货物和税银不得跨表重复；红夷炮二百零七与二百二十二、国库不同口径等冲突，十日内统一并保留差异说明。

3. 强制失败规则：实际任务完成而面板未更新，按未完成；面板更新而无原始凭证，按虚报；总库存更新而九团到营未更新，军械任务失败；建筑总数更新而逐项状态未更新，工程任务失败；省级建筑、军队、财政任一未同步，相关主官不得记功受赏。

4. 冬季年度总考只认面板最终值。完成底线且数据闭环者记功；达到上考者优先升阶升职；低于八成者冻结下一季扩张并更换办法，低于六成者换主官。皇权九十九、腐败为零、钱粮人才无阻而仍失职者，从重论处。

钦此。
