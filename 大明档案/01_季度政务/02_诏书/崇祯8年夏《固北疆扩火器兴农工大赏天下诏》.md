# 崇祯8年夏《固北疆扩火器兴农工大赏天下诏》
奉天承运皇帝，诏曰：
先申赏格：本季犒军银5万两、官僚赏银5万两、养廉银5万两、农民备耕银10万两、吏部考察银1万两照旧发放，不得短给，不得均分，不得改拨。另以内库50万两大赏天下，专分5库：农政推种修渠库25万两、工部增产火器冶造库15万两、科举新学实学库5万两、文官民生水利赏格库3万两、边民市井安业平粜库2万两。又另立100万两北疆专款，专修宣大、蓟镇、大同、山海关、喜峰口、龙井关、大安口、杀胡口、镇羌堡、古北口、居庸、独石诸口墙台、敌台、烽堠、壕沟、拒马、炮位、马草、机动营与粮仓，不得与前项互冲。前列20万两五路专项照旧：防疫治疫5万两、春赈归屯6万两并粮4万石、清鼠尸净井源2万两、六耳军专款3万两、吏部考成养廉4万两。凡银粮皆立专账，账面冲抵不得冒作实发，王承恩、房壮丽、李若琏、内阁4权互核。凡得赏者，军前守口、断粮、护民、办疫、修渠、推种、兴学、核账皆先赏后考；克扣、冒领、虚报、挪用者，虽有他功，先停职下狱。

【军事】
命孙传庭、曹文诏、秦良玉乘贼疫后饥疲，90日内分割粮道、焚仓截马、压诸贼不得复补；卢象升固宣大、宋应星孙元化扩火器、杨嗣昌徐霞客商人化侦缉六耳，孙承宗总裁北防，不许主动决战。
1. 孙传庭仍以陕西巡抚兼总督剿寇事，坐镇西安，节制陕西、山西、河南3省剿抚兵马；洪承畴专主粮赈归屯，曹文诏领精骑5000人，秦良玉领白杆兵守商洛、蓝田、武关、汉中。今夏以5股流贼补给不得复起为死线，王二、王嘉胤、高迎祥、李自成、张献忠任1股补给复至1以上，该路总兵罚俸6月，督抚具折待罪。曹文诏专行夜袭、断粮、截马、焚仓、破小营，不许深入大山孤战；秦良玉专守南下就粮诸道，不许擅离要口；洪承畴于西安、延安、凤翔、庆阳、渭南续设归降营、粥厂、粮棚，兵到处先立粮棚，不使饥民畏死复投贼。30日内成兵册、粮册、路线册、招降册、粥厂守卫册；60日内破小营130处为底线、170处为上考；90日内迫3股老营迁徙、溃散或分裂为底线，迫4股为上考；180日内诸贼主力合计减50%为底线、减65%为上考；本季陕西新增裹挟不逾50人为底线、不逾30人为上考，力争归0。擒斩首恶1名，或使2股贼众降散过半者，另列上功，赏银500两至2000两，军前立碑记名。敢勇营从归屯降众中择精壮无血债者编成，3000人为底线、5000人为上考，专用于追割贼后、断其外援、护其粮道，不得独立夺城，不得私自劫掠；每成1人赏银2两，举荐合格赏银5两，敢勇营只受孙传庭、洪承畴、曹文诏3线节制。军功只赏守口、夜巡、护民入堡、炮手退敌、随军断粮、焚仓截马者；擅自出塞野战，虽有斩获不叙功，折兵失堡者降调。
2. 卢象升兼督宣大、蓟州固防与新军扩编，仍行“只提拔、不裁旧”。宣大、蓟州、大同守口军、夜巡军、护粮军、炮手营，凡夏季有功者先发犒军银5万两中的应得份额；大同、宣府、蓟州守口、护民、修墙、验炮诸营，90日内须补齐城上火药、铳炮、滚木、礌石、夜巡、护民入堡6册。大同、宣府、蓟州烽堠、敌台、壕沟、拒马、护粮队再验1遍，遗炮仍须为0。擅自出塞野战，虽有斩获不叙功；守口、夜巡、护民入堡、炮手退敌者，加倍叙功。宣大、蓟州、大同本季不得抽调逾实兵2成赴陕，原防须留7成以上。北疆专款100万两，按35万两修墙台与烽堠、25万两补炮位与火药、20万两编机动骑兵与步哨、10万两买马草与粮仓、10万两赏守口与夜巡、各镇以3日一报、10日一验为限；三镇守备若因修防有成，士气底线40、上考45，补给底线70、上考75。宣府铸炮厂、官营火枪厂同步扩炉，火铳季度产量由3000支抬至4500支为底线、5000支为上考；轻型火炮季度产量由32门抬至45门为底线、55门为上考。工匠、铳管、火药、铅子、试放、木床、钻镗7册，30日内齐备；遗失1件即查，私卖后金者以通虏论。
3. 杨嗣昌仍统六耳侦缉军，徐霞客仍副舆图测路；六耳军今夏改以商队掩护、边外潜行、粮道核验、火器外泄缉查3路并进，只掌侦报、舆图、暗号、粮道、边情，不得审案、征税、调兵、抄家、刑讯。取屯田军、乡勇、边堡熟路兵、归屯青壮中清白精锐，夏季先选1.5万人，秋季补足2万人训练册；伪装晋商、茶商、马帮之商队30支，分往张家口、杀胡口、镇羌堡、河套、辽南、宣大6路，只准采情，不准扰民。夏季粮道图180幅为底线、240幅为上考；贼营疑报220条为底线、300条为上考；后金、蒙古、晋商炮书线索18条为底线、30条为上考；准确率须守80%以上，泄密仍为0。六耳商队若使官军焚贼仓、夺粮车、截炮书、破借道，杨嗣昌、徐霞客与分路主官并叙功；若越权扰民、假报冒功、勒索商旅，一律夺职。夏秋2季皆达底线而1季上考者，冬季授杨嗣昌正3品六耳军主将实职；徐霞客按舆图、水源、道路实绩，升兵部职方司员外郎或郎中。
4. 宋应星、孙元化于官营兵仗局外再扩火枪厂、火炮局与试放棚，专为北疆、东江、敢勇营、守城军供给。火枪工坊、熟铁场、火药房、铳管床、钻镗匠、试放手6项各立1册，60日内成册可验；今夏火枪与轻炮产能须较春季再抬50%：火枪季度产量由3000支抬至4500支为底线、5000支为上考；轻炮季度产量由32门抬至45门为底线、55门为上考。火器不先供空库后供实战，先保大同、宣府、蓟州、山海关、东江、敢勇营6处。北疆专款不与火器厂银冲抵，工部若挪用一两，先罚主事，后追工价。

【内政】
命毕自严、洪承畴、宋应星、王徵总治疫、春赈、归屯、推种、商屯、兴工，先把50万两大赏天下用于农工学政，再把20万两5路专项分账实拨，不加民田正税，不行全国清丈。
1. 毕自严以户部总理钱粮，今夏5项银分账支给：犒军银5万两直发诸营兵丁画押；官僚赏银5万两给办疫、赈旱、清边、核账、推种、督运有实者，不得均分；养廉银5万两按九品考第给基层州县、仓场、驿递、医药、工务吏员；农民备耕银10万两专给夏补种、秋播备种、农具、水车、井绳；吏部考察银1万两只准验册、差旅、誊录、取证。5项共26万两，皆须实发本人、画押入册、4权互核。王承恩掌账，房壮丽审账，李若琏密核，内阁复核；每30日具实发数、未发数、驳回数、追回数入册。50万两大赏天下仍分5库：农政推种修渠库25万两、工部增产火器冶造库15万两、科举新学实学库5万两、文官民生水利赏格库3万两、边民市井安业平粜库2万两；本季农工两库目标较春季再抬50%，不得空投文字，不得只赏不办。若农政、工部未把农具、种子、井渠、工坊、铳炉做实，管事官从严扣赏。
2. 洪承畴主陕西粥厂、归降营、归屯田。春季归降入屯约9000人，今夏新增归屯1.5万人为底线、2万人为上考；归屯丁口须具姓名、原籍、原属贼营、家口、田亩、农具6项，缺2项以上不得入功册。粥厂守卫仍以四镇老成兵丁30人守1厂，专防贼探混入、米粮被劫、降而复叛，不许向饥民索钱索粮。归屯青壮可编屯田营，边耕边守，不得私役为奴；降而复叛且劫粮杀人者治罪，胁从未杀官劫库而自首者给粮、给种、给具。夏秋前须使西安、延安、凤翔、庆阳、渭南5路归屯田各成春秋播册，不得有册无人、有人无具、具到无粮之弊。商屯戍边同步试行：在宣大、陕西、山西荒地招商屯田，底线8万亩、上考12万亩，商人免税3年，产粮只卖官府，官府给价不得低于市价；商屯若能代替一半以上远途运粮，则宣大、陕西运损可减一成以上。
3. 宋应星、王徵督夏修井渠仓棚谷库与来秋种具。春季续建已起，今夏以井渠800处为底线、1100处为上考；仓棚700处为底线、900处为上考；谷库150座为底线、210座为上考。陕西、山西、河南、乌思藏按地宜分给粟、黍、麦、豆与耐瘠杂粮种，另给水车、井绳、锄镰、牛具。灾区无偿给付，常省采用种贷，秋收后还种不取息。每县设种圃1处，府仓设存种册，发种须有村正、里甲、农户3方画押。倒卖官种、以劣换良、扣留农具者，官吏革职追赃，豪强加倍追还。农民补耕不止于口粮，今夏再给春秋接茬工具、磨石、镰刀、畚箕、井绳，使来年增产可核。番薯、玉蜀黍、早熟麦豆、耐旱黍稷择地试种，灾区种子无偿给付，常省采用种贷，秋收后还种不取息。
4. 山西、陕西、河南旧疫未尽，魏照乘、地方巡按、医官会办病舍、药仓、净井、焚秽、埋葬5册。春季病舍药仓已成一批，今夏药仓达150处为底线、200处为上考；病舍、净井、施药、掩埋、隔棚5项逐旬报数。不得封村断粮，不得弃尸入河，不得驱逐病民入邻县。药材银仍从疫前药仓库支给，不得挤占农民备耕银；贪药价、囤药材、虚报病亡者，交刘泽深会3法司审。防疫常平仓改为全国长效制度，13省各设1仓为底线、20仓为上考；每仓储药材、石灰、粗布、棺木、净井册，专职医官每省2人，春夏秋冬4时轮验。净鼠尸、熏仓场、封井口、焚秽草必须年年照办，鼠疫未起先治，疫起不乱民。
5. 钱谦益、史可法继续抚绅助饷与新学安民。江南夏前不新增隐田追缴，不公开全域清丈；士绅捐粮、献种、修渠、助药仓、助伤兵棉衣、助工坊者，给匾、记志、商税减等1次，但不得凭捐免罪、不得借名侵吞官种。应天、苏州、松江、常州、杭州、嘉兴6学继续收实学子弟，今夏新学由12学扩至18学为底线、24学为上考，农、算、工、医、火器诸科优先，官绅子弟入学须甄试，不授官、不占科举正额。补录实学诸生220人为底线、330人为上考；科举、律学、算学、农学、火器学、译算学分科开讲。陈新甲仍以左佥都御史督反贪、科举、新学、西学，不兼巡抚，不掌兵，不理军饷，90日内须具反贪复勘册、会试条陈册、新学名册、西学护持册4册；180日总验。若能整饬学政、补实新学、肃清借学营私、平衡士林与西学之议，成底线者加衔记功，达上考者再议升转；若借学植党、借反贪牵连无辜、压制西学工艺、朋附门户者，即夺职听勘。文官民生水利赏格库3万两，只赏办疫、修渠、安民、督运、推种有实者，不得均分。

【外交】
命来宗道、毛文龙、熊文灿、郑芝龙守蒙古分档互市、东江牵制、5口海贸禁炮旧制，不增旧额而加军情核验，不因夏防而乱旧信。
1. 来宗道仍主蒙古互市与边外军情。互市照春季旧额10万两，先给7万两以守信义，余3万两凭军情、拒作向导、截马、禁硝铁实绩给付，不增旧额，不断旧信。察哈尔、土默特、喀尔喀土谢图汗、札萨克图汗、车臣汗有报后金调兵、转粮、借道、归师者按实给赏；科尔沁、喀喇沁愿报路线、拒为向导者加茶绢盐引，私导后金入塞者停赏、绝市、入黑册。今夏有效军情12条为底线、18条为上考；宣大互市官每10日报市马、茶绢、盐引、军情4册，虚造军情领赏者革职追银。以夷制夷之法，只扶漠北，不再押重饷于漠南空转，以茶绢盐引诱其从后金背后牵制，不许赊火器、不许给火药、不许给炮图。
2. 毛文龙保东江敌后牵制，仍以皮岛为根本，铁山、义州停泊补水。辽南小股登岸只焚粮囤、毁船械、截盐铁、报兵马，不求大捷，不许诱后金主力围攻皮岛。东江边报每月送兵部，并抄山海关、蓟宣、登莱；若后金夏季再犯宣大或宁锦，东江可择风信袭扰辽南粮路，事后10日具报，不得擅并登莱水师，不得索朝鲜粮饷，不得私设税卡。东江补给不低于65为底线、不低于70为上考；船册、粮册、火器册缺报1月者罚俸。东江为海上唯一敌后入口，不许袁崇焕擅并，不许拿朝鲜做额外担子。
3. 熊文灿、郑芝龙护广州、宁波、泉州、漳州、登莱5口海贸税路，并禁硝磺、熟铁、炮书、炮匠、火药方、铅子模具北流。大商分级纳税，小商、小贩、近海渔户不得骚扰；海贸税、盐课、矿税中应拨新军、火枪厂、商屯与工坊者，须立专账，不得私扣。郑芝龙护商船队每月报船数、税数、禁货、获私4册；获硝磺、炮书、熟铁北贩实证者，按值给赏10%；私纵1船者，主事官罚俸6月，再犯革职；通后金者以通虏论。火器换白银之法，只准广州、泉州2口设军器市舶司，以旧款火铳、佛郎机炮、陈旧铳管换银、换粮、换香料，不许外售红夷炮、火药方、火绳、铅模。每季实收银3万两、热带粮1万石为底线、实收银4万两、热带粮1.5万石为上考。
4. 朝鲜、琉球、澳门诸线只用于东江停泊、海贸税路、铸炮工艺、军情互通。外籍炮匠可教铸炮、测算、钻镗，不得入兵部密册，不得知山海关、蓟宣、东江军机。汤若望、公沙的西劳等西学人员只许在宋应星、孙元化名下办理历法、炮术、测算、工艺，不授刑名、税课、兵权。泄火炮尺度、火药配方、铳管工艺者，不论华夷，按军法治。六耳军商队化仅限伪装晋商、茶商、马帮，出关只采边情，不得越境贸易扰市，不得代人收税，不得私携火器。

命王承恩、李若琏、房壮丽、刘泽深、李国普行4权互核与夏秋2季考察，冬季验杨嗣昌、徐霞客、宋应星、卢象升升降，务使文武分权、账刑分离、赏罚明白，兼安官僚之心，不使朝堂因军政偏重再起怨望。
1. 王承恩掌账不掌刑，刘泽深掌刑不掌账，房壮丽审账，李若琏掌密核，内阁复核，司礼监封册，仍行4权互核。今夏会核国库、内帑、4库、商税、盐课、矿税6账，并区分实银、实粮、实药、账面冲抵4类。凡犒军、官赏、养廉、农赏、吏部考察、火枪厂、六耳军首赏，皆单独成册；不得以账面冲抵冒称实发，不得把赈粮折银虚报，不得把官种算作商税入库。每30日王承恩呈账册，房壮丽附审语，李若琏附密核，李国普附考第。夏季各类满意度底线与上考分别为：军人40与45、官僚40与45、士绅42与50、农民35与42、武勋48与55、皇党38与45、东林28与35，未达者先减赏，达上考者再叙功。
2. 刘泽深会3法司，继续在陕西、山西、河南交界设流动查账4队，每队刑部司官、巡按御史、锦衣卫清慎官各1人，核赈银发放册、军饷实收册、粥厂米数、乡勇粮册、火器禁泄案。府县衙外仍设铜匦，告发属实者给追回赃款10%；诬告3人以上反坐；证据不足不得兴狱。王承恩不得越权定罪，锦衣卫不得借密报私拿士绅，刑部不得借审案查账夺银；违者同以越权论。流动查账只核票册、仓册、粮册、械册，不得因查账而把陕西药粮、北疆专款、东江补给串并。
3. 李国普总铨选考成，今夏改立4硬10辅。4硬为：陕西5贼补给维持0且新增裹挟不逾30人；新军总额达3.4万人且虚冒不逾1%；火铳季度产4500支、轻炮45门；六耳军准确率达80%、泄密0。10辅为：小营破130处、归屯新增1.5万人、井渠800处、仓棚700处、谷库150座、新学18学、补录实学诸生220人、东江补给不低于65、有效蒙古军情12条、5项赏银实发清楚。达底线者留任记功；达上考者晋1阶或加衔；未达底线者停本季赏银、九品考第降1级；因洪疫不可抗者准限期补效，虚报者不准。6计谋并行之效，须以本季实数回看：以夷制夷是否得军情、以贼攻贼是否降其粮道、火器换白银是否增税不失炮、商屯戍边是否减运损、密探商人化是否稳情报、瘟疫保险是否压病亡，6项各自可核可验。
4. 吏部、内阁同立诸臣功过册。孙传庭、洪承畴、曹文诏、秦良玉以定陕实绩考；卢象升、宋应星、孙元化以扩军、扩铳、零虚冒考；杨嗣昌、徐霞客以六耳选训、舆图准确、扰民泄密考；来宗道、毛文龙、熊文灿、郑芝龙以互市军情、东江补给、海贸禁炮考；毕自严、王承恩、李若琏、房壮丽、刘泽深、李国普以5项赏银实发、6账4类清楚、贪腐不反弹考。冬季总验，杨嗣昌合格授正3品六耳军主将；徐霞客合格升兵部职方司员外郎或郎中；宋应星、卢象升、孙元化达火器新军上考者升叙；陈新甲若90日初验、180日总验皆合格，可议左副都御史或加衔，不许兼外镇。贪挪、克饷、遗炮、通虏、扰民者，虽有他功，皆先问罪。
