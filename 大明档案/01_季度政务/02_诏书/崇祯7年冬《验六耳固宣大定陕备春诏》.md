# 崇祯7年冬《验六耳固宣大定陕备春诏》

奉天承运皇帝，诏曰：

先申赏格：本季犒军银5万两、官僚赏银5万两、养廉银5万两照旧发放；农民备春赏银10万两，专给冬春口粮、耕牛租价、种子、农具、水车、井绳，不得改拨他项；吏部考察银1万两，只准验册、差旅、誊录、取证，不许宴饮馈送。其军前守口、夜巡、护民入堡、炮手退敌有实功者先赏后考；办疫、督运、推种、核账、修渠、归屯有实者，官赏先给后核；养廉银仍按九品考第发给基层州县、仓场、驿递、医药、工务吏员。凡克扣、虚领、均分、冒支者，先停职，后交法司。

【军事】
命孙传庭总收陕西、卢象升固宣大并续扩新军、杨嗣昌徐霞客冬验六耳、宋应星孙元化续增火器，90日内务使宣大不失、贼粮不复、军情先至、军器再增。
1. 孙传庭仍以陕西巡抚兼总督剿寇事，坐镇西安，节制陕西、山西、河南3省剿抚兵马；洪承畴专主粮赈归屯，曹文诏领精骑5000人，秦良玉领白杆兵守商洛、蓝田、武关、汉中。秋季5股流贼补给俱为0，冬季以“补给不得复起”为死线，凡王二、王嘉胤、高迎祥、李自成、张献忠任1股补给复至1以上，该路总兵罚俸6月，督抚具折待罪。曹文诏专行夜袭、断粮、截马、焚仓、破小营，不许深入大山孤战；秦良玉专守南下就粮诸道，不许擅离要口；洪承畴于西安、延安、凤翔、庆阳、渭南续设归降营、粥厂、粮棚，兵到处先立粮棚，不使饥民畏死复投贼。30日内成兵册、粮册、路线册、招降册、粥厂守卫册；60日内破小营140处为底线、180处为上考；90日内迫3股老营迁徙、溃散或分裂为底线，迫4股为上考；本季陕西新增裹挟不逾30人为底线，不逾10人为上考，力争归0；至明年春季，诸贼主力合计减40%为底线、减55%为上考。擒斩首恶1名，或使2股贼众降散过半者，另列上功。
2. 卢象升兼督新军3年扩编，宋应星总新工新军，孙元化分督器械火炮。仍行“只提拔、不裁旧”，京营5军营、神枢营、神机营旧兵中识字习武、无逃兵劣迹者准应试入新军，原营未入选者仍留旧额。新军秋季已近3万人，今冬再增4000人为底线、6000人为上考，务使总额达3.4万人以上，火枪兵、长枪兵、炮营、轻骑、辅兵仍分册训练。入选本人实赏2两，主训军士每练成1人实赏1两，每名新兵只准1名主训官领赏；蓟镇、宣府骨干教习1200人每月加银2两照旧，不空原防。冬季成训、春季可用为底线；虚冒新兵、重领赏银、借扩军裁旧兵者，革职追赃。
3. 宋应星、孙元化续督官营火枪厂与轻炮局。火铳季产秋季已达2600支，今冬须增至3000支为底线、3600支为上考；轻型火炮季产须达32门为底线、40门为上考。30日内补齐炉房、熟铁、木床、钻镗、铳管、试放、火药分库7册；60日内火铳、轻炮、火药、铅子、匠户、废品、转运7册十日一报。火药、熟铁、铳管遗失1件即查，私卖后金者以通虏论。大同、宣府、蓟州守城炮位缺损者优先补给，不许先供空名库房后供实战口堡。
4. 杨嗣昌主六耳侦缉军军情统筹，徐霞客为舆图测路副总。秋季六耳补训约1.8万至2万人，泄密0、扰民2至3起、粮道图约280幅、疑报约220条、准确率约60%。今冬为总验补效之季：45日内补齐训练册2万人，粮道图达360幅为底线、500幅为上考；贼营疑报达300条为底线、420条为上考；可用密报准确率达70%为底线、85%为上考；泄密仍须0，扰民案不逾2起。六耳军只掌侦报、舆图、暗号、粮道、边情，不得审案、征税、调兵、抄家、刑讯；所得线索交孙传庭、卢象升、袁崇焕、毛文龙、刘泽深、王承恩按原职办理。冬季总验若达底线且1项上考，授杨嗣昌正3品六耳军主将实职；徐霞客按舆图、水源、道路实绩升兵部职方司员外郎或郎中；若泄密、扰民、通贼，则撤职听勘。
5. 孙承宗仍总裁边防军议，袁崇焕只办宁远、山海关前哨收容与辽西换防余务，不许出塞浪战；毛文龙完整保东江镇，专行小股袭扰、截盐铁、报兵马，不得擅并登莱，不得索朝鲜粮饷。大同、宣府、蓟州经秋季守住，然边民被掠、士气补给俱受损；今冬着卢象升会山西、北直隶督抚，30日内补齐大同、宣府、蓟州城上火药、滚木、礌石、铳炮、夜巡、护民入堡5册，60日内将要口烽堠、拒马、壕沟、敌台复验1遍。守口、夜巡、护民入堡、炮手退敌者照旧叙功；擅自出塞野战，虽有斩获，不叙功。宣大大口不失、东江补给不低于65、辽西遗炮仍为0，为冬季边防3硬。

【内政】
命毕自严、洪承畴、宋应星、王徵总备来春口粮、种子、归屯、井渠、仓棚、谷库诸务，90日内务使冬粮不断、春具先到、归屯可耕、官种入册。

1. 毕自严以户部总理钱粮，冬季5项银分账支给：犒军银5万两直发诸营兵丁画押；官僚赏银5万两给办疫、赈旱、清边、核账、推种、督运有实者，不得均分；养廉银5万两按九品考第给基层州县、仓场、驿递、医药、工务吏员；农民备春赏银10万两专给冬春口粮、种子、农具、水车、井绳；吏部考察银1万两只准验册、差旅、誊录、取证。5项共26万两，皆须实发本人、画押入册、4权互核。王承恩掌账，房壮丽审账，李若琏密核，内阁复核；每10日具实发数、未发数、驳回数、追回数入册。

2. 洪承畴主陕西粥厂、归降营、归屯田。秋季归降入屯约7500人，今冬新增归屯9000人为底线、1.2万人为上考；归屯丁口须具姓名、原籍、原属贼营、家口、田亩、农具6项，缺2项以上不得入功册。粥厂守卫仍以四镇老成兵丁30人守1厂，专防贼探混入、米粮被劫、降而复叛，不许向饥民索钱索粮。归屯青壮可编屯田营，边耕边守，不得私役为奴；降而复叛且劫粮杀人者治罪，胁从未杀官劫库而自首者给粮、给种、给具。冬尽前须使西安、延安、凤翔、庆阳、渭南5路归屯田各成春播册，不得有册无人、有人无具、具到无粮之弊。

3. 宋应星、王徵督冬修井渠仓棚谷库与来春种具。秋季续建已起，今冬以井渠480处为底线、600处为上考；仓棚520处为底线、650处为上考；谷库90座为底线、120座为上考。陕西、山西、河南、乌思藏按地宜分给粟、黍、麦、豆与耐瘠杂粮种，另给水车、井绳、锄镰、牛具。灾区无偿给付，常省采用种贷，秋收后还种不取息。每县设种圃1处，府仓设存种册，发种须有村正、里甲、农户3方画押。倒卖官种、以劣换良、扣留农具者，官吏革职追赃，豪强加倍追还。

4. 山西、陕西、河南旧疫未尽，魏照乘、地方巡按、医官会办病舍、药仓、净井、焚秽、埋葬5册。秋季病舍药仓已成一批，今冬药仓达96处为底线、108处为上考；病舍、净井、施药、掩埋、隔棚五项逐旬报数。不得封村断粮，不得弃尸入河，不得驱逐病民入邻县。药材银仍从疫前药仓库支给，不得挤占农民备春赏银；贪药价、囤药材、虚报病亡者，交刘泽深会3法司审。

5. 钱谦益、史可法继续抚绅助饷与新学安民。江南冬前不新增隐田追缴，不公开全域清丈；士绅捐粮、献种、修渠、助药仓、助伤兵棉衣者，给匾、记志、商税减等1次，但不得凭捐免罪、不得借名侵吞官种。应天、苏州、松江、常州、杭州、嘉兴6学继续收实学子弟，农、算、工、医、火器诸科优先，官绅子弟入学须甄试，不授官、不占科举正额。冬季以“抚绅而不纵绅、借绅而不伤民”为界，违者按扰政论。

6. 以内帑二十万两犒赏宣大边军、另拨二十万两充火器开发，

    第一，犒赏二十万两如何发放。此款分三笔：大同独给八万两，宣府六万两，蓟镇真保各三万两。大同遭受冲击最重，边军士气仅五十四，当以重赏稳住军心。发放之法，依既定章程——由王承恩遣清慎官直送卢象升大营，各营百总以上集于营门，当众唱名发放，兵丁逐一画押，不经将官私库。守城有功者、夜巡哨探有实绩者、炮手命中敌骑者，另给功赏银，每人不逾五两。发放完毕三日内，各营将画押册张榜公示，军士可自验。如此可防克扣，亦使赏银真正到兵。 第二，边民安抚。 此次宣大边墙外村庄被掠约三千人，晋北民心恐慌。从犒赏银外另行拨银三万两，专用于边民安置。具体之法：其一，被掠村庄遗属，每户给抚恤银三两、过冬口粮三斗、粗布一匹，由山西巡抚逐户核发。其二，边墙内堡寨增设粥厂三处，收容逃亡入堡之边民，每日给粥两顿，至明年春耕为止。其三，边民青壮愿从军者入护关营，愿屯田者入军屯册，老弱妇孺入赈籍。如此既安民心，亦不使流民为贼。 第三，坚壁清野。 坚壁清野乃御虏长策。臣查崇祯六年春季边民内迁已清空边墙外三十里村庄约九五成，此次后金入寇所掠，多为偏远零散未清之户及内迁后复回者。臣请下旨卢象升，冬季封河前完成三事：一，大同宣府蓟州各边口再清边墙外三十里，零散村庄尽数内迁入堡，不可迁之粮焚、井填、空屋拆；二，各堡寨清查复回之民，编入堡内户籍，给安置银一两、种子一斗，明春在堡内授田耕种，不得再出边墙；三，九边各口烽堠每五日一报，发现边墙外有烟火踪迹即报，失报者哨长革职。 第四，边镇粮饷保障。 宣大边军补给下降，根本原因在于运输道路被扰、仓储损耗。三管齐下：其一，大同仓、宣府仓各补储粮三万石，从山西、河南常平仓调运，冬季封冻前运抵。其二，各边口增设护粮队，每队五十人，专司粮道巡查，由边军辅兵中选充，不另增饷。其三，边军冬季马草折银，大同每匹每月加发银三钱、宣府加发二钱，从犒赏银外另行拨付，合计约需银一万二千两。 以上四项，犒赏二十万两由内帑拨付，边民安置三万两、粮草折银一万二千两合计四万二千两，

【外交】
命来宗道、毛文龙、熊文灿、郑芝龙守蒙古互市、东江牵制、5口海贸禁炮旧制，不增旧额而加军情核验，不因冬防而乱旧信。
1. 来宗道仍主蒙古互市与边外军情。互市照秋季旧额10万两，先给7万两以守信义，余3万两凭军情、拒作向导、截马、禁硝铁实绩给付，不增旧额，不断旧信。察哈尔、土默特有报后金调兵、转粮、借道、归师者按实给赏；科尔沁、喀喇沁愿报路线、拒为向导者加茶绢盐引，私导后金入塞者停赏、绝市、入黑册。冬季有效军情8条为底线、12条为上考；宣大互市官每10日报市马、茶绢、盐引、军情4册，虚造军情领赏者革职追银。
2. 毛文龙保东江敌后牵制，仍以皮岛为根本，铁山、义州停泊补水。辽南小股登岸只焚粮囤、毁船械、截盐铁、报兵马，不求大捷，不许诱后金主力围攻皮岛。东江边报每月送兵部，并抄山海关、蓟宣、登莱；若后金冬季再犯宣大或宁锦，东江可择风信袭扰辽南粮路，事后10日具报，不得擅并登莱水师，不得索朝鲜粮饷，不得私设税卡。东江补给不低于65为底线，不低于70为上考；船册、粮册、火器册缺报1月者罚俸。
3. 熊文灿、郑芝龙护广州、宁波、泉州、漳州、登莱5口海贸税路，并禁硝磺、熟铁、炮书、炮匠北流。大商分级纳税，小商、小贩、近海渔户不得骚扰；海贸税、盐课、矿税中应拨新军与火枪厂者，须立专账，不得私扣。郑芝龙护商船队每月报船数、税数、禁货、获私4册；获硝磺、炮书、熟铁北贩实证者，按值给赏10%；私纵1船者，主事官罚俸6月，再犯革职；通后金者以通虏论。
4. 朝鲜、琉球、澳门诸线只用于东江停泊、海贸税路、铸炮工艺、军情互通。外籍炮匠可教铸炮、测算、钻镗，不得入兵部密册，不得知山海关、蓟宣、东江军机。西学人员只许在宋应星、孙元化名下办理历法、炮术、测算、工艺，不授刑名、税课、兵权。泄火炮尺度、火药配方、铳管工艺者，不论华夷，按军法治。
