# 崇祯7年春《补刑稳学扩军收陕春耕补库诏》

奉天承运皇帝，诏曰：

朕览崇祯6年冬诸臣密奏，陕西贼粮已困，王二、王嘉胤、高迎祥、李自成补给皆为0，张献忠补给仅余2，归降入屯约5000人，春耕补农库已实拨35万两，井渠300处、仓棚350处、谷库50座皆有成效。然徐光启、袁可立同季薨逝，西学与刑名2柱遽空，若不速补，则新军、农政、核贪皆失所依。今春不是重行旧令，乃在既成之数上加力。凡钱粮、兵额、粮石、工程、满意度诸目标，皆用实册核验，不许以旧功冒新功。

【军事】
命孙传庭总陕晋豫剿抚，卢象升兼督新军扩编与犒军，90日内乘贼饥疲收陕、扩军备、不空边防。

1. 孙传庭坐镇西安，节制延绥、固原、宁夏、甘肃赴陕兵，各镇调兵不得逾实兵20%，原防留70%以上。曹文诏领精骑5000人，分10队夜袭、断粮、截马、焚仓、破小营，专取贼粮、马草、械具、哨探，不许深入大山孤战。秦良玉领白杆兵守商洛、蓝田、武关、汉中，截王嘉胤、高迎祥南下就粮。朱燮元川兵清汉中私粮与川陕山道，防张献忠复取粮道。
2. 陕西剿抚以30日成兵册、路册、粮仓册、降众册、粥厂守卫册为底线。60日内破小营80处为底线、120处为上考；90日内迫2股大营迁徙或溃散；6个月内诸贼主力合计减30%为底线、减50%为上考。王二、王嘉胤、高迎祥、李自成补给必须仍为0，张献忠补给须由2压至0；陕西新增裹挟不逾100人为底线，归0为上考。
3. 贼中饥民、妇孺、胁从丁未杀官焚仓者，弃械即给粥、给路粮、编归屯；执刃杀官、焚仓、诱边军叛逃者，不在赦限。军功以截粮、救民、招降、护仓、守口5项合计，不专计首级。杀良冒功、杀降抢粮者，兵丁斩，将官连坐。定陕有功，孙传庭加兵部尚书衔候补，曹文诏、秦良玉、洪承畴并列御前功册；若新增裹挟复逾500人且非洪水疫病所致，孙传庭罚俸6个月，曹文诏罚俸3个月。
4. 定陕战功赏银20万两由户部定陕军赏库支给。能招降100人且入册归屯者，主官赏银30两，吏役军士按名给赏；能护粮1000石入仓无失者，押运官赏50两，兵丁每人赏银1两；能破悍首营寨、缴获粮械者，按实值30%给军中赏；擒斩王二、高迎祥、王嘉胤、李自成、张献忠等首恶者，另给银1万两、授功牌，仍须3司验明。虚报降人数、虚报战功、克扣军赏者，10倍追赔，1000两以上交刑部审办。
5. 卢象升兼督新军，废“汰旧”之名，只提拔、不裁旧。京营5军营、神枢营、神机营中识字习武、无逃兵劣迹者准试入新军，入选本人赏银2两，主训军士每练成1人赏银1两，每名新兵只准1名主训领赏。新军由1.2万人扩至1.8万人为底线、2.2万人为上考，火枪、长枪、辅兵、轻骑、炮营分册列名，实兵、实训、实饷3册互核。
6. 蓟镇、宣府各出精锐步卒500人、炮手100人，合1200人为骨干教习，每月加银2两，分批调入，原防不得低于70%。犒军银5万两由王承恩监临直发大同、宣府、蓟州、关宁、东江、陕西援剿诸营，大同独拨1.2万两，兵丁画押，不经将官私库。军人满意底线46、上考50，大同士气底线55、上考60。虚冒新兵、空饷、教习重领、克扣犒军者，革职追赃；新军达上考且边防无空，卢象升晋1阶。
7. 孙承宗仍总边防，袁崇焕守宁远、山海关，辽西锦州只作撤民撤粮中转，不添大堡，不诱关宁主力野战，遗炮、炮匠、炮图外泄必须为0。毛文龙东江本季补粮2万石、火药5000斤、修船银1万两为底线，专行焚后金粮囤不低于3次、毁船械不低于3次、截盐铁、报兵马不低于3次，毋求大战。边口失报、遗炮资敌、擅杀东江镇将者，以军法重治。

【内政】
命洪承畴、宋应星、王徵专保春耕补库，春播前发农赏、种子、农具、口粮到户到屯。

1. 洪承畴专主粮赈归屯，西安、延安、凤翔、庆阳、渭南归降营与粥厂不得停，绥德、鄠县、三原、泾阳、耀州新增粥厂即日开设，户部增拨粮6000石。每厂以30人老成兵丁守卫，防贼探混入、米粮被劫、降而复叛，不许向饥民索钱索粮。
2. 春耕农赏银10万两入陕晋豫赈抚屯田库，陕西4万两、山西3万两、河南2万两、乌思藏1万两。灾区无偿给种，常省种贷无息，秋收还种不取息；种子、农具、春耕口粮须在春播前发到灾区民户、归屯丁口、边堡荒田、粥厂归籍户。任何州县不得以保库、待拨、军用为名迟发。
3. 归屯新增9000人为底线、1.3万人为上考；粥厂覆盖新增归降、逃荒、被胁从丁80%为底线、95%为上考。每归屯丁口给种子、农具、口粮，并列入原籍、亲属、旧营、技能、保甲5册；来历不明者先入试屯营30日，不得混入军营。
4. 宋应星承徐光启遗策，总农政推种与工务，不参党争，不掌刑名；王徵督水车、井绳、犁具、锄镰、种筛；孙元化督火器海运与器械转运；汤若望、公沙·西劳只授历算、炮术、测量，不许涉户籍、刑狱、党争。西学派满意由47回至50为底线、55为上考，若工匠散失、器械停办，宋应星罚俸3个月，相关主事降考。
5. 崇祯6年冬既成井渠300处、仓棚350处、谷库50座，今春底线为井渠450处、仓棚525处、谷库75座，上考再加50%，即井渠675处、仓棚788处、谷库113座。工程只许为春播、蓄水、储粮、归屯服务，不许修虚名门楼。太仆寺拨驽马300匹充耕牛，河南购牛1000头、湖广购牛800头，两省巡抚不得阻运。
6. 饥民精壮编屯田营，边耕边守，每营500人，设营官1员、农官1员、老兵守卫50人；屯田粮先给本营口粮，余粮入府仓，不抵扣本季军饷。农民满意由18升至26为底线、32为上考；陕西民心由26升至31为底线、36为上考，山西、河南、乌思藏各升5点为底线、8点为上考。凡借推种勒派、强夺熟田、私卖官种、侵吞补贴者，以侵赈例治罪。
7. 钱谦益、史可法会礼部、学官、乡约耆老，刊发《贼粮已断归屯给种榜》《春耕农赏榜》《军民有功赏格榜》各30万张，陕西、山西、河南、北直隶、山东诸府县10日内张挂宣读。榜文只写实给口粮、种具、赏格，不许粉饰贼已尽平。能劝归籍100户、助种1000石、修渠1处者，给匾入志；虚榜扰民、钱粮未到而空口宣谕者，主办官降考。

【外交】
命来宗道守蒙古互市、朝鲜东江、5口海贸禁炮旧制，不增旧额，不断边报，不挪赈种军赏之银。
1. 蒙古互市仍以10万两为名额保信义，先给7万两，余3万两只凭军情、拒作后金向导、截马、禁硝铁实绩给付。察哈尔、土默特、喀喇沁中愿报后金粮道、马队、炮匠、硝铁者，按情给茶绢盐引小赏，不给火器、火药、甲胄、炮图。军情10条为上考，5条为底线；虚报者停赏，私给火器者以通虏论。
2. 来宗道每月将互市银物、军情、边外部落动向、拒作向导实据造4册，送孙承宗、卢象升、王承恩、毕自严各存副本。若后金有西调、买硝、索炮匠、诱蒙古借道等情，须3日内飞报大同、宣府、蓟州、山海关。
3. 毛文龙东江镇完整保留，不许裁撤、兼并、擅杀；东江补给不得低于65，每5日边报抄兵部、山海关、宁远、蓟宣、大同。东江小股袭扰仍取焚粮囤、毁船械、截盐铁、救辽民、报兵马5功，不以斩首为唯一功；春季袭扰5次有实为底线、8次为上考，虚冒兵饷、私设税卡、扰朝鲜民者削职。
4. 礼部与朝鲜维持义州、铁山停泊、补水、养伤之约，不索粮饷，不迫出兵。朝鲜所报后金调兵、买硝、炮匠、粮道等情，兵部核实后给布药小赏；东江不得擅取朝鲜民粮，不得以征粮为名逼其出兵。
5. 熊文灿、郑芝龙守广州、宁波、泉州、漳州、福州5口，照3等商税征收，大商足税给护照，小商、小贩、小渔船免扰；海税崇祯6年冬超30%为底线，增50%为上考。硝磺、熟铁、炮书、炮匠、火药方、铅子模具北流者，以通虏论；缉获禁货30%赏水师与告发人，70%入海防库。
6. 海贸、互市、朝鲜、东江4路所得，只许补春耕补农库、定陕军赏库、东江补给库、海防库，不得挪陕西赈粮、犒军银、官僚赏银、养廉银、吏部考察银作外赏。外交之功，只取断向导、禁火器、保东江、保海税、得军情5事；邀虚贡、广馈赂、私开新额者，礼部主官罚俸，承办官降调。

【其他】
命李国普补刑部、王承恩行4权互核，10日内定人定册，90日内总验赏罚。

1. 袁可立已薨，刑名不可空。准李国普所奏，补刘泽深为刑部尚书，沈演备南京刑部，郑三俊留大理寺；刘泽深未到任前，设3法司临时会审官5人，专审赈银、军饷、火器禁泄、粥厂侵米、乡勇粮册5案，直报内阁与司礼监，不受地方督抚私压。
2. 王承恩掌账不掌刑，刑部掌刑不掌账，内阁复核，司礼监封册；毕自严核国库、内帑、4库、商税、盐课、矿税6账，李若琏掌密册，房壮丽会都察院审账。每项钱粮各造实银册、实粮册、实具册、实发画押册4册，发毕3日内贴榜营门、县衙、仓场；缺1册罚俸3个月，缺2册降1级，4册全缺者革职问罪。
3. 官僚赏银5万两给办疫、赈旱、清边、核账、推种、督运有实者，不得均分；养廉银5万两按9品考第发给基层州县、仓场、驿递、医药、工务吏员；吏部考察银1万两只准验册、差旅、誊录、取证，不许宴饮馈送。官僚满意由28升至35为底线、40为上考。
4. 腐败度由39压至36为底线、34为上考。举发侵银属实者，给追回赃款10%；侵银10两以上停职，100两以上交刑部，1000两以上抄没追赔；诬告3人以上反坐，证据不足不得兴狱。厂卫、御史、刑部互相牵制，不许借案倾陷党派。
5. 6辅各守本职：孙承宗总边防换守与东江协同；钱谦益总江南官绅、新学、宣传；宋应星承徐光启遗务，总农政工务，会卢象升办新军器械；李国普总铨选考成；毕自严总财赋仓储；来宗道总蒙古、朝鲜、海贸。3日内各具案，10日内列责，30日内报初效，90日内报总验。
6. 达底线者记功，达上考者晋1阶或加衔；连续2季上考者越次擢用。虚报、挪赈、克饷、遗炮、扰民、通虏者不适用宽典。各衙门奏报必须写明执行人、地区、钱粮数、粮石数、兵额数、期限、底线、上考、赏格、问责；无实数者封还重拟。

钦此。
