# 军队档案入口

本目录保存军制、军团、边军、水师、密侦编制、军阶和装备配置的阅读稿。

当前优先入口：

1. `data/current_snapshot.json`
2. `data/military/`
3. `data/intelligence/`
4. 崇祯11年冬季朝政纪要
5. 本目录中的三军、六耳军和九级军阶原稿

读取时必须区分：

- 编制定额与实到；
- 总库存与到营装备；
- 产能与实际产量；
- 军队番号成立与实际授旗；
- 主官名册与钦定到任；
- 地方军、水师、锦衣卫、六耳军之间的重复兵籍。

11年冬最新已知：三军九团实到148690、满编99.3%；甲缺10700副、红夷炮缺2门。战兵、辅兵逐团最终分解仍待补。
