# Edict Memory Protocol

The canonical rolling memory for all 崇祯 edict work is:

`大明档案/03_国策与战略/01_制度规则/AI起草与档案规则/崇祯模拟器诏书撰写长期记忆.md`

The immutable blank template is:

`skills/writeimperial/templates/崇祯模拟器诏书撰写记忆模板.md`

Before drafting any edict, read the rolling memory. After archiving any edict or quarterly feedback, update the rolling memory in the same change set.

Mandatory rule:

> 本季所列硬目标，季末必须逐项报实际数、完成率及判定；无实际数者按未完成论，不得以启动、推进、预计、可达成、待下季考成等语代替实际季度结果。

Carry unfinished targets across quarters with their original order quarter, original deadline, current deadline, overdue count, actual result, completion rate, judgment, evidence, and next mandatory report fields. Never erase an unfinished item merely because a new quarter starts.
