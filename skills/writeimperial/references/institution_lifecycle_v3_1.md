# Institution Lifecycle v3.1

## Scale v3.1：即时成效、年度考成与三年日落

本文件用于 `writeimperial` 在写新制度、临时官职、临时机构、专项差遣和后续季度考成时统一判断。核心目标是防止新制度第一季度只搭架子、防止K类系统结果只写前置信号、防止临时机构长期膨胀并挤压朝廷正职体系。

## 一、新制度第一季度即时起效

F类新制度第一季度必须同时完成建制和实际起效。不得只写设官、建账、分工、流程、试行、待观察。

首季考成100分：

| 项目 | 分值 |
|---|---:|
| 建制与执行链条 | 35 |
| 直接业务成果 | 40 |
| 系统结果与实际影响 | 25 |

建制与执行链条考主责正式官职、兼领人员、权责边界、账册、试点范围、资源到位、数据回流、日落时间、正案和败案。

直接业务成果必须是真实办成的事，例如总数局核验并查清关键冲突数字、粮价烽火触发红灯救济、九品考成产生首轮官员评定和整改、军户保信完成士兵登记和抚恤、武备学堂学员真实到营、六耳新制产生双源有效情报、海贸新制实际入库银两或样品。

系统结果与实际影响必须至少有一个可验证结果，例如满意度、民心、权威或威望提高1点，腐败度或动乱风险下降1点，或政策响应时间、账实差、粮价、军饷到账率、情报准确率、扰民案件等出现明确改善。

如果游戏没有直接返回点数，必须使用等价实际结果指标。纯建制里程碑不能替代实际成效。

## 二、四季度年度考成

每个新制度发布时自动建立一年考成周期。默认累计路径：

| 季度 | 年度目标累计完成比例 |
|---|---:|
| 第一季度 | 25%，可在20%–35%内调整 |
| 第二季度累计 | 50%，可在45%–60%内调整 |
| 第三季度累计 | 75%，可在70%–85%内调整 |
| 第四季度 | 100% |

年度上考通常为110%–120%。第一季度最高不超过年度目标40%，避免一季做完整年目标。

新制度必备记录：

```yaml
制度名称:
制度版本:
主责正式官职:
兼领官员:
启动季度:
年度考成季度:
年度御前实得目标:
第一季度目标:
第二季度累计目标:
第三季度累计目标:
第四季度年度目标:
年度上考:
年度失败线:
季度实际记录: []
系统结果记录: []
年度考成结论:
三年日落日期:
三年处置:
```

第四季度年度总考只能判为：上考、达标、基本达标但须整改、未达标需更换方法或主官、停止试行。

年度总考检查实际成果、系统结果、成本、扰民、虚报、重复设官、是否值得继续、是否可以并入正式衙门。

## 三、K类双层考核

K类必须同时包含：

- K1可控前置信号：军饷到账率、赈粮到账率、粮价、账实差、抚恤到账、冤案、扰民案件、工程返修、情报提前量、晋升兑现、归屯留存。
- K2实际系统结果：军人满意度、官僚满意度、农民满意度或民心、士绅满意度、皇帝权威、国家威望、腐败度、动乱风险、疫病风险、地方稳定度。

凡新制度明确宣称改善某个K类结果，就必须设置第一季度和年度目标。

普通第一季度目标：

| 指标 | 底线 | 上考 | 极特殊上限 |
|---|---:|---:|---:|
| 满意度、民心、权威、威望 | +1至+2点 | +3点 | +5点 |
| 腐败度、动乱风险 | -1至-2点 | -3点 | -5点 |
| 到账率、通过率、留存率 | +3至+5个百分点 | +6至+8个百分点 | +10个百分点 |
| 账实差、扰民率、冤案率 | 改善5%–10% | 改善10%–15% | 改善20% |

普通年度目标：

| 指标 | 年度底线 | 年度上考 | 年度硬上限 |
|---|---:|---:|---:|
| 满意度、民心 | +4至+6点 | +7至+8点 | +10点 |
| 权威、威望 | +3至+5点 | +6至+7点 | +8点 |
| 腐败度 | -4至-6点 | -7至-8点 | -10点 |
| 动乱风险 | -5至-10点 | -12至-15点 | 视危机单独计算 |
| 到账率、留存率 | +10至+15个百分点 | +16至+20个百分点 | +25个百分点 |

只有制度直接作用领域可以设置相应K目标。武备学堂主要影响军人训练、军人满意和军队战力；军户保信主要影响军人满意、忠诚、逃亡和抚恤；粮价烽火主要影响粮价、农民民心、流民和动乱风险；九品考成主要影响官僚满意、执行效率、腐败和账实差。

K类失败处理：

- 业务完成但K2不改善：判为“建制和业务已完成，但制度影响尚未穿透，限下一季度调整传导机制。”
- 连续两季度K2无改善：进入逆向审查，不得只继续抬高数字。
- K2反向恶化：检查扰民、官僚恐慌、资源挤占、宣传奖励和制度权责冲突。

## 四、正式官职优先

长期国家能力原则上依托内阁、六部、都察院、大理寺、通政司、地方督抚、布政司、按察司、府县、正式军镇、正式学政和军政官职。

新制度优先由现有正式官员兼领：

```yaml
正式官职: "户部尚书"
临时兼领: "御前总数局总核"
```

不得轻易建立与户部、兵部、刑部、都察院或地方督抚平行且永久存在的独立官署。临时机构服务于制度试行、核验和过渡，不自动成为朝廷正职体系之外的常设衙门。

## 五、三年日落

纳入三年日落的范围包括临时衙门、专项委员会、专项总局、专使、钦差差遣、专项军、专项巡核队、临时学堂管理机构、专库管理机构、临时考成官职、试点港务机构、临时情报组织、非朝廷正职体系中的新增头衔。

默认期限：

```yaml
期限: 3年
季度数: 12季度
年度考成间隔: 4季度
自动续期: false
```

设立时必须写明：

```yaml
设立季度:
首年考成季度:
第二年考成季度:
三年日落季度:
正式主管衙门:
兼领正式官职:
撤并预案:
档案移交对象:
```

第一年、第二年年度考成检查实际成果、年度K类目标、职权重叠、预算膨胀、是否需要调整、是否可以提前并入正式衙门。

第三年总清理必须四选一：

- 撤销
- 并入正式衙门
- 缩编为正式衙门下属常设科司
- 续期3年

不允许自动续期。

续期必须同时满足：原始任务仍存在；最近一年达到年度底线；有B级以上证据；没有严重越权、腐败或扰民；无法直接由现有正式官署接管；已提交下一阶段目标；再次设置明确3年日落日期。续期最长仍为3年。

机构撤销后，正式官员回归本职，临时差遣自动解除，临时编制不得转为永久冗员；有能力人员可通过吏部考核转入正式空缺；账册、资金、档案和未结事项移交正式主管衙门；不得因为机构撤销而销毁责任记录。

## 六、诏书示例

```markdown
命户部尚书兼御前总数局总核，仍归户部正职统摄，不另成永久财署。本制以1年为初考之期，每季具实效册；首季除建账设人外，限90日核验12项国库、军册、仓储关键数字，查清至少8项冲突，账实差较旧册下降5%为底线、下降10%为上考；若账实差无降而仅报设局，则为建制已成、影响未穿透，次季改法复核。满1年总考，满3年撤并总验。
```

```markdown
命河南巡抚兼领粮价烽火试点，户部给银，御史按月抽核。首季四省试点府须报粮价、流民、仓储和赈粮到账，红灯地区3日内启动救济达到80%为底线、90%为上考；粮价或动乱风险须有一项实际回落。此差遣附于巡抚正职，12季度后撤、并、缩或续，不得自动成常设独署。
```

## 七、年度记录示例

```yaml
制度名称: 御前总数局
制度版本: v1
主责正式官职: 户部尚书
兼领官员: 户部尚书兼御前总数局总核
启动季度: 崇祯X年春
年度考成季度: 崇祯X年冬
年度御前实得目标: 核验48项关键数字，查清32项冲突
第一季度目标: 核验12项，查清8项，账实差下降5%
第二季度累计目标: 核验24项，查清16项，账实差累计下降8%
第三季度累计目标: 核验36项，查清24项，账实差累计下降12%
第四季度年度目标: 核验48项，查清32项，账实差累计下降15%
年度上考: 核验54项以上，查清36项以上，账实差下降18%至20%
年度失败线: 核验少于30项或无K类改善
季度实际记录: []
系统结果记录: []
年度考成结论:
三年日落日期: 崇祯X+3年冬
三年处置: 撤销、并入户部、缩编为户部常设科司、或续期3年
```
