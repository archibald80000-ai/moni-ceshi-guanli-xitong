# Style Examples

These examples show style only. They are not current archive facts.

## Compact Clause Style

```markdown
【军事】
命孙传庭总陕晋豫剿抚，曹文诏、秦良玉分领机动兵，`90日`内维持5股义军补给为`0`，并将新增裹挟压至`80人`以下。
1. 曹文诏领精骑`5000人`，专行夜袭、断粮、截马、焚仓、破小营；`60日`破小营`100处`为底线、`130处`为上考，不许深入大山孤战。
2. 秦良玉守商洛、蓝田、武关、汉中，截贼南下就粮；护粥厂、护归屯粮道有功者赏，纵兵扰民者降级。
3. 洪承畴设归降营与粥厂，归屯新增`6000人`为底线、`9000人`为上考；降而复叛且劫粮杀人者治罪，胁从自首者给粮给种。
```

## Reward-First Style

```markdown
朕先申赏格：犒军银`5万两`、官僚赏银`5万两`、养廉银`5万两`照旧发放；农民补耕赏银`10万两`专给补种、归屯、疫区农具与秋播备种；吏部考察银`1万两`只准验册、差旅、誊录、取证。凡实发本人、画押入册者为功，克扣虚领者先停职后交审。
```

## Boundary Style

```markdown
六耳军只掌侦报、舆图、暗号、粮道、边情，不得审案、征税、调兵、抄家、刑讯；其线索交孙传庭、卢象升、袁崇焕、毛文龙、刑部、王承恩按原权责办理。
```

## Bad vs Good

Bad:

```markdown
命诸臣妥善安抚灾民，加强边防，稳定民心。
```

Good:

```markdown
命洪承畴`30日`内于西安、延安、凤翔设粥厂`30处`，每厂老兵`30人`守卫；每`5日`报给粮册、病亡册、归屯册。克扣米粮`1石`者杖流，侵银`100两`以上交刑部。
```
