# Edict Rules

## Required Structure

Every formal edict uses this frame:

```markdown
奉天承运皇帝，诏曰：

【军事】
命某某……。
1. ...
2. ...

【内政】
命某某……。
1. ...

【外交】
命某某……。
1. ...

【其他】
命某某……。
1. ...

钦此。
```

Each section's first line is the core command. It must name the main owner and action, not a slogan.

## Clause Checklist

Each major clause should specify:

- 执行人 and backup/监察官
- 衙门 or region
- concrete action
- money, grain, troops, tools, or materials
- deadline such as `30日`, `60日`, `90日`, `6个月`
- bottom-line target and上考 target
- reward for达标/上考
- punishment for虚报、延误、贪挪、扰民、遗炮、通虏

## Numeric Style

- Use Arabic digits for quantities: `5万两`, `2.5万人`, `80处`, `30日`, `70`, `35`.
- For 5+ digit quantities, prefer `万`: use `1.2万人`, not `12000人`; use `20万两`, not `200000两`.
- Proper nouns and institutions may keep established Chinese forms, e.g. `王二`, `九品`, `四权互核`, but avoid Chinese numerals for measured quantities.

## Target Rules

- If there is a prior actual value, do not reuse it as the new target.
- Default bottom-line target: prior actual + about `30%`, adjusted for disaster constraints.
- Default上考 target: bottom-line or prior actual + about `50%`.
- If disaster, flood, plague, or war makes punishment unfair, write “免罚但限期补效”; do not erase accountability.

## Forbidden Empty Phrases

Do not write:

- 妥善安抚灾民
- 加强边防
- 整顿吏治
- 恢复财政
- 稳定民心

Replace with concrete commands:

- `拨银5万两、粮2万石，30日内入西安、延安2仓；每5日具给粮册、死亡册、归屯册。`
- `卢象升30日内复验大同、宣府、蓟州烽堠，遗炮为0，守口夜巡有功者赏。`

## Strategic Red Lines

Avoid unless the user explicitly overrides and archives support it:

- 加派民田正税
- 主动与后金决战
- 撤销或擅并东江
- 全面清丈江南
- 高阻力宗室大改
- 低威望时全国性激进改革
- 让情报军掌刑名、征税、调兵、抄家、刑讯

## Section Guidance

### 军事

Use for剿抚、边防、换防、清野、东江、新军、火器、犒军. Tie military actions to logistics and troop morale. Distinguish主帅、中层将官、普通士卒 in奖惩.

### 内政

Use for赈灾、春耕、种子、仓储、水利、疫病、税源、养廉、官僚奖赏. Do not挪陕西赈银 into border or factory costs unless explicitly ordered.

### 外交

Use for蒙古互市、朝鲜东江、海贸、禁炮、郑氏水师、西洋工匠. Do not expand spending casually; prefer绩效给付.

### 其他

Use for四权互核、三硬七辅、九品考成、密探、查账、刑部、吏部、归档、派系平衡. Keep权责 separated: 王承恩掌账不掌刑, 刑部掌刑不掌账, 内阁复核, 司礼监封册.
