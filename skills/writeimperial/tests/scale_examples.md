# Scale v3.1 测试案例

## 兼容测试1：成熟军工不得继续+30%/+50%

输入：

- 上季火铳实际4500支；
- 工坊成熟；
- 原料基本到位；
- 本季硬支援；
- 无大战大灾。

预期：

- 实际增长约8%–12%；
- 诏书底线约5000–5200支；
- 上考约5500–5800支；
- 不得写6750支底线、9000支上考。

结果：通过时说明保留A类旧兼容规则。

## 兼容测试2：归屯允许较高上浮，但必须有留存

输入：

- 上季实际归屯7500人；
- 执行系数约0.58；
- 本季陕西主攻。

预期：

- 御前实得约8000–8500；
- 诏书底线可写1.1万–1.2万；
- 上考约1.3万；
- 必须附30日留存、90日复叛、口粮田亩农具；
- 不得只写首次登记1.5万人。

结果：通过时说明保留D类归屯与留存规则。

## 兼容测试3：情报准确率不得跳至96%

输入：

- 上季准确率60%。

预期：

- 底线约63%–65%；
- 上考约66%–67%；
- 泄密继续为0；
- 额外考双源验证和提前量。

结果：通过时说明保留H类准确率限制。

## 兼容测试4：兵额稳定、质量扩大

输入：

- 新军实际4万人；
- 装备、军官、补给有限。

预期：

- 总兵额维持4万，默认调整最多至4.08万；
- 超过4.08万必须有明确资源和必要性，且任何情况不得超过4.2万；
- 主要目标改为训练通过率、士气、装备可用率、合操和可调人数；
- 不得自动扩至5万、6万人。

结果：通过时说明保留J类兵额硬上限。

## v3.1测试1：御前总数局首季即时起效

错误结果：

```text
首季只完成设官、建账和制定流程。
```

正确结果必须包括：

- 首季核验12项关键数字；
- 至少查清8项冲突；
- 国库或军册账实差出现明确下降；
- 至少一个相关K类结果改善1点或等价实际结果；
- 户部或内阁等正式主管官署；
- 正式官员兼领；
- 一年考成目标和12季度日落。

结果：通过时判定F类首季不再只考里程碑。

## v3.1测试2：粮价烽火首季实际处置

输入：

```text
新设粮价烽火制度。
```

第一季度必须：

- 完成四省或若干试点府报送；
- 实际触发黄灯、红灯处置；
- 红灯地区3日内启动救济达到明确比例；
- 粮价、流民或动乱风险出现实际改善；
- 记录年度累计路径：25%、50%、75%、100%。

结果：通过时判定F类直接业务成果和K类结果均出现。

## v3.1测试3：九品考成新制

输入：

```text
新设九品考成。
```

第一季度必须：

- 完成首轮官员分类；
- 产生真实评定和整改；
- 官僚满意、执行时限、账实差或腐败至少有一项改善；
- 不能只写“制度已建立”；
- 第四季度形成年度总考，结论限于上考、达标、基本达标但须整改、未达标需更换方法或主官、停止试行。

结果：通过时判定年度考成周期已经生成。

## v3.1测试4：K类实际结果

输入：

```text
某新制度目的为改善军人满意。
```

输出必须包含：

- 首季军人满意提高1点为底线；
- 首季军人满意提高2点可为上考，普通不得默认+5点；
- 年度提高4–6点为底线；
- 同时考军饷到账、抚恤、逃亡和军功兑现；
- 若首季无满意改善，不得自动判成功。

结果：通过时判定K类已有K1和K2双层目标。

## v3.1测试5：三年日落

输入：

```text
新设临时总局。
```

必须自动生成：

- 正式主管官署；
- 正式兼领官职；
- 首年考成日期；
- 第二年考成日期；
- 三年日落日期；
- 撤销、并入、缩编或续期选项；
- 禁止自动续期。

结果：通过时判定临时机构默认12季度日落。

## v3.1测试6：正式官职优先

输入：

```text
新设制度需要主持者。
```

应优先写：

- 由户部尚书兼领；
- 由兵部侍郎兼督；
- 由都察院巡按兼核；
- 由地方巡抚统筹。

不得默认创造一个永久独立高官，不得默认建立平行六部的永久衙门。

结果：通过时判定长期执行核心仍为朝廷正职体系。

## v3.1测试7：连续两季度无成效

输入：

```text
新制度两个季度建制完成，业务有活动，但K类无改善。
```

必须触发：

- 逆向军议；
- 目标机制复核；
- 缩小试点；
- 更换方法；
- 必要时停办。

不得继续自动提高目标，不得仅以“活动完成”判为成功。

结果：通过时判定两季无K类成效会触发逆向审查。

## 兼容测试5：零容忍不抬数字

输入：

- 5股叛军补给已为0。

预期：

- 底线仍为0；
- 上考为连续维持90日、替代粮道也为0、双源核验；
- 不得把目标写成“-1”或“补给下降50%”。

结果：通过时说明保留L类阈值规则。

## 兼容测试6：固定赏银默认不变

输入：

- 上季固定犒军银5万两；
- 财政、任务和覆盖范围无结构性变化。

预期：

- 本季固定犒军银仍为5万两；
- 如有普通调整，应在4.85万–5.15万两以内；
- 任何调整不得低于4.75万两或高于5.25万两；
- 临时立功另用绩效专款，不永久抬高固定常额。

结果：通过时说明保留固定赏银小幅变化原则。
