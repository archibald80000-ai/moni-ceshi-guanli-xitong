# 御前密谈模式与问话梯子

## A. 开题密谈

### 输入

- 玩家的一两句意图；
- 当前季度或时间点；
- 已知约束、相关人物或原始资料。

### 输出骨架

```text
【御前开题】
朕欲……。此事以……为先，不得……。卿等各据实情，限……前具奏：现有底数、可用钱粮人手、三种做法、各自利害、最迟见效时日及败案。空言无益。

【分问】
- 主责：朕问……
- 财计：朕问……
- 执行/地方：朕问……
- 监察/反方：朕命……专核……

【待回要点】
基线｜资源来源｜执行链｜期限｜验据｜失败线｜备选
```

### 问话梯子

先问“现在有什么”，再问“缺什么”，再问“谁负责、如何落地”，最后问“失败时如何止损”。只在存在真实政策分歧时安排反方意见。

## B. 二轮追问

### 拆解清单

| 检查项 | 追问焦点 |
| --- | --- |
| 数据 | 基线来自何处、何时、是否已验收 |
| 资源 | 钱粮、军械、人手是否与既有事项重算 |
| 权责 | 谁主责、谁协办、谁能否决或核验 |
| 时限 | 何时出首报、何时验收、何时止损 |
| 后果 | 未达底线是补资、换法、换人还是停止 |

### 可复制话术

```text
卿所陈……，朕已览。然其中……尚无实据，……又与……相抵。朕不许只报愿景。限卿于……前，明列：一、以何数为实底；二、由谁主办、谁复核；三、钱粮/人手从何项出而不妨……；四、底线与上考各为何数；五、若未及底线，当即如何收束。并与……会核后具题。逾限或虚报者，按……论处。
```

## C. 政令协同

### 最小协同表

| 角色 | 必须明确 | 不应承担 |
| --- | --- | --- |
| 主责 | 结果、分解、首报、风险处置 | 自行核验自己的账或军功 |
| 协办 | 一项资源、技术或地方执行接口 | 与主责并列但责任模糊 |
| 制衡 | 抽查、复核、冲突上报 | 日常代替主责指挥 |
| 验收 | 验据、期限、结案判断 | 事后补写成功 |

### 可复制话术

```text
朕拟行……。命……为主责，统筹……；……专办……，不得越主责而另立门径；……会同核验……，所见不实即直达御前。卿等先勿拟空泛诏辞，各按本司职掌于……前会列：任务交接、钱粮/物资口径、每旬回报、验据样式与争议处置。朕据此裁定后，方下正式政令。
```

## 有实际反馈时的三案对照

| 方案 | 使用场景 | 先问什么 |
| --- | --- | --- |
| 守成 | 财政、执行或民心接近红线 | 哪些既有承诺绝不可断，哪些可暂停 |
| 均衡 | 需兼顾一项主危机与有限支线 | 哪项为主轴，哪些资源能重排且不重复 |
| 进取 | 有经过L3验证的储备和执行能力 | 所需增量来自何处，失败后如何退出 |

先把反馈事实和备选行动分栏；不要把“拟增”“将拨”“预计”写成“已增”“已拨”“已成”。
