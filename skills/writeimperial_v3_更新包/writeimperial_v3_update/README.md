## 目的

本压缩包用于更新：

`E:\AIS\AI任务执行清单\0730\崇祯模拟器辅助管理系统\skills\writeimperial`

它解决当前技能中的核心问题：

- 上考默认再高约50%；

- 朝政纪要实际结果经常缩水，下一季又以旧目标继续扩大，产生层层偏差；
- 兵额和固定赏银可能被不必要地持续抬高；
- 未建立稳定的季度执行系数更新上限。

## 包内结构

- `baseline_snapshot/`：从 GitHub 主分支读取的旧版关键文件快照；
- `replacement/`：建议合并后的完整新文件；
- `patch/`：旧版到新版的统一差异补丁；
- `给ChatGPT的修改指令.txt`：上传本包时可直接使用的提示词；
- `CHANGELOG.md`：改动摘要。

## 建议更新方式

1. 先备份本地 `skills/writeimperial`；
2. 将本压缩包上传给 ChatGPT；
3. 同时上传本地当前 `skills/writeimperial` 文件夹或压缩包；
4. 使用“给ChatGPT的修改指令.txt”；
5. 要求 ChatGPT 以本地当前版本为准进行合并，不要直接覆盖本地额外改动；
6. 合并后验证 JSON；
7. 使用测试案例检查目标输出；
8. 不要在这一步修改国家档案、诏书全集或 `data/*.json`，只修改 skill。

## 核心参数

### 执行系数每季度更新

- 普通：最多 `±0.05`;
- 连续2季同方向：最多 `±0.08`;
- 年度或结构性变化：最多 `±0.10`;
- 单次极端事件：最多 `±0.03` 或排除。

### 兵额和固定常额

- 兵额默认每季 `0%–2%`;
- 普通上限 `3%`;
- 硬上限 `5%`;
- 紧急扩军最高 `10%`，但需军官、粮饷、装备与训练；
- 固定赏银默认不变，普通调整 `±3%`，硬上限 `±5%`。

### 目标扩张

扩大质量、合格率、战备、产能、留存、运输、情报和真实到账，不盲目扩大纸面人数。
