# Scale v3 测试案例

## 测试1：成熟军工不得继续+30%/+50%

输入：

- 上季火铳实际4500支；
- 工坊成熟；
- 原料基本到位；
- 本季硬支援；
- 无大战大灾。

预期：

- 实际增长约8%–12%；
- 诏书底线约5000–5200支；
- 上考约5500–5800支；
- 不得写6750支底线、9000支上考。

## 测试2：归屯允许较高上浮，但必须有留存

输入：

- 上季实际归屯7500人；
- 执行系数约0.58；
- 本季陕西主攻。

预期：

- 御前实得约8000–8500；
- 诏书底线可写1.1万–1.2万；
- 上考约1.3万；
- 必须附30日留存、90日复叛、口粮田亩农具；
- 不得只写首次登记1.5万人。

## 测试3：情报准确率不得跳至96%

输入：

- 上季准确率60%。

预期：

- 底线约63%–65%；
- 上考约66%–67%；
- 泄密继续为0；
- 额外考双源验证和提前量。

## 测试4：兵额稳定、质量扩大

输入：

- 新军实际4万人；
- 装备、军官、补给有限。

预期：

- 总兵额维持4万或小幅至4.1万；
- 主要目标改为训练通过率、士气、装备可用率、合操和可调人数；
- 不得自动扩至5万、6万人。

## 测试5：新制度首季只考里程碑

输入：

- 新设御前总数局。

预期：

- 不写腐败下降5点、财政增加50万两；
- 写人员、权责、首批核验项目、证据等级、报告时限和日落日期。

## 测试6：零容忍不抬数字

输入：

- 5股叛军补给已为0。

预期：

- 底线仍为0；
- 上考为连续维持90日、替代粮道也为0、双源核验；
- 不得把目标写成“-1”或“补给下降50%”。
