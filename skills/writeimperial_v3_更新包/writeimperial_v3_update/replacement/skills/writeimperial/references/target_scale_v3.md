# Target Scale v3
## writeimperial 诏书目标、折损、上浮、上考与季度修正规则

> **版本**：3.0
> **用途**：解决旧规则将所有目标统一按“底线约+30%、上考约+50%”处理所造成的偏差。
> **核心原则**：实际目标增长、执行折损补偿、诏书上浮、上考幅度是四个不同参数，必须分别计算。
> **特殊约束**：兵额、固定赏银、常设机构等存量指标默认不大幅变动；优先扩大质量、合格率、战备率、产能、周转、留存和已验证成果。

---

## 一、五层目标模型

每个主要指标建立五层：

1. `B`：最新实际基线；
2. `R`：御前真正希望得到的季度实际结果；
3. `E`：预计执行系数；
4. `L`：诏书中写出的底线目标；
5. `U`：诏书中写出的上考目标；
6. `F`：失败线。

正向数量指标：

```text
R = B × (1 + g)
L_raw = R ÷ E
L = min(L_raw, R × (1 + uplift_cap))
U = L × (1 + stretch)
```

其中：

- `g`：实际结果的合理季度增长率；
- `uplift_cap`：为抵消执行折损而允许的诏书上浮上限；
- `stretch`：上考相对底线的有限增幅。

下降型指标，如叛军人数、账实差、伤亡、扰民：

```text
需要减少量 = B × g
R = B - 需要减少量
```

随后对“减少量”计算执行能力，而不是把剩余值机械相除。

评分、士气、准确率、到账率等指标使用“百分点”：

```text
R = B + 目标百分点
```

零容忍指标不使用百分比上浮。

## 二、任务类型

### A　成熟生产流水线

适用：

- 已运行多季的火铳、轻炮；
- 成熟工坊；
- 稳定仓储建设；
- 已验证的常规生产。

参数：

| 参数 | 默认 | 常用范围 | 硬上限 |
|---|---:|---:|---:|
| 实际季度增长 `g` | 8% | 5%–12% | 15% |
| 执行系数 `E` | 1.00 | 0.90–1.10 | 1.15 |
| 诏书上浮 | 5% | 0%–10% | 15% |
| 上考增幅 | 10% | 8%–12% | 15% |

说明：

- 连续两季上考，下一季实际增长可取10%–12%；
- 原料、工匠或设备不足时降至5%；
- 不因一次超产把下一季目标直接提高30%–50%。

### B　单一军事行动

适用：

- 断粮；
- 围困；
- 破营；
- 守口；
- 护民入堡；
- 小股袭扰；
- 截断外援。

参数：

| 参数 | 默认 | 常用范围 | 硬上限 |
|---|---:|---:|---:|
| 实际季度增长/改善 | 10% | 5%–15% | 20% |
| 执行系数 | 0.75 | 0.65–0.85 | 0.90 |
| 诏书上浮 | 20% | 15%–25% | 35% |
| 上考增幅 | 12% | 10%–15% | 20% |

说明：

- 战争目标必须受敌军存量、地形、季节和主力保全约束；
- 敌军已接近覆灭时，将“破营数量”改成“取消番号、首领处置、投降留存”等决定性指标；
- 不让破营数无限季度递增。

### C　训练、质量与军制改编

| 诏书上浮 | 15% | 10%–20% | 30% |
| 上考增幅 | 8% | 5%–10% | 12% |

评分/比例参数：

- 士气、经验、战备评分：通常每季 `+3–6` 点，硬上限 `+8`；
- 通过率、可用率：通常每季 `+3–5` 个百分点，硬上限 `+8`；
- 不把总兵额增长当成训练成果。

- 维持 `0`；
- 上考改为双重隔离、诱饵测试、来源保护等韧性指标。

- 优先不扩总量；
- 重点提高可战、通过训练、装备齐全和可调比例；

适用：

- 民心；
- 满意度；
- 腐败度；
- 皇帝权威；
- 国家威望；
- 社会稳定。

不直接按产量规则计算。

季度合理预期：

- 满意度、民心、威望：`0–2` 点；上限 `3` 点；
- 腐败度：`0–2` 点下降；上限 `3` 点；
- 大胜、重大法制改革或灾难可能例外，但不写作单一部门硬产量。

诏书应写前置信号：

- 到账率；
- 粮价；
- 抚恤；
- 扰民；
- 冤案；
- 账实差；
- 晋升兑现；
- 灾害死亡；
- 主力保全。

### L　阈值、零容忍和二元结果

适用：

- 补给=`0`；
- 泄密=`0`；
- 遗炮=`0`；
- 核心关口失守=`0`；
- 军饷断发=`0`。

规则：

- 不提高零；
- 不设置“上考为负数”；
- 底线是维持；
- 上考使用持续时间、覆盖率、备用方案、恢复时间和独立核验。

示例：

```text
底线：5股补给继续为0。
上考：连续90日为0，且3条粮道均有双源核验，无一股转入河南山西取得新补给。
```

## 四、每季度如何更新

### 1. 计算实际兑现率

数量型：

```text
realization = actual ÷ edict_bottom_line
```

改善型：

```text
realization =
  实际改善量 ÷ 诏书要求改善量
```

比例/评分型：

```text
realization =
  实际增加百分点 ÷ 要求增加百分点
```

阈值型：

- 达成：1；
- 未达：0；
- 另记录持续天数和复起次数。

### 2. 冲击修正

将未达原因分为：

- 资源不足；
- 外部冲击；
- 协同失败；
- 目标失真；
- 本人失职。

只有可比、可信且非极端异常的数据进入系数更新。

### 3. 滚动更新

默认：

```text
E_new =
  E_old × 0.70
  + median(last_4_comparable_realizations) × 0.30
```

每季度变动上限：

| 情况 | 单季上限 |
|---|---:|
| 一般更新 | ±0.05 |
| 连续2季同方向 | ±0.08 |
| 年度总校准/结构变化 | ±0.10 |
| 单次极端事件 | 不直接更新或仅±0.03 |

### 4. 目标增长更新

按实际相对“预计实得”的表现：

| 完成情况 | 下一季实际目标增长 |
|---|---|
| ≥110% | 使用类别增长区间上半段 |
| 95%–109% | 使用默认增长 |
| 80%–94% | 使用区间下半段或保持 |
| 60%–79% | 暂停增长，先补资源/方法 |
| <60% | 不上浮；改方法、缩试点或换责 |

长期战略目标可以保持进取，但季度目标必须服从真实能力。

## 六、兵额与固定常额

用户偏好：兵量/兵额不大幅变动，目标在原有基础上扩大。

因此：

### 兵额

- 总兵额季度默认 `0%–2%`；
- 普通上限 `3%`；
- 硬上限 `5%`；
- 战时新募硬上限 `10%`，但必须同时具备军官、训练、粮饷和装备。

扩大目标应优先写：

- 可战率；
- 训练通过率；
- 装备可用率；
- 补给；
- 士气前置信号；
- 机动时间；
- 火力密度；
- 工兵、运输、军医和修械能力。

### 固定赏银

- 默认保持原额；
- 不因新季度自动加码；
- 普通调整 `±3%`；
- 硬上限 `±5%`；
- 额外奖励使用绩效专款，不永久抬高常额。

## 七、偏差修正

### 1. 旧规则的高估偏差

统一 `+30%/+50%` 会：

- 对成熟军工过度加压；
- 对新制度产生虚报；
- 对归屯仍可能不足；
- 对情报准确率产生不可能跳跃；
- 对兵额造成纸面膨胀。

Scale v3 分类型处理。

### 2. 基线偏差

如果基线来自旧诏书目标而非实际结果，会层层膨胀。

修正：

- 强制使用最新实际；
- 未知时使用范围；
- 证据C/D不用于高幅增长。

### 3. 幸存者偏差

不能只记录成功项目。

修正：

- 未完成、暂停、失败和取消也进入季度反馈；
- 但极端冲击单独标记。

### 4. 单季波动

修正：

- 4项同类任务中位数；
- 70%旧系数+30%新信息；
- 单季变化上限。

### 5. 目标拥塞

同季项目过多时，额外任务聚焦系数降至0.70。

若出现：

- 超过1主攻；
- 超过2硬支援；
- 超过3维持；
- 同一条款4名以上共同总责；
- 10个以上核心数字；
- 3项以上新制度；

必须缩减或主动下调预计执行。

## 八、示例

### 示例1：火铳产量

最新实际：4500支。
成熟流水线，正常资源，实际希望增长10%。

```text
B = 4500
R = 4950
E ≈ 1.00
上浮 = 5%
L ≈ 5200
上考 = L × 1.10 ≈ 5700
失败线 ≈ 4300
```

建议诏书写：

> 火铳季产5200支为底线、5700支为上考；合格率、试放、铳管与弹药配套必须同时达标，低于4300支或炸膛返修异常者专项复核。

### 示例2：归屯

最新实际：7500人。
实际希望增长8%，预计执行偏低。

```text
B = 7500
R = 8100
E ≈ 0.58
L_raw ≈ 1.4万人
上浮硬限制50%
L = 1.2万人左右
U = 1.35万人左右
F = 5000–6000人
```

必须同时写30日留存和90日复叛。

### 示例3：六耳准确率

最新实际：60%。

不使用比例增长。

```text
R = 63%
L = 65%
U = 67%
F = 58%或重大误报成灾
```

不能写93%–96%。

### 示例4：新军兵额

最新实际：4万人。

```text
兵额目标：维持4万，最多扩至4.1万–4.2万
真正扩大：
- 训练通过率
- 装备齐备率
- 士气
- 车炮铳骑合操
- 可调人数
```

### 示例5：补给为0

```text
底线：5股补给继续为0
上考：连续90日为0，且无一股从河南山西取得替代粮道
失败线：任一股补给升至1
```

## 十、强制校验清单

写诏书前必须回答：

- 基线是实际还是旧目标？
- 属于哪种任务类型？
- 是存量还是绩效？
- 实际目标增长多少？
- 执行系数多少？
- 上浮是否超过类型上限？
- 上考是否仍在合理范围？
- 失败线是什么？
- 是否有前置信号？
- 是否有败案？
- 是否因项目过多降低聚焦？
- 是否将满意度、腐败等误写成直接产量？
